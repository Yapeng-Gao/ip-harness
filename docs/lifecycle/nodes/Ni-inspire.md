# 节点 Ni · 创新激发（Inspire）

> **业务规格**（产品级）。样机壳旁证见 [docs/architecture/inspire/](../../architecture/inspire/README.md)；专家席 `expert-inspire` 见 [13-agents.md](13-agents.md) §9.2。  
> **必经分层**：条件触发 / 可轻跑；**不堵**交底→查新→立项主链。  
> **日期**：2026-10-23（Asia/Shanghai）。业务不以原型为准。

---

## 0. 一句话讲清这个节点

**创新激发：先把「还能往哪走」摊成方向清单，再交给挖掘或交底——不谈申不申、能不能授权。**

| | |
|---|---|
| **目的** | 降低冷启动：从问题/技术点扩召出可收藏的方向（灵感卡） |
| **谁做** | 研发/发明人为主；IPR 或挖掘顾问可组织激发会 |
| **交出什么** | 方向清单 / 灵感卡（可收藏）；**不**打分、**不**建案、**不**出三性/FTO |
| **下一站** | 捕获入口或 [Nm 挖掘](Nm-mining.md)；也可直接进 [00 交底](00-inventor-disclosure.md) 入口。本站可跳过 |

### 白话摘要

回答「还有什么可做」。不是挖掘（申什么）、不是查新（能不能授权）、不是布局（整盘怎么护）。条件触发、可轻跑；不堵主链。

产品化三条件：

| 条件 | 说明 |
|---|---|
| 独立买方 | 中小企业研发负责人、代理所挖掘顾问；也可作 IP 部「创新工坊」入口 |
| 独立价值 | 把研发漫游变成可交接清单 |
| 独立边界 | 只出方向/卡片；评分与建案在下游 |


## 1. 节点定位与产品边界

### 1.1 在生命周期中的位置

```
[Ni 创新激发] ──方向清单──▶ [捕获入口/Nm] ──▶ [00 交底] ──▶ [01 查新] ──▶ …
      │                         ▲
      └── 可跳过（条件触发）─────┘
```

默认主链见 [business-spine.md §1.3](../business-spine.md)。捕获 **Nc 不单列**（⚠ 可改）：技术事实入池并入 **00 提报入口 / Nm 上游**，见 spine §1.3.1。

### 1.2 StageId / 路由 / 壳 / 产物键

| 项 | 值 | 现状 |
|---|---|---|
| StageId | 无正式 `StageId`（提案轴） | ❌ contracts 未登记 |
| midStage（席位） | `proposal` | ✅ `patentMidMap` |
| 专家席 | `expert-inspire` | ✅ [13](13-agents.md) |
| Agent（手） | 常挂 `agent-research`（共享手） | ⚠ 对内编排；对外不说 Agent |
| 样机壳 | `apps/inspire` :5185 | ✅ 样机 |
| 产物键（contracts） | **无**；提案产出 `inspire_brief` / 方向清单 | ❌ 未进 `HandoffArtifactKey` |
| 读工具（席） | `brainstorm_directions` / `draft_inspire_brief` | ⚠ 样机/剧本 |

### 1.3 是 / 不是

| 是 | 不是 |
|---|---|
| 方向扩召、灵感卡、收藏夹 | 发明点评分 / 拆案（那是 **Nm**） |
| 可送挖掘 / 送交底入口 | 可专利性结论（那是 **01**） |
| 可挂假 Hit 作「相关公开」示意 | FTO / 自由实施（那是 **01b**） |
| 条件触发、可轻跑 | 法律必经或业务必经关 |

### 1.4 上下游契约

| 方向 | 对象 | 契约 |
|---|---|---|
| 上游 | 研发问题、技术点、产业全景卡片（可选） | 至少一句可扩召的种子输入 |
| 下游 → Nm | 收藏卡摘要 / 种子 id | 文本+id；**不**带评分 |
| 下游 → 00 | 「送交底」占位深链 | 仅入口意图；不写 `disclosure_pack` |
| 旁路 → search | 可选相关公开示意 | 禁止在 Ni 重造检索引擎 |

### 1.5 独立产品形态

| 模块 | 做什么 | 不做什么 |
|---|---|---|
| 扩召台 | 输入→多卡→收藏 | 真 LLM 可后期接；不得假装已建案 |
| 送出桥 | 送 Nm / 送 00 入口 | DomainCommand 写 case-core |
| 工坊入口 | 公司/部门叙事下的「创新激发部」 | 对外讲 Agent/Harness |

## 2. 角色与权限矩阵

| 角色 | 代码对应 | 能做什么 | 不能做什么 |
|---|---|---|---|
| 发明人/研发 | inventor / self | 输入种子、收藏、送出 | 代签立项、改他人案 |
| IPR / 挖掘顾问 | enterprise / agency | 组织激发会、挑选方向送 Nm | 把方向清单当 Go |
| 专家席 `expert-inspire` | 席位 | 建议权：出 brief | 决定权（无 D1–D7） |
| 系统 | Agent 手 | 扩召草稿 | 不可代人确认送出（须 HITL 交卷） |

**当前实现真相**：样机无真鉴权；席位 RACI 为提示文案（见 13）。对外产品应用「部门交卷 · 待你确认」，不对小白说 HITL。

### 2.1 决策权

本节点**无 D1–D7**。仅有「是否采纳某方向进入 Nm/00」的 L1 经办选择；**不**构成申请决策。

## 4. 业务规则（编号 `RNi-`）

### 4.1 核心判定

| ID | 规则 | 现状 |
|---|---|---|
| RNi-01 | 激发产出仅为方向清单；不得直接产生 Go/No-Go | ❌ 无正式闸 |
| RNi-02 | 送 Nm 只传卡片文本/种子 id，不传「已评分」假象 | ⚠ 样机约定 |
| RNi-03 | 跳过 Ni 不得阻断 00→01→02 | ✅ 文档口径 |

### 4.2 齐套（提案级，非 contracts handoff）

| ID | 规则 | 现状 |
|---|---|---|
| RNi-10 | 交卷送出至少 1 张已收藏卡或等价方向条目 | ❌ |
| RNi-11 | 每张卡须有 title + hook | ⚠ 样机 |

### 4.3 写回 / 权限

| ID | 规则 | 现状 |
|---|---|---|
| RNi-20 | Ni **禁止** DomainCommand 创建/改 PatentCase | ⚠ 样机诚实 |
| RNi-21 | 建议权与「送出确认」分离；确认须留操作者 | ❌ |

### 4.4 例外与冲突

| ID | 规则 | 现状 |
|---|---|---|
| RNi-30 | 紧急交底（公开时点临近）可跳过 Ni，直接 00 | ✅ 条件触发口径 |
| RNi-31 | 与 Nm 边界冲突时：**收敛/评分归 Nm，扩召归 Ni** | ✅ 架构 overview |

## 5. 法律底座 / 行业规则

本节点无强法律强制程序。行业惯例：

| 规则 | 产品落点 | 失效后果 |
|---|---|---|
| 公开前不得无管控外泄技术方案 | 激发会产物默认企业内部可见；导出须脱敏策略 | 新颖性丧失风险（链到 00 公开时点） |
| 职务发明线索仍属企业 | 方向卡归属企业项目，而非个人作品集对外公开 | 权属纠纷 |
| 不得承诺「这些方向一定能授权」 | UI 禁用授权率承诺文案（对齐 decision-rights 红线） | 非正常申请/误导风险 |

⚠ 奖酬、宽限期等落在 **00**，不在 Ni 重复立法。

## 6. 状态机

```
empty → seeded → cards_ready → favorited → sent_to_mining
                                   └──────→ sent_to_disclosure_entry
任意态 ──skip──▶ bypassed（记录跳过原因）
```

| 当前态 | 可迁往 | 谁做 | 业务含义 | 出口条件 |
|---|---|---|---|---|
| empty | seeded | 用户 | 有种子 | text 非空 |
| seeded | cards_ready | 系统/席 | 已扩召 | ≥1 卡 |
| cards_ready | favorited | 用户 | 已挑选 | ≥1 收藏 |
| favorited | sent_* | 用户确认 | 交卷 | SendIntent 写入 |
| * | bypassed | 用户/IPR | 跳过激发 | 原因码 |

**实现偏差**：样机多为内存态；无正式状态枚举进 domain。

| 闸门 | 触发 | 文案口径 | 代码 |

## 11. 边界与失败场景

| # | 场景 | 正确处置 | 现状 |
|---|---|---|---|
| 1 | 把灵感卡当交底提交 | 拒绝；引导补 00 六项 | ❌ |
| 2 | 把假 Hit 当查新结论 | 卡上标注「示意」；01 重做 | ⚠ |
| 3 | 跳过 Ni 被系统强迫补做 | 允许 bypass | ✅ 口径 |
| 4 | 一人「激发并直接 Go」 | 禁止；Go 只在 02 | ❌ |
| 5 | 外发未脱敏方向清单 | 阻断或水印+审批 | ❌ |
| 6 | 与 Nm 同壳揉成一个 | 分壳/分部门 | ⚠ 架构已禁 |
| 7 | 承诺授权率 | 红线硬阻断文案 | ❌ |
| 8 | 发明人只能从 Ni 进系统 | 允许直达 00 | ✅ 口径 |
| 9 | 收藏空仍送出 | 齐套失败 | ❌ |
| 10 | 下游 Nm 已评分又改卡 | 新版本卡；旧评分作废提示 | ❌ |
| 11 | 把 Ni 当 FTO | 引导 01b | ✅ 文档 |
| 12 | Agent 自动送出无确认 | 须人确认交卷 | ❌ |

## 12. 指标

| 指标 | 定义 | 健康区间 | 说明 |
|---|---|---|---|
| 方向→挖掘转化率 | 送 Nm 的卡 / 收藏卡 | 视企业；建议可追踪 | 产品价值 |
| 跳过率 | bypass / 全部激发会话 | 高不一定坏（紧急交底） | 勿强降 |
| 误用率 | 当交底/当查新的拦截次数 | →0 | 边界清晰度 |
| 工时 | 次均人时 | 轻跑 <2h | 可换算省顾问费 |

## 13. 产品化切分建议

| 层 | 内容 | 可独立交付 |
|---|---|---|
| L1 入口模块 | 激发部四步 UI | 是（轻量 SKU） |
| L2 与 Nm 联运 | 送出桥 + 转化漏斗 | 是 |
| L3 接真模型 | 替换种子拼装 | 可选升级 |

定价锚点：按「激发会话数」或打进「挖掘/交底」包的入口能力。竞品多停在聊天脑暴；**可交接方向清单 + 明确不越权**是空位。
