## 0. 一句话讲清这个节点

**PCT 是「一次申请、多国保留、延迟决策」的国际专利申请通道：先用一份国际申请占住 30 个月的决策窗口，再逐国决定进不进、怎么进。**

它不是「国际专利」——**世界上没有国际专利**。PCT 只统一了**申请程序**（受理、检索、公布、初步审查），授权仍然由各国专利局分别作出。这一点是所有误解的源头。

产品化视角下它能独立成产品，因为三条同时成立：

1. **有独立买方**：有出海业务的企业（制造出口、跨境电商、海外投标）、涉外代理所。
2. **有独立价值**：30 个月窗口的价值可以量化——每延迟一个月决策，就少一次「押错国家」的沉没成本；多国期限并发管理的失败一次就是整国权利灭失。
3. **有独立边界**：输入是「一件优先权申请 + 目标国清单」，输出是「国际阶段档案 + N 条国家阶段期限 + N 份进入案卷」，不依赖国内撰写/审查流程即可独立运行。

> 讲给实习生的一句话：**PCT 卖的不是申请，是「时间」和「不出错」。** 客户为 30 个月付钱，为「别把 32 个月的宽限算错」付更多钱。

### 1.3 它是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 一份国际**申请**，统一程序、延迟决策 | 一个国际**专利**（不存在） |
| 30 个月决策窗口的**载体** | 30 个月后自动在多国生效（必须逐国办理进入） |
| 国际检索报告（ISR）作为**参考意见** | 授权结论（ISR 无约束力） |
| 国际初步审查（第 II 章）作为**可选**程序 | 必经程序（多数申请人不用） |
| 巴黎公约路径的**替代**方案 | 巴黎公约路径的**升级**（两者并列，各有适用场景） |

> 最容易错的一点：**PCT 不授权。** ISR 说「有新颖性」不代表各国会给授权；ISR 说「没新颖性」也不代表一定被驳回。它只是给申请人一次**提前看牌**的机会。

## 2. 角色与权限矩阵（建议口径）

| 角色 | 能做什么 | 不能做什么 |
|---|---|---|
| 企业 IPR | 决定进入哪些国家、批准预算、确认放弃 | 不能代填代理所国际阶段信息 |
| 涉外代理师 | 递交国际申请、处理 ISR、办理国家阶段进入 | 不能替企业决定商业国别 |
| 外国当地代理 | 本国进入手续、译文校对、本国 OA | 不能改国际阶段记录 |
| 法务 | 保密审查申请、出口合规 | 不能改期限 |
| 财务 | 分国费用确认、外汇付汇 | — |
| Docket 岗 | 期限监控与升级 | 不能改法律事实（进入日等） |

**当前实现的权限真相**：**不存在**。全仓无 PCT 角色、无 PCT 权限、无 PCT 审计。只有 `draft_claims` 的 `countries` 数组由企业在撰写台点选。

### 2.1 决策权

角色矩阵回答「谁能做什么」。PCT 要回答的是：**「进不进、进哪几国、花多少钱」谁说了算。**

本节点承载 **D4（去哪里申请）** 的国际维度，其决策权模型与国内单案有三处根本不同：

| 差异 | 国内单案 | PCT 国际 |
|---|---|---|
| **期限性质** | 有延期、有恢复、有宽限 | **30 个月是硬期限，错过不可恢复**（中国最多到 32 个月 ⚠，且须缴宽限费） |
| **决策粒度** | 一案一决策 | **一国一决策**，决策本身也是要落库的数据（`decision` 字段） |
| **成本结构** | 官费 + 代理费 | 官费 × 国数 + 翻译 × 语种数 + 当地代理 × 国数 + 年费 × 国 × 年 |

> **本节点最硬的一条**：**30 个月是硬期限，错过不可恢复。** 它不是「内部流程慢」能解释的事，也不是「客户还在想」能挡的事。**系统必须在期限前把决策逼出来，而不是在期限后生成一条「权利灭失」事件。** 逾期一旦发生，产品能做的只有记录，不能补救。

**四种权能，在 PCT 里这样落**：

| 权能 | 含义 | 典型场景 | 系统落点 |
|---|---|---|---|
| 建议权 | 给方案、给概率、给成本 | 代理师（路径、第 II 章）、涉外 IPR（国别推荐）、08 布局（国别建议） | 建议与决议分表 |
| 决定权 | 拍板并承担后果 | **企业**（IP 总监按额度）；代理师不得替企业选国 | 决议 + 签署 + 每国 `decision` |
| 否决权 | 叫停已决定的事 | **财务**（预算超限）、法务（保密审查未过、出口管制） | 一票否决，书面理由 |
| 知情权 | 被动获知 | 业务部门（各国市场）、当地代理（进入指令）、下游 04/05 | 通知不阻断流程 |

**决策归属**：

| 决策 | 建议权 | 决定权 | 否决权 | 分级与依据 |
|---|---|---|---|---|
| 是否走 PCT（vs 巴黎公约） | 代理师（三维对比）、08 布局 | 企业 IP 总监 | 财务（国际阶段费） | L2：可逆性低（12 个月窗口内仍可改路径） |
| 指定国清单（国际阶段） | 代理师、08 布局 | 企业 IPR | 法务（保密审查） | L2：指定不产生进入义务，成本低 |
| **30 个月进入哪些国家** | 涉外 IPR、当地代理（可行性） | **IP 总监 + 财务**（按额度） | **财务（超预算）、法务（合规）** | **L4**：不可逆 + 高金额 |
| 各国代理所选聘 | 涉外 IPR（比价与资质） | 代理所管理岗 / IP 总监 | 采购（合规） | L2；**当地代理不得自行决定进入国别** |
| 译文质量与定稿 | 翻译、当地代理校对 | 涉外代理师（专业责任） | — | 译文错误可致权项范围变化，须复核 |
| 预算分级与分配 | 财务 BP | 按额度（见下表） | 财务 | 不得拆分国别规避审批 |
| 放弃某国（进入前） | 涉外 IPR（影响评估） | IP 总监 | 业务负责人（该国为主要市场时） | **L3**：决定本身可改，但期限一过即成事实放弃 |
| 放弃某国（已进入后） | IPR | IP 总监 | 财务 | L4：退出不可逆，联动 05/23 |
| 第 II 章（IPEA）是否请求 | 代理师 | 企业 IPR | 财务 | L2：22 个月期限 ⚠ |

**预算分级**（金额为示意 ⚠，须按企业授权制度配置，不得硬编码）：

| 层级 | 触发条件 | 批准人 | 典型情形 |
|---|---|---|---|
| L1 | 可逆 + 低金额 | 经办 IPR | 单国补正、单份译文校对 |
| L2 | 可逆 + 高金额 | IP 总监 | 指定国调整、单国进入 |
| L3 | 不可逆 + 低金额 | 双人复核 | 放弃单国、第 19 条修改定稿 |
| L4 | 不可逆 + 高金额 | IP 总监 + 财务会签 + 双人复核 | 多国进入包、全族放弃 |

**三条不可让渡的边界**：

1. **国别决策是预算决策，须财务参与。** 选国不是法律判断，是资源分配。没有财务会签的国别清单，本质上是一张愿望清单。系统须要求每国绑定预算科目，无科目的国家不得进入「决定进入」。
2. **各国代理所不得自行决定进入国别。** 当地代理只对本国的**手续可行性与成本**负责；「这个国家值不值得进」是企业的商业判断。代理所代填 `decision` 是越权，须在权限模型里硬阻断。
3. **译文错误可能导致权项范围变化，须复核。** 译文不是格式化工作：权项中的一个限定词译错，可能缩小保护范围，且后续更正受严格限制。译文须有「译者 + 校对 + 定稿人」三段留痕，定稿人对专业准确性负责。

> **一条容易漏的**：**进入决策与进入执行是两件事，期限相同但责任人不同。** 决策由企业做（可以晚到 29 个月），执行由当地代理做（需要 5–20 个工作日）。把两者当成同一个截止日，是涉外案件最常见的操作事故（§5.5）。

### 4.7 例外情形

PCT 的规则大半是**法定硬期限**，没有内部裁量的空间。所以本节的例外分两类，必须分开处理：

- **程序例外**：条约/细则本身给了救济（优先权恢复、宽限、额外手续），属**规则的一部分**，系统应内置，不是「特批」；
- **内部例外**：企业内部流程做不到时的处置（预算未批、译文来不及），须批准 + 留痕 + 限期。

把它们混成一个「特殊处理」按钮，后果是：法定的救济没人会用，内部的破例没人敢拒。

| # | 例外 | 例外条件 | 谁批准 | 风险 | 留痕 |
|---|---|---|---|---|---|
| E1 | 30 个月将过但预算未批 | 已具备完整进入材料（译文 + 委托 + 官费估算），仅差内部审批；且该国属「必须进」 | IP 总监 + 财务（紧急会签，建议 3 个工作日内 ⚠） | **先进入后补预算**意味着企业已对外承诺；若预算最终被拒，只能立即放弃，进入费沉没 | 必留：紧急会签记录 + 预算追认时限 + 「若不追认即放弃」的处置预案 |
| E2 | 部分国家需额外手续 | 该国要求公证/认证委托书、额外译文、本地实体证明等，使标准周期不足 | 涉外 IPR 判断，代理师执行 | 手续未备即递交 → 不予受理，占用进入期限却不产生进入效果 | 必留：该国手续清单 + 办理周期 + 启动时点 |
| E3 | 译文来不及 | 译文在期限内无法定稿，但可先提交**机器译文/初译**并保留更正 | 涉外代理师 + 企业知情 | 初译错误可能改变权项范围；更正受该国程序限制，未必允许 ⚠ | 必留：初译版本 + 更正计划 + 范围影响初评 |
| E4 | 优先权恢复 | 12 个月窗口已过，但符合条约/细则的恢复条件（如遗漏非故意）⚠，且受理局接受 | 代理师建议，企业决定 | 恢复不被接受则优先权彻底丧失；恢复请求本身有费用与时限 ⚠ | 必留：恢复请求文书 + 受理局回执 + 原逾期原因说明 |
| E5 | 某些国家不接受某些主题 | 目标国对软件、商业方法、诊断治疗方法、动植物品种等主题有排除或限制 ⚠ 按该国法律核 | 代理师判断，企业决定是否仍进入 | 进入后必被驳回，白付翻译与官费；但某些国家可通过权项改写规避 | 必留：主题适格性意见 + 是否改写权项的决议 |
| E6 | PCT 国际阶段已发现障碍 | ISR/书面意见全部为 X 类文献，或存在清楚性/支持缺陷，进入后大概率无法克服 | 代理师 + 企业（决策会） | 逐国硬进 = N 份驳回；但国际阶段意见无约束力，部分国家审查更宽松 | 必留：逐条引证研判 + 「哪些国家仍有空间」的国别差异分析 |
| E7 | 汇率大幅波动影响预算 | 预算按单一汇率编制，实际付汇时偏离超阈值（建议 ±10% ⚠，企业配置） | 财务 | 预算被动击穿；多国同时付汇时偏差被放大 | 必留：预算汇率与付汇汇率对照 + 差额来源 |

**E1 的边界（唯一需要单独建模的例外）**——「先进入后补预算」是本节点最诱人、也最危险的出口：

| 判断项 | 问什么 | 结论 |
|---|---|---|
| 该国是否「必须进」 | 制造地 / 主销售地 / 主对手所在地，命中任一 | 否 → **不得走 E1**，按常规放弃决策处理 |
| 材料是否已齐 | 译文定稿 + 委托书 + 官费金额确定 | 否 → 走 E3/E2，不是预算问题 |
| 谁承担沉没成本 | 预算被拒时，进入费由哪个科目承担 | 无科目 → 不得进入 |
| 补预算时限 | 建议 10 个工作日 ⚠，逾期自动转「放弃」并通知业务 | 逾期未批 → 系统置为放弃，须留痕 |

> **例外不是豁免**：每条例外必须记录**依据、批准人、风险、有效期**四件，缺一视为违规（[decision-rights.md](../decision-rights.md) §4.2）。本节点的 E4、E5 是**法定例外**，不能做成特批按钮；E1、E3、E7 是**内部例外**，必须有时限与追认。

**本节点的红线（任何批准都不能突破）**：

| 红线 | 原因 |
|---|---|
| 保密审查未过即向外国递交 | 中国不授权，已授权亦构成无效理由（§5.6），不可补救 |
| 为赶 30 个月而倒签进入日、伪造递交回执 | 伪造法律事实，权利基础不成立 |
| 用「已通知客户」代替「客户已决定」 | 沉默不构成同意，也构不成放弃 |
| 当地代理代企业勾选进入国别 | 越权决策，责任无法归属 |
| 提交与本申请主题不符的译文以凑期限 | 进入无效，且后续更正受严格限制 |
| 对外宣称「PCT 已授权」 | PCT 不授权，属误导性陈述 |

### 4.8 规则冲突与裁决

本节点的冲突有一个共同特征：**一方永远是国家数量与覆盖面，另一方永远是钱、时间、质量。** 而这四者之间没有客观最优解，只有**明确的裁决顺序**。

**五类真实冲突**：

| # | 冲突 | 典型表现 | 裁决 | 裁决人 |
|---|---|---|---|---|
| C1 | 覆盖国家多 vs 预算 | 08 建议 12 国，预算只够 5 国 | **按「制造地 > 销售地 > 对手所在地 > 诉讼优选地」排序取前 N**；未进入国须标「监控」并写明重新评估触发点（如对手在该国布局）。**不得平均摊薄到 12 国**，摊薄的后果是每国都不完整 | IP 总监，财务会签（L4） |
| C2 | 进入快 vs 译文质量 | 期限倒计时 3 天，译文尚未定稿 | **期限优先（原则 4）**：先以初译递交保住进入日（E3），同时启动更正；但**须书面声明范围风险**。反过来——若该国不允许更正译文，宁可放弃也不递交错译 | 涉外代理师判断，企业确认 |
| C3 | 总部决策 vs 当地业务需求 | 总部砍掉某国，当地业务称该国是主战场 | **当地业务有数据则重排优先级**：以销售/制造数据而非意见为准；数据不支持则维持总部决定。**当地业务无决定权，但有否决权的情形限于「该国为唯一制造地」** | IP 总监 + 业务负责人 |
| C4 | PCT vs 巴黎公约 | 代理师建议 PCT，财务认为多一道国际阶段费 | **按决策树而非偏好**（§5.4）：目标国 ≤2 且已定 → 巴黎公约；≥3 或未定 → PCT。**国际阶段费不是「浪费」，是购买 18 个月决策期权的价格**；用「每国摊薄后的成本」比较，而非绝对总额 | 代理师建议，IP 总监决定 |
| C5 | 放弃某国 vs 对手在该国布局 | 预算紧张拟放弃某国，情报显示对手正在该国密集申请 | **对手布局本身即「该国重要」的证据**：先查该国的判赔力度与实际销售占比，再决定。若该国是竞争对手的制造地，**放弃等于给对方一个无对抗市场**，须由 IP 总监书面确认后方可放弃 | IP 总监，业务负责人可否决 |

**裁决顺序（自上而下适用）**：

| 序 | 原则 | 含义 | 本节点例 |
|---|---|---|---|
| 1 | **法定硬期限优先** | 12 / 22 / 30 / 32 个月不可让渡 ⚠ | 任何冲突不得以「来不及」为由跳过期限 |
| 2 | **合规优先于成本** | 保密审查、主题适格性不可交易 | 未过审查的国家不能进，省钱不是理由 |
| 3 | **不可逆优先于可逆** | 进入日、放弃、译文定稿不可撤回 | 先处理期限最近的国家 |
| 4 | **期限优先于质量** | 有硬窗口的先递交，质量用后续程序补 | C2：初译先入，更正后补 |
| 5 | **覆盖优先级按「制造 > 销售 > 对手 > 诉讼」** | 预算不足时的排序规则 | C1、C5 |
| 6 | **组合成本优先于单国最优** | 单国的完美进入若挤掉三国，不划算 | 不为一国争超项费而砍掉其他国家 |
| 7 | **书面留痕优先于口头一致** | 任何偏离须有书面理由 | E1 的追认、C3 的分歧 |

> **最重要的一条**：C2 的裁决方向不能反过来用。**「期限优先于质量」只允许在「有后续更正程序」时适用。** 若某国不允许更正译文，先递交错译 = 用确定的进入机会换一个错误的保护范围，等于**花了钱买了一个不可用的权利**。系统应把「该国是否允许译文更正」做成进入决策的前置字段，而不是让代理师凭记忆判断。

**冲突规则补遗**：

| ID | 规则 | 现状 |
|---|---|---|
| R09-77 | 偏离 §4.7 任一条例外的操作，须记录依据、批准人、风险、有效期四项，缺项不得执行 | ❌ 无例外对象 |
| R09-78 | 预算不足时须输出「进入 / 监控 / 放弃」三张国别清单，监控国须写明重新评估触发点 | ❌ |
| R09-79 | 国别排序须按「制造地 > 销售地 > 对手所在地 > 诉讼优选地」并可解释，不得按字母序或主观排序 | ❌ |
| R09-80 | 决定以初译递交前，须校验该国是否允许译文更正；不允许者不得走 E3 | ❌ 无国别属性 |
| R09-81 | PCT 与巴黎公约的路径比较须用「每国摊薄后的总成本 + 时间 + 灵活性」三维，不得只比绝对总额 | ❌ 撰写台只有一个复选 |
| R09-82 | 放弃某国前须查询该国是否存在对手布局；存在时须由 IP 总监书面确认，不得由 IPR 单独决定 | ❌ |

| R09-84 | 每次冲突裁决须记录适用的原则序号（§4.8），以便年度复盘时核对规则是否失效 | ❌ |

## 5. 法律底座 / 行业规则

### 5.1 PCT 两阶段的结构

| 阶段 | 谁在办 | 产出 | 约束力 |
|---|---|---|---|
| **国际阶段** | 受理局 RO（受理）、ISA（检索）、IPEA（可选初审）、IB（公布） | 国际申请日、ISR + 书面意见、国际公布、IPER | 对各国**无约束力**，仅供参考 |
| **国家阶段** | 各指定国专利局 | 各国申请号、各国审查、各国授权 | 各国独立，**授权与否由各国决定** |

**产品落点**：系统必须把这两段做成**两套台账**，而不是一条时间线。国际阶段的记录是「一次性的历史」，国家阶段的数据是「N 条并行的活账」。

### 5.2 时间轴（自最早优先权日起算）

| 时点 | 事项 | 性质 |
|---|---|---|
| 0 | 优先权基础申请提交 | 锚点 |
| **12 个月** | PCT 国际申请提交截止（否则不能主张优先权） | **硬期限** |
| 约 16 个月 | ISA 出具 ISR + 书面意见（实务均值）⚠ 非硬期限 | 实务 |
| **18 个月** | 国际公布 | 硬时点（不可提前取消） |
| 约 19 个月 | 提出第 II 章请求的「安全线」 | 实务 |
| **22 个月** | 第 II 章请求的法定截止（或 ISR 传送后 3 个月，取晚）⚠ | **硬期限** |
| 约 28 个月 | IPER 出具（若请求了第 II 章） | 实务 |
| **30 个月** | 进入国家阶段（多数国家） | **硬期限** |
| **32 个月** | 中国宽限截止（缴宽限费） | **硬期限 + 费用** |

> **⚠ 关于「16 个月」的常见错误**：它不是法定硬期限。ISR 的法定上限是「ISA 收到检索本起 3 个月，或优先权日起 9 个月，取晚者」，实务中常在 16 个月前后到手。写进 docket 时应标为**业务预估**，不能当法定期限报警。本仓旧文档把它说成硬期限，需纠正。

### 5.3 中国作为受理局与进入中国

| 事项 | 规则要点 | 产品落点 |
|---|---|---|
| 受理局 | 中国申请人可向 CNIPA 提交 PCT 国际申请（中文或英文） | 受理局字段须支持 CNIPA |
| 保密审查 | 在中国完成的发明向外国申请前须经 CNIPA 保密审查（专利法第 19 条）；违反 → 中国不授权，已授权的构成无效理由 | **硬前置闸**，未过审查不得递交 |
| 进入期限 | 优先权日起 30 个月；缴宽限费可延至 32 个月 ⚠ 条号按 2023 修订细则核（旧版第 103 条，新版约第 129–130 条） | docket 双期限 |
| 宽限费 | 逾期进入需缴宽限费 ⚠ 金额按当期收费表（有资料称约 1000 元，须复核） | 独立费用项 |
| 译文 | 外文提交的须提交中文译文 | 译文状态字段 |
| 代理 | 在中国无长期居所/营业所的外国人/外国企业**必须**委托中国代理机构 | 校验当地代理必填 |
| 费用 | CNIPA 作为受理局的申请进入中国时，申请费与申请附加费**免征** ⚠ | 费用规则分支 |
| 超项费 | 权利要求超过规定项数按项加收 ⚠ 单价与项数门槛按收费表 | 按权项数自动算 |

### 5.4 巴黎公约路径 vs PCT 路径

| 维度 | 巴黎公约直进 | PCT |
|---|---|---|
| 时间压力 | **12 个月内**必须逐国递交完毕 | 12 个月提交国际申请，**30 个月**再决定国家 |
| 前期成本 | 低（只缴目标国） | 高（多一道国际阶段费） |
| 国家多时的总成本 | 高（逐国翻译+代理，早付） | 较低（翻译与代理推迟，且可删减国家） |
| 灵活性 | 低（递交即承诺） | 高（30 个月内可反复评估） |
| 适用 | 目标国 ≤2、已确定、预算敏感、要快速授权 | 目标国 ≥3 或未定、需要融资/许可/市场验证时间 |
| 检索价值 | 无统一检索 | ISR 提供一次高质量预判 |

**产品落点**：这不是「哪个更好」，是**决策树**。系统应让用户输入「目标国数量 / 是否已定 / 预算 / 是否需融资」，输出推荐路径 + 三维对比表，并把选择理由留痕。

### 5.5 国家阶段进入的实务四件套

| 件 | 内容 | 失败后果 |
|---|---|---|
| **译文** | 说明书、权项、摘要译成该国语言并校对 | 译文错误导致权项范围缩小，且后续难以更正 |
| **代理委托** | 当地代理委托书（部分国家需公证/认证） | 无委托 → 不予受理 |
| **官费** | 申请费、附加费、实审费、超项费 | 逾期未缴 → 视为撤回 |
| **进入声明** | 申请号、进入国、修改情况、提前处理请求 | 声明错误 → 补正，甚至进入日争议 |

> **顺序很重要**：译文与委托是「进入手续」的组成部分，费用是「进入后」的义务。把两者混在一个截止日，是涉外案件最常见的操作事故。

### 5.6 与保密审查的关系（最容易出大事的一条）

**规则**：任何单位或个人将**在中国完成**的发明或实用新型向外国申请专利的，应当事先报经国务院专利行政部门进行保密审查。违反规定的，该发明在中国**不授予专利权**；已授权的构成**无效理由**（专利法第 19 条）。

**产品落点**：

- PCT 递交前必须有一个**不可跳过的检查项**：「本发明是否在中国完成？」→「是」则必须先取得保密审查结果。
- 这条对「外资企业在中国的研发中心」和「中国企业的出海」都是刚需，而市面工具几乎都不做。
- 审查通过后仍须记录审查结论与日期，因为无效程序里这是举证点。

**失效后果**：整族在中国的权利直接归零，且不可补救——这是 PCT 产品里**唯一一个会导致「全盘皆输」的检查点**。

### 5.7 多国年费：组合成本的真正大头

**规则**：进入国家阶段后，各国独立缴纳年费，档位、币种、缴费渠道、宽限规则全部不同；逾期 → 该国权利终止。

**产品落点**：

- `generateAnnuitySchedule(baseDate, years=5, startYear=1)` 当前只产出**单国、5 年、单一档位表**（`docketRules.ts:306-322`），且 `ANNUITY_FEES` 是示意值（`docketRules.ts:304`）。
- 多国化后，年费是「族 × 国 × 年」的三维表，且总额会随汇率波动。
- 这是 PCT 产品最容易被低估的价值：**客户真正怕的不是申请费，是 20 年 × N 国的年费失控**。

## 6. 状态机（建议）

### 6.1 族级状态

```
草案 ──► 已递交国际 ──► ISR 已收 ──► 已公布 ──► 国家阶段决策中 ──► 部分进入 / 全部进入 ──► 全族关闭
                            │                          │
                            └──► 放弃（未进任何国家）──┘
```

| 当前态 | 可迁往 | 谁做 | 业务含义 | 出口条件 |
|---|---|---|---|---|
| 草案 | 已递交国际 | 代理 | 国际申请已提交 | 有国际申请号 + 国际申请日 |
| 已递交国际 | ISR 已收 | 系统 | 检索报告到手 | `isrDate` 非空 |
| ISR 已收 | 已公布 | 系统 | 18 个月公布 | `publicationDate` 非空 |
| 已公布 | 国家阶段决策中 | 企业 | 开始逐国决策 | 每个指定国都有 `decision` |
| 国家阶段决策中 | 部分/全部进入 | 企业 + 代理 | 办理进入 | 至少一国 `entryDate` 非空 |
| 任意（进入前） | 放弃 | 企业 | 全族放弃 | 填理由 + 影响评估 |
| 全部进入 | 全族关闭 | 系统 | 全部权利终止 | 所有 `NationalPhase` 终态 |

### 6.2 国家阶段单国状态

```
未决策 ──► 决定进入 ──► 译文/委托准备 ──► 已递交 ──► 已受理 ──► 审查中 ──► 授权 / 驳回
   │            │
   └─► 决定放弃 └─► 逾期未办 ──► 权利灭失（不可逆）
```

| 当前态 | 可迁往 | 谁做 | 出口条件 |
|---|---|---|---|
| 未决策 | 决定进入 / 决定放弃 | 企业 | 有 `decision` + 理由 |
| 决定进入 | 已递交 | 当地代理 | 译文 + 委托 + 官费齐 |
| 已递交 | 已受理 | 该国局 | 有当地申请号 |
| 已受理 | 审查中 | 该国局 | 进入实审 |
| 任意（期限前） | 逾期未办 | 系统 | 期限过且无宽限或宽限亦过 |

### 6.3 当前实现的偏差

1. **只有一条规则、没有对象**：`pct_national_entry` 是扁平规则，无族、无国、无阶段。
2. **`graceMonths` 是死字段**：`computeDueDate` 只读 `months`/`days`（`docketRules.ts:120-127`），`graceMonths: 2` 从未被消费。**30 月与 32 月在系统里是同一个日期。**
3. **规则名叫「PCT 进中国」**，但被当成通用 PCT 期限用；seed `de7` 也是「进中国」，无法表达「进美国/欧洲」。
4. **`slaDefaultDays: 912` 与 `months: 30` 双轨**：912 天 ≈ 29.98 个月，而 `addMonths` 算出来可能是 913 天，两者会打架。
5. **无宽限费、无译文、无代理、无官方回执**任何字段。

## 11. 边界与失败场景

| # | 场景 | 正确处置 | 现状 |
|---|---|---|---|
| 1 | 客户在优先权日后第 13 个月才想起走 PCT | 无法主张优先权 → 改为直接申请并重新评估新颖性 | ❌ 无倒计时 |
| 2 | 中国研发的技术，直接向美国递交 | 保密审查前置 → 未过不得递交 | ❌ 无闸 |
| 3 | 第 30 个月当天才决定进欧洲 | 查该国是否允许宽限及宽限费 → 立即办理 | ⚠ 只有一条规则，无国别差异 |
| 4 | 某国译文交错了版本 | 立即提交更正译文，评估权项范围影响 | ❌ 无译文版本 |
| 5 | 指定了 15 国，实进 4 国 | 其余 11 国逐条记录「放弃 + 理由」 | ❌ 无放弃记录 |
| 6 | ISR 全是 X 类文献 | 触发「是否继续」决策会，考虑放弃或大幅修改 | ❌ 无 ISR 对象 |
| 7 | 客户在 30 个月内被收购，新股东要求缩减国家 | 决策可变更，但已进入的不可撤 | ❌ |
| 8 | 一国年费用当地货币缴，汇率波动 20% | 预算按汇率区间而非单点 | ❌ |
| 9 | 同名同族在两个系统里各建一次 | 族根唯一 + 幂等 | ❌ |
| 10 | 进入后 2 个月费用忘缴 | 该国视为撤回；查是否有恢复程序 | ❌ |
| 11 | 代理所说「PCT 已经授权了」 | 纠正：PCT 不授权，只出 ISR/IPER | ❌ 无教育性文案 |
| 12 | 客户要「PCT 专利证书」 | 说明不存在，证书由各国分别发 | ❌ |
| 13 | 优先权基础案在国内被驳回 | 不影响 PCT 国际申请（只要 12 个月内已提交） | ❌ |
| 14 | 一国进入失败，其余国正常 | 族视图须显式标红该国，不得整体静默 | ❌ |
| 15 | 客户问「走 PCT 还是巴黎公约」 | 按国数/确定性/预算/时间四维给决策树 | ❌ 只有一个复选 |

## 12. 指标（验收尺子）

| 指标 | 定义 | 健康区间 | 说明 |
|---|---|---|---|
| 优先权窗口命中率 | 12 个月内提交 PCT 的比例 | > 95% | 硬指标 |
| 国家阶段决策及时率 | 24 个月前完成全部决策的族占比 | > 90% | 留 6 个月缓冲 |
| 宽限使用率 | 用宽限进入的国家数 / 总进入数 | < 10% | 高 → 流程失控 |
| 进入失败率 | 逾期未进入 / 应进入 | 0% | 应为 0，非「越低越好」 |
| 单国进入周期 | 决定 → 递交 | < 15 工作日 | 效率 |
| 译文返工率 | 译文被当地代理退回修改的比例 | < 10% | 质量 |
| 族均国家数 | 每族实际进入国家数 | 3–8 | 过少=布局不足，过多=成本失控 |
| 族年费总额 | 每族每年年费合计（折人民币） | — | **能换算成钱** |
| 海外投入产出比 | 海外组合年费 / 海外许可+判赔收入 | < 1:3 | **能换算成钱** |

> 卖点时优先讲「进入失败率」（应为 0，一次失败就是一国权利灭失）和「族年费总额」（客户最容易被这个数吓醒）。

| L2 台账层 | 族/国际阶段/国家阶段三段台账 | 是 |
| L3 决策层 | 逐国进入决策 + 理由 + 预算 | 是（差异化） |
| L4 费用层 | 分国官费/翻译/代理 + 超项费 + 币种 | 是（财务买单） |
| L5 合规层 | 保密审查前置 + 译文/委托完整性 | 是（法务买单，护城河） |
| L6 年费层 | 多国多币种年费排期与组合汇总 | 依赖 05，但可独立售卖 |

**定价锚点**：按「族数」年费 + 按「进入国数」计价最自然；也可按「管理的国家阶段案卷数」。

**竞品参照系**：Anaqua / CPA Global 的 PCT 模块强在期限与年费代缴，弱在**保密审查与中文场景**；国内代理所系统强在流程，弱在**组合视图与费用预测**。**「中国保密审查 + 多国组合成本预测」是空位。**

**架构建议**：新建独立 `FlowKey = 'pct'`，**不新增 StageId**（PCT 是横跨 drafting→prosecution 的通道，硬塞进某个 Stage 会重演 08 的错误）。理由与 08 的「辅台」同一逻辑：它办理的是「一组案件」而不是「一个案件的一个阶段」。

## 14. 现状差距表（代码 vs 本文）

| # | 差距 | 严重度 | 影响 |
|---|---|---|---|
| 1 | 无 `PCTFamily` / `NationalPhase` 对象 | **高** | 整个节点无法建模 |
| 2 | 无 ISR / 书面意见 / 指定国字段 | **高** | 国际阶段完全空白 |
| 3 | `graceMonths` 从不参与计算 | **高** | 30 月与 32 月在系统里是同一个日期 |
| 4 | 只有一条「PCT 进中国」规则，无多国期限并发 | **高** | 进美国/欧洲无法表达 |
| 5 | 无保密审查前置闸 | **高** | 法律风险最高的缺口 |
| 6 | 无译文 / 委托 / 官费 / 超项费字段 | **高** | 进入手续不可办 |
| 7 | `generateAnnuitySchedule` 单国单档、只到 10 年 | **高** | 多国年费无法算 |
| 8 | 撰写台 `countries`/`pct` 只影响展示，不写库 | **高** | 布局→撰写的国别选择传不下去 |
| 9 | 与 08 `layout_insight` 无结构化对接 | **高** | 布局成果到不了 PCT |
| 10 | 无 `priority_deadline`（12 月）docket 规则 | 中 | 窗口无提醒 |
| 11 | 无 18 月公布 / 22 月第 II 章 docket 规则 | 中 | 国际阶段无节点 |
| 12 | `slaDefaultDays: 912` 与 `months: 30` 双轨可能不一致 | 低 | 差 1–2 天 |
| 13 | seed `de7` 的 `officialFeeHint` 是「约 ¥5,000+」示意 | 低 | 不可用于报价 |
| 14 | 无 PCT 角色、权限、审计 | 高 | 交付不可 |
| 15 | 无「PCT 不授权」的教育性文案 | 低 | 客户误解风险 |

**优先补的三件事**（按投入产出比）：

1. **`graceMonths` 真正参与期限计算 + 每国一条 docket**（差距 3、4）—— 改动最小、风险最高的一处；`computeDueDate` 加宽限计算即可先止血。
2. **`PCTFamily` + `NationalPhase` 两个对象**（差距 1、2、6）—— 没有对象就没有产品，但对象一旦建好，期限、费用、年费都能挂上去。
3. **保密审查前置闸**（差距 5）—— 唯一的「全盘皆输」检查点，也是面向外资/出海客户最有说服力的卖点。

## 15. 术语表

| 术语 | 含义 |
|---|---|
| PCT | 专利合作条约，统一国际申请程序，**不统一授权** |
| 受理局 / RO | Receiving Office，接收国际申请的机构（可为 CNIPA、WIPO 等） |
| 国际检索单位 / ISA | International Searching Authority，出具 ISR + 书面意见 |
| 国际初步审查单位 / IPEA | 第 II 章可选程序，出具 IPER |
| ISR | 国际检索报告，列引证文献（X/Y/A 类） |
| 书面意见 | 对新颖性/创造性/工业实用性的初步意见，无约束力 |
| IPER | 国际初步审查报告，比书面意见更进一步，仍无约束力 |
| 国际公布 | 自优先权日 18 个月公开，形成 WO 号 |
| 指定国 | 国际申请中指定的、希望获得保护的国家 |
| 国家阶段 | 在各指定国办理实际进入手续 |
| 宽限费 | 中国 30 月后至 32 月进入所需缴纳的附加费 ⚠ |
| 超项费 | 权利要求超过规定项数按项加收的官费 ⚠ |
| 保密审查 | 中国完成的发明向外国申请前须经 CNIPA 审查（专利法第 19 条） |
| 巴黎公约路径 | 不经过 PCT，直接逐国递交，须在 12 个月内完成 |
| 优先权日 | 最早基础申请的申请日，是所有 PCT 期限的锚点 |
