# 节点 00c · 专利挖掘（Mining）

> **业务规格**（产品级）。样机壳旁证见 [docs/architecture/mining/](../../architecture/mining/README.md)；专家席 `expert-mining` 见 [13-agents.md](13-agents.md) §9.2。  
> **必经分层**：业务上强烈建议（拆案/分级）；**可粗检**，**不替代** [01](01-research.md) 单案查新。  
> **捕获 Nc**：默认**不单列**，技术事实入池并入本节点上游入口 + [00](00-inventor-disclosure.md) 提报（⚠ 可改，见 spine §1.3.1）。  
> **日期**：2026-10-23（Asia/Shanghai）。业务不以原型为准。
> **编号**：本文件为 `00c-mining.md`；旧 id `Nm / RNm-` 已弃用，见 [README 节点编号约定](../README.md)。

## 0. 一句话讲清这个节点

**专利挖掘：把技术线索收成「申什么、拆几案、怎么分级」——不代替正式查新，也不在这里拍板立项。**

| | |
|---|---|
| **目的** | 少漏挖、少一案塞太多点；给出可解释的候选发明点清单 |
| **谁做** | 企业 IPR、代理所挖掘/提案顾问；发明人配合补事实 |
| **交出什么** | 候选点 + 评分/分级 + 拆案建议（`mining_pack`）；可带粗检示意 |
| **下一站** | 多数进 [00 交底](00-inventor-disclosure.md) 补齐；查新后才支撑 [02 立项](02-decision.md)。粗检 **≠** [01](01-research.md) |

### 白话摘要

回答「申什么」。不是激发（方向）、不是查新（能不能授权）、不是 08 组合布局、不是 02 的 Go/No-Go。捕获默认并入本站上游入口（Nc 不单列）。

产品化三条件：

| 条件 | 说明 |
|---|---|
| 独立买方 | 企业 IPR、代理所挖掘顾问 |
| 独立价值 | 给 02 可解释的候选池；减少重复挖 |
| 独立边界 | 出建议；D1/D2 只在 02；完整检索在 01 |


## 1. 节点定位与产品边界

### 1.1 位置

```
[00a 可选] → [捕获入口（并入）] → [00c 挖掘] → [00 交底完善] → [01 查新] → [02 立项]
                              │                ▲
                              └── 已有较完整交底时可并行/回流 ─┘
```

实务常见两条：

1. **线索型**：激发/捕获 → 挖掘拆点 → 再补交底（00）→ 查新  
2. **交底型**：已有交底正文 → 挖掘拆点/评分 → 查新 → 立项  

### 1.2 StageId / 路由 / 壳 / 产物键

| 项 | 值 | 现状 |
|---|---|---|
| StageId | 无；席位 `midStage: pre_intake` | ⚠ 非 StageId |
| 专家席 | `expert-mining` | ✅ |
| 样机壳 | `apps/mining` :5184 | ✅ |
| 产物键 | 提案 `mining_pack`（≠ `intake_quote`） | ❌ 未进 contracts handoff |
| 读工具 | `extract_invention_points` / `pack_mining` | ⚠ |
| 粗检 | 可消费 search Hit 作对照示意 | ⚠ 不替代 01 |

### 1.3 是 / 不是

| 是 | 不是 |
|---|---|
| 拆发明点、评分、排序、拆案建议 | D1 要不要申请 / D2 类型终裁（**02**） |
| 可粗检（示意 Hit） | 完整可专利性检索报告（**01**） |
| 送 00 补交底 / 送 02 候选 | 组合布局图（**08**） |
| 挖掘包 mining_pack | 立项报价 intake_quote |

### 1.4 上下游契约

| 方向 | 对象 | 契约 |
|---|---|---|
| ← 00a | 方向卡摘要 | 无评分 |
| ← 捕获/00 | 技术正文/提报草稿 | 可编辑 Disclosure 文本 |
| ← search | Hit 示意 | 只读对照 |
| → 00 | 需补强的点/缺口 | 不自动批准 disclosure_pack |
| → 02 | 候选点列表+评分 | **建议权**；须 01 后才能支撑 Go |
| → 01 | 点选后的单案主题 | 01 以交底+点为准重做检索 |
| → 08 | 多点组合线索 | 可选；08 出布局图 |

### 1.5 独立产品形态

| 模块 | 做 | 不做 |
|---|---|---|
| 拆点台 | 正文→候选点 | 写 PatentCase |
| 评分卡 | 多维假分/真模均可 | 假装已立项 |
| 送出桥 | 送 00 / 送 02 占位 | 替代 01 |

## 6. 状态机

```
empty → disclosure_ready → candidates_ready → scored → packed
                                              └→ sent_to_disclosure
                                              └→ sent_to_decision（建议，待 01）
```

| 当前态 | 可迁往 | 谁 | 出口条件 |
|---|---|---|---|
| empty | disclosure_ready | 人 | body 非空 |
| disclosure_ready | candidates_ready | 席/人 | ≥1 candidate |
| candidates_ready | scored | 席/人 | 每点有 ScoreCard |
| scored | packed | 人 | mining_pack 齐 |
| packed | sent_* | 人确认 | Intent |

**偏差**：样机内存；无 domain 枚举。
