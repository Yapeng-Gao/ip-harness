```
登录前宣传站（未登录；品类+七部货架+专家+场景）
```

## 2. 部门工作台统一布局

> **权威稿 · Leslie 定 Cursor 三栏（本轮 docs-only，Figma 月额暂停 / `f2e01fa`）**：**左目录 / 中产出物 / 右对话**；**需要人确定的都在右侧**；产品壳**浅色**（只借信息结构，不抄暗色）。结构以**本节 §2** 为准；观感以 [main-path-ui-design](../superpowers/specs/2026-10-23-main-path-ui-design.md) Frame 5 + 下方「视觉目标」为准。  
> **已锁 · 交卷·待你确认硬闸（vision §3.1a + [business-spine §3.3](business-spine.md) G1–G3）**：齐套不过不得标完成、不得进待确认；确认权跟人；无人确认不移交；过→移交 / 驳回→回流补齐。期限/账单后置，不抢本闸。  
> **作废**：「主区交卷清单 + 右钉专家」两栏（旧 §6.3a 钉栏部内形态）。公司总览仍 §4.3 网格+抽屉；部内作业见本节；确认页见 §4.11（铃铛多案待办仍保留；部内确认嵌右栏）。

所有部门工作台共用同一**三栏**骨架；**只换「左树节点 / 中产出正文 / 右栏专家与齐套缺项」**。

| 验收 | 口径（Cursor 三栏 + §3.1a + spine G1–G3） |
|---|---|
| **用户应感到** | 「像 Cursor：左点材料、中看产出、右对话确认；齐套不过右侧交卷点不动」 |
| **首屏结构** | **左·目录** · **中·产出物工作区** · **右·对话区**（专家协作 + 待你确认 + **交卷**）；顶栏公司壳常在 |
| **主 CTA** | **交卷**（**仅在右栏**）：齐套勾齐后可用 → **进入「待你确认」推进态**；**禁止**无决策「下一步」直进下一部门 |
| **不放什么** | 无交卷物装完成；齐套未勾齐仍可点交卷/进待确认；确认流跑到中间或顶栏别处；假指标/执行集群/工具引擎；抄暗色；专家采纳/起草人自批当确认；对外 Agent/Harness/Seat/HITL 黑话；AI 黑话目录名 |
| **上下页** | 上：公司首页「去当前部门」或点部抽屉「去该部干活」→ 本页 → 下：右栏确认或铃铛 §4.11（**过→移交**；**驳回→回流本台补齐**，可标回流） |

```
┌─ 顶栏（公司壳，浅色，常在）────────────────────────────────────────────┐
│ 案名 · 当前部门 · 铃铛(待确认) · 期限 · 回公司首页 · 更多/后勤            │
├─ 部门头（白话目标 · 本站在主链位置；无主交卷按钮——交卷在右栏）────────────┤
├─ 左·目录 ──────┬─ 中·产出物工作区 ────────────┬─ 右·对话区 ─────────────┤
│ 本案/本部门     │ 当前选中的产出正文            │ 专家协作对话（≤3+头像）   │
│ 材料树：        │ （交底/报告/权项…可滚动长文）  │ 建议稿 · 采纳 ≠ 确认     │
│ 交卷物节点      │ 与当前产出相关的齐套勾选可附   │ 缺项列表（G1 可见）       │
│ 附件 / 版本     │ 旁，不抢中间阅读               │ 【交卷】主 CTA（G1）     │
│ 点选 → 决定中栏 │ 不在此放确认/交卷主按钮         │ 待你确认条（过/驳回）     │
│                │                              │ 回流/驳回意见；回公司/换部 │
└────────────────┴──────────────────────────────┴──────────────────────────┘
```

| 区块 | 必须展示 | 规则 |
|---|---|---|
| 顶栏 | 案、当前部门、铃铛、期限；可回公司首页 | 浅色壳；不丢「公司」语境；**不**在顶栏放交卷主 CTA |
| 部门头 | 白话目标 + 主链位置 | 一屏知道本站干什么；交卷不在此 |
| **左·目录** | 本案/本部门材料树（交卷物节点、附件、版本） | 点选决定中栏；禁 AI 黑话目录名 |
| **中·产出物** | 当前选中产出的权威正文（编辑/预览） | 对 L1 SKU / 节点产物键；可滚动；齐套勾选可挂相关项旁，**不抢阅读** |
| **右·对话区** | 专家协作 + 缺项 + **交卷** + 待你确认 | **人确定的全在右**；G1 交卷灰且点不动；G2 采纳≠确认 |
| 回流 | 驳回意见落右栏（可标回流） | **G3**：驳回→回流当前部补齐 |

**页行为硬闸（必须兑现；对齐 vision §3.1a + spine §3.3 G1–G3）：**

| # | 页行为 | 禁止 |
|---|---|---|
| **G1 齐套闸** | **一部门一交卷**：齐套清单未勾齐 → **右栏**交卷 CTA **灰且点不动**（缺项在右栏明示）→ **不得**标「部门完成」→ **不得**进入「待你确认」推进态 | 灰了还能点；空材料装完成；未齐套溜进待确认；交卷按钮放中栏/顶栏 |
| **G2 确认权** | 确认人 = 发明人 / 代理人 / 企业负责人等真实主体；专家只有建议权；右栏「采纳建议稿」≠确认 | 专家采纳当拍板；**起草人自批自己的交卷**；「AI 已通过」当确认 |
| **G3 确认决策** | 无人确认 → **不得移交下一部门**，**不得**装成已递交 / 已立项；**过 → 移交**；**驳回 → 回流当前部补齐**（可标回流） | 跳过确认换部；无人确认改法律相关状态；无决策「下一步」 |

**演示优先段（spine）：** 至少交底→查新→立项（00→01→02）三段硬闸可走通；齐套未齐或无人确认必须挡在部门台右栏 / 确认页。

**右栏 MVP 禁放：** 假指标、执行集群、工具引擎卡；以及把右栏做成「第二阅读台 / 监控大屏」的堆砌（右栏是对话+确认，不是第二中栏）。

**移动端：** 顶栏压缩；左目录改为可收起抽屉；中栏仍为产出正文；右栏（对话+交卷）改为底部抽屉或全屏叠层；交卷固定在确认区（未齐套仍禁用）。

**未齐套：** 右栏「交卷」**灰且点不动**，并列出缺项名（业务口径；实现债另见 working 债清单）。

### 4.0p 登录前宣传站（品类 · 货架 · 场景 · 非干活）

> **状态：已锁 · Leslie 2026-10-23 拆两层 · 对齐 vision §3.3 A**。  
> **本页 = 登录前官网式宣传站（获客另做）。** **不在**登录后产品信息架构内；可另开营销站/独立路由。承担品类 + 货架（七部 + 专家 + 场景）。登录后干活入口见 §4.0a **薄入口**。  
> **STOP** 把本页整页复制成登录后 `/agent`；在本页交卷/齐套/拍板；要求登录才能看懂品类。

| 字段 | 内容 |
|---|---|
| **逻辑路径** | 未登录默认可达（实现路由由 Agent壳定：如独立 `/welcome`、未登录根路径等；**须**未登录可打开） |
| **谁用** | 未登录访客；样机演示前 |
| **目的** | 一眼看懂品类与货；点主 CTA 去登录/进入 |
| **用户应感到** | 「这是外挂 IP 部 / 办专利全流程；七部与专家长这样；场景对得上我；要干活先登录」 |
| **角色边界** | **本页=宣传/认知**；会话与作业在登录后 |

### 4.0 登录

| **不放什么** | 无决策含义的「下一步」；起草人自批 / 专家自批；空材料装通过；无人确认推进下一部门或装成已递交/已立项；不可逆无责任提示；Agent/HITL 黑话 |
| **上下页** | 上：部门台**齐套勾齐后交卷**（G1）→ **本页（待你确认）** → 下：**过→移交**（回公司首页或下一部门工作台）；**驳回→回流当前部补齐** |
| **空态** | 「暂无待确认」+ 回公司首页 / 产品首页待确认入口 |
| **硬闸** | ① **G3**：过→移交；驳回→回流补齐（可标回流）。② **无人确认 → 不得移交下一部门**，**不得**装成已递交 / 已立项（当前部门卡住可见）。③ **G2**：专家建议稿 / 起草人自批 **≠** 确认；确认权跟人。④ 未齐套材料不可经本页装「通过」（入口侧 G1 已挡）。⑤ 不可逆法定动作须责任提示。⑥ 截图不能把未确认案子读成已办完。 |
| **产品逻辑** | L2 交接；vision §3.2 #5 + **§3.1a**；[business-spine §3.3](business-spine.md) G2–G3；节点 [10](nodes/10-handoff-state-machine.md) |
