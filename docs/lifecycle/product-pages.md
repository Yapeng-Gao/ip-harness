### 1.1 三档导航可见性（真行为 · 对齐 vision `2ffbb7d` §3.1d）

> **变更理由（跟齐 vision `2ffbb7d` · Leslie 改口）**：覆盖 `031c412`「禁专业工作室另页 / 专业=同面加密度」。顶栏切「专业」须**一眼能跟「项目」分开**；可见差 = **换面**（项目作业面 vs 专业能力面），**作废**仅靠卷宗/案盘/三栏密度冒充。仍只留**顶栏**三档；仍**禁**侧栏双入口 / MCP·Prompt·Skill 墙 / 橙皮。  
> 三档 = **同一案子底座**的使用深度；入口**仅在顶栏**切换。截图须能分出真行为差，**不是**换皮标签，**不是**三套产品壳。不改事实库与确认权。

#### 专业 vs 项目 · 可见差原则

| | **项目**（干活默认） | **专业**（能力/编制） |
|---|---|---|
| **面的类型** | **作业面**：公司首页七部认知锚 + **工作台 Cursor 三栏**干活 | **能力面**：着陆 **专业部门页**（七部能力与专家编制 · 可看可配） |
| **用户主对象** | 本案当前部门 / 本节点交卷 | 各部门「能干什么、谁在岗、怎么配」 |
| **禁止用什么冒充差** | — | **禁止**仅靠「同底座更深密度 / 卷宗更满 / 案盘加重」冒充专业档 |

#### 三档真行为

| 档 | 真行为（可见性） | 边界 |
|---|---|---|
| **助手** | **藏**侧栏与部门地图（七部墙弱化/收起）；以**顾言**+轻量事项为主；公司网格可弱化、可按需唤回 | 不另开产品壳 |
| **项目** | **日常干活默认**：公司首页 + **工作台**（一屏三栏）；持续委托链完整可走 | 默认上手；**不**进专业部门页当作业面 |
| **专业** | 顶栏切过来 → **着陆专业部门页**（§4.3a）；代理默认可偏此档看编制 | **不是**工作台加密度；**不是**第二套产品壳 |

**入口规则：** 只留**顶栏**助手 / 项目 / 专业；**禁止**侧栏再开「专业工作室」第二全局入口（不抄 Kimi 双入口）。  
**专业部门页（§4.3a）：** slug `/cases/:id/professional`；主入口=顶栏「专业」；次入口=公司首页弱链「看专业能力 / 编制」；CTA「去该部干活」→ 切回**项目**档并进该部三栏作业台；**禁**在本页改文书；**禁** MCP 墙。  
**公司首页 §4.3：** 七部网格仍是**进度/导航**认知锚；与专业部门页**两页分工**，不合并成一张糊墙。  
**主路径 hops：** 专业部门页**不进** 宣传→登录→薄入口 第一屏；从顶栏/公司弱链进入。配看编制进主壳能力面，**不是**后置另面。  
**明确不抄：** 侧栏双入口、MCP/Prompt/Skill/测试发布配置墙、橙皮、用工作室替代作业台、在专业部门页改交卷正文。

> 逐页验收字段统一为：**目的 · 用户应感到 · 首屏三块 · 主 CTA · 不放什么 · 上下页**。禁区全文见路径图。

## 2. 工作台统一布局（对外称「工作台」）

> **交互归属（vision `723f9d2`+`66a64d2`）**：**顾言**=入口·路由·跨部接力（工作台内**弱入口**：换部/改目标；**非**部内主聊伴）；**部门**=本站执行主对象（进部后用户主对象=**本部门/本节点**）；**专家**=≤3 建议稿、右栏可交互折叠；**你**=确认权（**工作台右栏**通过/驳回；G1 齐套→交卷→同屏待你确认；**废**单独确认页）。  
> **已锁 · 交卷·待你确认硬闸（vision §3.1a / `66a64d2` + [business-spine §3.3](business-spine.md) G1–G3）**：G1–G3 **业务口径不变**；**体验落点**改右栏——齐套不过不得标完成、不得进待确认；确认权跟人；专家建议稿 ≠ 确认；**质检 ≠ 确认权**；无人确认不移交；**过→下一部** / **驳回→本台补齐或退回上一部**（可标回流）；中栏须先见交卷物正文（**禁盲确认**）。铃铛深链回本台右栏闸，**不**另开确认页。期限/账单后置。  
> **作废**：「主区交卷清单 + 右钉专家」两栏；**独立确认页 / `/pending` 主路径 hops**（旧 §4.11 页职责并入本节右栏）。公司总览仍 §4.3 网格+抽屉；部内作业+拍板见本节。

### 2.0 交互归属（顾言 · 部门 · 专家 · 你）

> 对齐 vision `723f9d2`+`66a64d2` §3.1c / §3.1a。硬闸 G1–G3 **业务口径** / 薄入口 hops / 七部投影**不动**；拍板**体验落点**=工作台右栏。

| 角色 | 管什么 | 不管什么 |

| **顾言（知产负责人）** | 听目标、计划可调、**分发/路由到部门**、跨部接力；工作台内**弱入口**（换部 / 改目标，可挂顶栏或右栏一角） | 部门内改文书时的**主聊伴**；替代本站执行；替代确认权 |

### 2.1 节点工作契约（各部共用骨架）

> 对齐 Kimi「本节点工作契约」+ vision 部门「输入契约 · 交卷」。**各部共用契约字段骨架**，只换交卷物 / 齐套 / 专家（见 §4.4–4.10 导语）。落在部门头或右栏**折叠**契约区，一屏可读。

| 字段 | 口径 |
|---|---|
| **负责部门** | 当前部 |
| **输入依据** | 本站读取的事实 / 证据 / 已确认决策（权限内继承，**非**全量上下文） |

| **布局** | §2 三栏；中栏=事件与手续清单；右栏=对话+齐套缺项+交卷 + 专家；明显链回维持部 |
