# 行业真实业务逻辑对照（专利全生命周期 · 补遗）

> 2026-10-19 · 本篇是 [README.md](../README.md) 节点文档的**法规/行业补遗**：把每个「demo 节点」映射到真实法规下的**期限 / 费用 / 程序 / 失败模式**。
> 权威源永远是法条，本篇是**对照地图**；冲突以法规原文为准。

## 0. 怎么读本篇

- **稳定**（可放心写进 docket）：法定期限、程序关系、宽限/终止语义、权利保护期 —— 这些是法条或审查指南，短期不变。
- **需复核**（写进 docket 前要按当年 CNIPA 收费表核对）：官费金额、减缴比例、滞纳金档位。⚠️ 标注。
- **demo ↔ 真实**：每个节点给出「样机现在建模了什么 / 行业真实还要什么 / 差距」。

## 2. 法定「硬规则」速查（可直接进 docket）

### 2.1 保护期限（`grant` 后决定年费循环长度）
- 发明：**20 年**（自申请日起）· 实用新型：**10 年** · 外观设计：**15 年**（2021 起，此前 10 年）。
- 样机 `ANNUITY_FEES` 只到第 5 年 —— 真实要覆盖到 20/10/15 年，且外观专利档位不同。

### 2.2 年费与滞纳金（节点 05 · 最该补的硬数据）
- 每年年费须于**申请日周年**前缴纳；**授权当年**登记后缴第 1 年。
- 滞纳：**6 个月宽限**，宽限内补缴须付**滞纳金**；超过 6 个月专利权**终止**（lapse）。
- 滞纳金计算：按**逾期月数**阶梯（每满 1 月加收当年年费的一定比例），非固定百分比。⚠️ 具体档位以《收费办法》复核。
- 真实规则：`annuity` 规则应挂 `+6grace` + `+滞纳金` + `终止` 三态，样机现在只有「12 月 + 6 月宽限」两步。

### 2.3 实质审查请求（节点 03 前置 / 09）
- 发明须自**申请日起 3 年**内提实审请求 + 缴费，否则申请**视为撤回**。
- 样机 `substantive_exam_request` = 36m（与法规一致，✅）。
- 说明：实用新型/外观**不走实审**（只初审）—— 样机只按发明建模了。

### 2.4 OA 答复期限（节点 04）
- **第一次**审查意见：一般 **4 个月**（自通知发文日/推定收到日起）。
- **后续**审查意见：**2 个月**。
- 均可**延期**（缴延期费，通常可延 1–2 个月）；**逾期不答复 → 申请视为撤回**。
- 样机 `oa1_response=4m / oa_subsequent=2m`（✅ 已对齐），缺「延期费」和「视为撤回」两态。

### 2.5 授权登记费（节点 03 → 05 之间）
- 收到**授予专利权的通知书**后须在规定期限内缴**登记费 + 第 1 年年费**，逾期**视为放弃**取得专利权。样机 `grant_registration=2m`（需与当期法规核对，⚠️）。

### 2.6 恢复权利（样机完全没有的分支）
- 因**正当理由**（不可抗力/正当延误）在期限恢复前，当事人可请求**恢复权利**（通常自收到终止/撤回通知起 2 个月内）。
- 这是节点 05 之外、04 之内真实存在的「救活」路径 —— 样机没有建模（缺口 4 的近亲）。

### 2.7 优先权（节点 09 的核心）
- 巴黎公约/PCT：**发明专利 12 个月**优先权（实用新型/外观 6 个月）。
- 优先权决定 PCT 国际申请日、各**国家阶段进入期限**（多数 30 个月 / 部分 16 个月）。样机 `pct_national_entry=30m`（✅ 常用口径，需按具体缔约国复核）。

### 2.8 无效宣告（样机完全没有的独立程序）
- **授权后**任何人均可向 CNIPA 专利局请求**无效宣告**（无次数限制，直到权利终止）。
- 无效宣告决定**中止**相关程序（审查/维权诉讼可中止等待无效结果）。
- 样机把「无效/异议」当缺口 1，本篇补上它的真实位置：**prosecution 之后、commercialization 前后都可能被触发**。
- **完整规格**：[nodes/22-invalidation.md](nodes/22-invalidation.md)（法定理由、证据规则、两造状态机、追溯力）。

### 2.9 职务发明奖酬（节点 00 · 2023 细则新增口径）

- **约定/规章优先**（细则第九十二条）：单位可以与发明人、设计人**约定**，或在**依法制定的规章制度**中规定专利法第十五条奖励、报酬的方式和数额；国家鼓励股权、期权、分红等产权激励。
- **法定兜底**（细则第九十三条）：无约定也无规章时，应自**授权公告日起 3 个月内**发放奖金；发明专利**不低于 4,000 元**，实用新型或外观设计**不低于 1,500 元** ⚠️。发明创造源于发明人建议被采纳的，应从优发给。
- **报酬**：细则已不再规定固定比例（2010 版「营业利润 2%/0.2%、许可费 10%」等已删除）；无约定时实务多参照《促进科技成果转化法》给予合理报酬 ⚠️。
- **样机差距**：无奖酬台账、无「授权公告日 + 3 个月」docket、无「约定 vs 法定」判定。

### 2.10 新颖性宽限期（节点 00 · 专利法第二十四条）

- 申请日以前 **6 个月**内，下列情形**不丧失新颖性**：①国家紧急状态/非常情况下为公共利益首次公开（2020 修法新增）；②中国政府主办或承认的**国际展览会**首次展出；③**规定的学术会议或技术会议**首次发表；④**他人未经同意泄露**。
- **程序**：须在**提出申请时于请求书中声明**，并自申请日起 **2 个月内**提交证明材料；申请日前已知晓他人未经同意泄露的，应在知晓后 2 个月内提交声明。
- **认知要点**：宽限期是**补救**而非许可——它不意味着「6 个月内申请就行」，而是「已公开还能救，但要声明、要举证、且只救这 6 个月」。
- **样机差距**：`riskDate` 只用于 `risk='高'` 与 `nextDeadline`，无倒计时、无声明流程、无「属于四类情形中哪一类」的判定。

### 2.11 保密审查（节点 00 / 09 · 专利法第十九条）

- **规则**：任何单位或个人将**在中国完成的**发明或实用新型向外国申请专利的，应当**事先**报经国务院专利行政部门进行保密审查。
- **后果**：违反规定向外国申请后再在中国申请的，**不授予专利权**——并构成无效宣告理由。
- **判断要点**：先直接去国外申请可以，但前提是先在中国提交并完成保密审查并获准。
- **样机差距**：交底与 PCT 节点均未采集「是否有海外申请计划」「技术是否在中国境内完成」，无硬阻断。

### 2.12 非正常申请（节点 00 · 局令第 77 号，2024）

- 承接 2021 年《关于规范申请专利行为的办法》，现行依据为《规范申请专利行为的规定》（国家知识产权局令第 77 号）。
- **典型情形**：多件内容明显相同；明显抄袭现有技术/设计；不同材料、组分、配方、部件、结构或步骤的**简单替换、拼凑**；**编造、伪造、变造**发明内容/实验数据/技术效果；发明创造与申请人、发明人的**实际研发能力及资源条件明显不符**。
- **审查程序**：受理、初审、实审、复审及 PCT 国际阶段均可启动专门审查；被初步认定后可提交意见陈述并附证明材料申诉。
- **产品落点**：这是「禁止空材料装完成」的产品纪律的法律根据；KPI 不能只考核申请量。

### 2.13 企业知识产权合规体系（GB/T 29490-2023）

- 《企业知识产权合规管理体系要求》（GB/T 29490-2023）2023-08-06 发布、2024-01-01 实施，替代 2013 版「管理规范」；**推荐性**国标，是否认证取决于客户/合同/项目要求。
- 对**立项、研发、采购、生产、销售、售后**各环节提出 IP 管理要求；立项环节要求对项目涉及的 IP 进行分析（检索、侵权风险）。
- **产品落点**：交底与检索流程是认证证据链的一环；面向国企/上市公司的销售支点。

## 3. 逐节点「行业真实 vs 样机」对照

### 00 发明人披露（in-house pre-filing）
- **真实**：企业 IP 部门的**书面发明披露单**（IP disclosure form），含 技术构思 / 发明点 / 现有技术 / 发明人 / 职务发明认定 / 保密标记；触发**新颖性丧失前的保密义务**（自公开 6 个月新颖性宽限是法定例外，不是常规）。
- **真实规则要点**：披露单是**职务发明权属**与**优先权日**的起点；发明人报酬（《专利法》报酬规定）与披露绑定。
- **样机差距**：样机 `disclosure_pack` 建模了 6 项齐套 + 7 态，很接近；缺「职务发明认定」「发明人报酬」「保密义务触发新颖性宽限」。

### 01 调研 / FTO（pre_research）
- **真实**：查新检索（novelty search，申请前）+ **FTO 检索**（freedom-to-operate，上市前）；检索数据库 = 商业（IncoPat/智慧芽/Derwent）+ 官方（CNIPA/USPTO/EPO/ESPACenet）；结论 = 风险分级（非阻断/中等/高阻断）+ **claim chart（权利要求对照表）**。
- **真实规则**：FTO 结论是**商业决策**依据（上市/规避设计/许可谈判），不是法律意见；**先有检索报告再立项/上市**。
- **样机差距**：样机 `research_report` + `hits_verifiable`（pubNo 正则）已含检索可验证 + claim chart 草稿；缺「检索式（CPC/IPC 分类号）沉淀」「规避设计结论回写产品」。

### 02 立项决策（Go/No-Go）
- **真实**：**可专利性**（novelty/inventiveness）× **商业价值**（市场/竞品/回报）双维，常配**评分矩阵** + 委员会/管理层决议；产出 Go / No-Go / 有条件 Go。
- **真实规则**：No-Go 常有**复议/重新提案**通道；预算/代理费档在立项时锁定。
- **样机差距**：样机 `go_nogo` + 委员投票 + `intake_quote` 已建模；缺「No-Go 复议」「预算档锁定」「代理费报价单」。

### 03 撰写申请（drafting）
- **真实**：**权利要求书**（独立 + 从属，层级引用）+ 说明书（背景/技术方案/实施例）+ 摘要/附图；**国别策略**（PCT 路径 / 直接进入各国）+ 优先权标记；**官费 + 代理服务费**报价。
- **真实规则**：权利要求的**保护范围**是核心资产，撰写决定后续维权边界；国别/优先权选择影响后续成本与保护期；提交后 18 个月公开（PCT/各国）。
- **样机差距**：样机 `draft_claims` + 5 项 filing_check + 国别费率（示意）已建模；缺「权利要求树层级校验（从属引用完整性）」「18 个月公开时点」「代理费档位（非仅官费）」。

### 04 审查答复（prosecution）
- **真实**：对 **OA（审查意见通知书）** 逐争点（新颖性/创造性/清楚性/支持）答复 + **权利要求修改**（限缩）+ 意见陈述；可能一审/二审多轮；**延期费**延长答复期；逾期视为撤回。
- **真实规则**：答复策略 = 「争辩（维持）」vs「修改（限缩）」vs「分割申请」的组合；每轮 OA 都有硬期限（§2.4）；**分割申请**（divisional）是真实分支，样机没有。
- **样机差距**：样机 `oa_meta`/`oa_statement` + `claimAmended` 已建模；缺「多轮 OA 轮次对象」「分割申请」「延期费档位」。

### 05 授权维持（maintenance）
- **真实**：授权登记费 + **逐年年费循环**（§2.2 滞滞纳/终止）+ **权利状态管理**（生效/终止/恢复）+ **价值分层**（哪些专利续、哪些放弃）。
- **真实规则**：年费是**持续成本中心**；企业常做**专利组合价值评估**决定续缴/放弃（portfolio management）；终止后有**恢复权利**窗口（§2.6）。
- **样机差距**：样机 `pay_unlock` + `ANNUITY_FEES`（到第 5 年）建模了缴费闸；缺「20/10/15 年全周期」「滞纳金阶梯」「放弃/恢复双分支」「组合价值评估驱动放弃」。

### 06 运用转化（commercialization）
- **真实**：路径 = 自实施 / **许可（独占/排他/普通）** / **转让** / 入股 / **维权诉讼**；许可需**备案**（许可合同登记），费率（royalty）对标行业；转让需**登记**生效对抗第三人。
- **真实规则**：许可/转让都走**著录项目变更 + 登记**；维权 = 取证 + 发函 + 诉讼（§2.8 无效可中止诉讼）；「薄法务审」在真实业务是**合同审阅 + 法务签字**，样机已标注非 e-sign。
- **样机差距**：样机 `monetize_terms` + `legal_review` + 诉讼灰化 已建模；缺「许可备案/转让登记」「royalty 对标模型」「取证/发函子流程」。

### 07 监控预警（monitoring）
- **真实**：**IP watch**（竞品/侵权/到期/技术演进）+ **docket**（官方期限）双轨；告警 = 竞品专利、侵权风险、年费到期、无效威胁；触发**建案/升级/标记**决策。
- **真实规则**：官方期限（docket）与业务监控（watch）是**两条线**，样机已正确分开；升级 = 建 FTO/维权案。
- **样机差距**：样机 `watch_alert` 双轨 + 建案 已建模；缺「竞品专利族展开」「无效威胁专项」。

### 08 布局（layout · 辅台）
- **真实**：**专利组合/技术布局**（landscape + 空白点分析 + 国别布点），是**前瞻性**的，不挂具体案件流程；输入常来自调研（landscape）。
- **样机差距**：样机把它当辅台（无 StageId，读 `layout_insight`）是合理的；真实企业布局常独立成「专利战略」职能。

### 09 PCT / 国际（样机 = 缺口）
- **真实**：PCT 国际申请（自优先权 12 个月内）→ 国际检索报告（约 16 个月）→ **国家阶段进入**（自优先权 30 个月，各国 2 个月宽限）；**多国**各自期限/费用不同；是**多国保护的标准路径**。
- **样机差距**：样机只有 `pct_national_entry` 一条 docket + 1 个 seed（见 [09-pct-international.md](nodes/09-pct-international.md)）。真实需要：**PCT 申请日**、**国际检索**、**国家阶段多国矩阵**（每国独立 docket + 费用），是最大的一块待建。

## 4. 横切线补遗

### 10 交接状态机
- 样机 7 态（drafting→…→filed）是**企业内工作流**口径。真实法律事件是**提交/受理/公开/授权/终止**几个官方态；样机把「官方态」藏在 docket 里是对的。补：官方受理日/公开日/授权日应作为**不可逆**锚点写回案件时间线。

### 11 docket 引擎
- 样机 7 规则 + 4 级升级已不错。补法规锚点：
  - `application_fee`（缴费期限 2 个月 + 15 日）、`substantive_exam_request`（36m，§2.3）✅
  - `oa1/oa_subsequent`（4m/2m，§2.4）✅ + 补「延期费」子规则
  - `grant_registration`（§2.5）⚠️ 核
  - `annuity`（§2.2 滞滞纳/终止三态）需扩
  - `pct_national_entry`（30m+2grace，§2.7）✅ + 补「各国矩阵」
  - 缺 `divisional_request`（分割申请）、`priority_deadline`（优先权 12m）、`publication_18m`（公开时点）

### 12 商务/发票
- 样机 `pay_unlock` + `invoiceBlocked` 反卡递交，商业逻辑对。补真实：**官费（CNIPA 收）与代理服务费（律所收）是两条账**；年费官费有**减缴**（单位 70%/个人 85%，⚠️ 核）；**发票合规**（先开票后付款/对公）影响 `pay_unlock` 的前置。

### 13 Agent 编成
- 样机 9 Agent × 18 席 是演示层。补真实分工：**检索/FTO（咨询或外部）、撰写（代理律师）、OA（代理人）、年费/docket（专利运营/IPR）、无效/诉讼（律师团队）** 是真实角色边界；样机的 tier（core/beta/assist）对齐了「核心=代理+审查、辅助=运营、灰=战略」的成熟度。

## 5. 建议补进样机的 4 类「真实规则」

| 类别 | 具体 | 落到哪 |
|------|------|--------|
| **期限扩** | 滞纳金阶梯 / 终止 / 恢复权利 / 延期费 / 分割申请 | docket（11）+ 05 + 04 |
| **多国** | PCT 国际检索 + 国家阶段多国矩阵（每国独立 docket+费） | 09（新建 Flow） |
