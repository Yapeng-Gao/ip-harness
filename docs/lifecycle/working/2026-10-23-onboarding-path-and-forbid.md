## 路径图

```
（未登录宣传站 · 官网）→ 登录
  ↓
产品首页 /agent          ← 人人；薄入口（主 CTA ·「现在需要我处理」）；宣传货架在登录前官网
  ├─【代理】主 CTA → 多案流水（案盘）→ 点进某案
  └─【企业】主 CTA → 开案子（无案）或 公司首页（有案）
                         ↓
                   公司首页（一案一公司）
                         ↓
              七部工作台（交底→…→答复；对外勿称「部门台」）
                         ↓
         齐套交卷 → 同屏右栏通过/驳回（废独立确认页）
                         ↓
         过 → 下一部工作台；驳回 → 本台补齐或退回上一部
                         （铃铛仅提醒，深链回工作台右栏闸）
```

核心理念贯穿：**尽快把专利申下来**；宣传站 H1=**虚拟知产公司**（VIRTUAL），**外挂知识产权部**仅手段/品牌副标（公司 / 部门 / 专家 / 交卷·待你确认）。对外禁用 Agent / Harness / 智能体编排。

## 全局禁区（实现自检）

1. **禁止**登录后无真正产品首页（仅 Redirect 不算有首页）。  
2. **禁止**用一张页 + 权限开关冒充代理/企业双角色。  
3. **禁止**产品首页与公司首页抢戏（跨案理念叙事 vs 案级 IP 部）。  
4. **禁止**「总工作台」承载部门作业或万能功能堆。  
5. **禁止**默认导航十二部一屏；更多部门折叠。  
6. **禁止**对外文案出现 Agent / Harness / 智能体编排 / Seat / HITL。  
7. **禁止**无人确认就装成已立项 / 已递交。  
8. **禁止**登录后 `/agent` 堆货架/七部/专家宣传（属登录前站）。  
9. **禁止**把未登录官网整页复制成登录后首页。  
10. **禁止**产品首页放部门地图作业或 Agent 目录。  
11. **禁止**独立确认/pending 页充当主路径拍板；铃铛须深链工作台右栏闸（vision `66a64d2`）。  
12. **禁止**对外再称作业面为「部门台」（正确=**工作台**）。
