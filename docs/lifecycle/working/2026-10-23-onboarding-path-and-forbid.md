## 路径图

```
登录
  ↓
产品首页 /agent          ← 人人；薄总览（定位 · 角色主 CTA · 待确认）
  ├─【代理】主 CTA → 多案流水（案盘）→ 点进某案
  └─【企业】主 CTA → 开案子（无案）或 公司首页（有案）
                         ↓
                   公司首页（一案一公司）
                         ↓
              七部部门工作台（交底→…→答复）
                         ↓
                   确认页（铃铛）
                         ↓
              回公司首页 或 下一部门工作台
```

核心理念贯穿：**外挂 IP 部**（公司 / 部门 / 专家 / 交卷·待你确认）。对外禁用 Agent / Harness / 智能体编排。

## 每一跳：应感到什么 / 禁止什么

| # | 页 | 用户应感到什么 | 禁止什么 |
|---|---|---|---|
| 0 | 登录 | 选角色，进外挂 IP 部 | 无首页直跳；同页滤权限冒充双角色；营销页当登录后首页 |
| 1 | 产品首页 `/agent` | 这是外挂 IP 部；主按钮清楚；有待确认 | 部门作业堆；空总工作台抢戏；替代案盘/公司首页；Agent 目录墙 |
| 2a | 多案流水 | 案子清单：卡点 / 待确认 / 期限 | 企业单案陪跑壳；七部作业；无案名就进深页 |
| 2b | 开案子 | 极少字段立业务线 | 长表单；直进交底 Word；跳过公司首页 |
| 3 | 公司首页 | 本案 IP 部；当前部门；点部门才见专家；去当前部门 | 直进交底表；十二部全开；专家花名册墙；第二套产品总览 |
| 4 | 七部工作台 | 交卷物 · 齐套 · ≤3 专家建议 · 交卷 | 空材料完成；>3 岗变目录；无公司顶栏 |
| 5 | 确认页 | 拍板（过/驳回有决策含义） | 「下一步」退化；自批；空材料通过；不可逆无责任提示 |

## 全局禁区（实现自检）

1. **禁止**登录后无真正产品首页（仅 Redirect 不算有首页）。  
2. **禁止**用一张页 + 权限开关冒充代理/企业双角色。  
3. **禁止**产品首页与公司首页抢戏（两页职责不同：跨案薄壳 vs 案级 IP 部）。  
4. **禁止**「总工作台」承载部门作业或万能功能堆。  
5. **禁止**默认导航十二部一屏；更多部门折叠。  
6. **禁止**对外文案出现 Agent / Harness / 智能体编排 / Seat / HITL。  
7. **禁止**无人确认就装成已立项 / 已递交。
