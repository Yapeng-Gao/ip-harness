## 1. 目标与成功标准

把「**外挂知识产权部**」从结构正确推到**一眼像在办事**，并兑现 Kimi 结合的理念 / 产品逻辑（不只壳感）：

| 成功 | 失败 |
|---|---|
| 研发/代理人不学编排黑话也能回答：现在在哪个部门、交卷齐了没、谁该确认 | 像 Agent 目录、仪表盘假指标、灰按钮仍可点 |
| 交卷闸 / 确认权在 UI 上不可绕过（G1–G3） | 装饰性「下一步」、专家自批冒充确认 |
| 浅色、克制、按压与焦点可感 | 暗色皮、堆动画、无 focus-ring |
| **截图能分出企业简版 vs 代理卷宗，且同部门路由模板**（两工作台 B） | 两套产品壳、空总台 |
| **薄入口 = 一主 CTA +「现在需要我处理」轻量轨**；持续委托链可点通 | 三卡平铺、跨案经营台、只 toast |
| **三档真行为**（助手藏侧栏与部门地图；项目日常；专业工作室占位） | 三档仅换皮标签 |
| **确认后交付快照可见**；四类确认类型标签露出 | 黑箱过闸；把类型标签升级成新硬闸 |

## 2. 浅色设计语言（纸感 · 对齐 Kimi token）

| Token / 规则 | 取值 | 理由 |
|---|---|---|
| 品牌句 | **外挂知识产权部**（钉死；品类可称虚拟知产公司，不顶替品牌句） | vision / combine |
| 底 | `--paper` / `--warm-paper`（oklch 纸白 / 暖纸） | 办公纸感，非消费炫彩、非暗色 OS |
| 字色 | `--ink` / `--ink-2` / `--ink-3` | 层次靠字重+对比 |
| 强调 | 主 CTA 墨色白字或 `--accent`；待确认琥珀/橙 | 确认权醒目，不做彩虹状态 |
| 圆角 | 外 lg · 内 md · 芯片 sm | 同心 |
| 阴影 | 仅轻 rest；抬起不加厚 | 克制 |
| 按压 | `.btn-press` → `scale(0.96)` | apple-design Response |
| 焦点 | 统一 focus-ring（accent） | a11y |
| 数字 | `tabular`（徽标、齐套计数） | 不跳 |
| 头像 | 真人照片风 / 字头像 + 细描边 | 拟人；禁机器人插画 |
| 禁用 | 暗色皮肤、假 KPI 环、Agent/Harness/Seat 对外文案、跨案经营台指标条 | vision §3 / pages 禁区 |

观感对照：Kimi `Downloads/…/app` 只读；借壳密度与纸感，不借跨案经营首页。

## 3. 主路径帧（路由顺序）

画板参考：1440×900；每帧标注：路由、角色（企业/代理）、档位（助手/项目/专业）、硬闸。

### Frame 1 · 宣传站 `/agent/welcome`
- **感觉**：货架 · 「登录再干活」
- **首屏**：大标题钉「外挂知识产权部」；定位句；七部/场景货架；主 CTA「登录」
- **禁**：登录后薄入口的三入口复刻；案内交卷闸

### Frame 2 · 登录 `/agent/login`
- **感觉**：干净表单；企业 / 代理一眼可选
- **业务**：写入角色后落薄入口（企业→本公司链路；代理→案盘链路）

### Frame 3 · 薄入口 `/agent`（登录后）★ combine 收口
- **感觉**：总览薄壳 · **马上能进干活 / 持续委托** · 无宣传长文 · **无跨案经营台**
- **信息序钉死**（pages §4.0a）：
  1. **一主 CTA（唯一）**  
     - 企业有案：**顾言持续委托**（可点链入口）为主视觉；同区可弱链「进入本公司」  
     - 企业无案：「开案子」（可顺手发起持续委托）  
     - 代理：「进入案盘」；可挂持续委托，仍算同一主 CTA 区  
     - **禁止三卡平铺**；禁止第二大卡「经营台」
  2. **「现在需要我处理」轻量轨** = 待确认 / 待接力（含四类确认**类型标签**）；点进确认页或接力；**本页不批**
  3. **弱链**（非大卡）
- **持续委托可点链（须走通，禁只 toast）**：提目标 → 计划可调 → 部门执行 → 确认 → 接力  
  - 交办后仍进**公司首页**认知，部门由负责人路由；不拆 hops
- **作废**：旧三入口卡；跨案「正在推进」完整台；假 KPI 指标条；万能 Agent / 外挂聊天窗

### Frame 4 · 公司首页 `cases/:id`
- **感觉**：一案一公司 · 「现在在哪个部门」
- **首屏**：定位句；**七部网格 = 认知锚**（每部 ≤3 头像；交卷态文案清晰，无假进度环）
- **三档真行为**：
  | 档 | 行为 |
  |---|---|
  | **助手** | **藏侧栏**；**弱化/收起七部地图**（可按需唤回）；以负责人对话与轻量事项为主 |
  | **项目** | 日常默认：侧栏 + 七部锚 + 部门台入口 |
  | **专业** | 工作室占位（卷宗/多案协同加重提示；可进部门台重视图） |
- **交互**：部卡 → 右侧抽屉（专家+交卷态）；主 CTA「去当前部门」/ 负责人路由
- **交付快照**：确认通过后可在本页露一小格（交卷摘要 / 已确认事实）

### Frame 5 · 部门台 `cases/:id/depts/:slug`（同一模板 · 两工作台 B）
- **同一部门页模板**；禁两套产品壳；禁空总台
- **两工作台 B**：
  1. **代理默认** = 卷宗三栏：左目录 / **中栏=文书** / 右对话+协同
  2. **企业默认** = 简版重心：事项 / 已确认事实 / 待决策；左目录可收折；右栏仍保留闸与确认
- **协同 ↔ 文书**：同页 **Tab**（或同页切换），共享当前节点与版本；中栏文书、协同面（计划/专家/确认）可切
- **硬闸 G1**：未齐套 → 右栏「交卷」禁用 + 缺项可见；齐套后可交卷进确认
- **验收句**：截图能分出企业简版 vs 代理卷宗，且同路由模板

### Frame 6 · 确认页 `/agent/pending/...`
- **感觉**：人拍板 · 「待你确认」
- **首屏**：① **四类确认类型标签**之一（技术事实 / 专业复核 / 商业与风险决策 / 对外交付·递交）+ 交卷摘要 ② 齐套/依据 ③ 通过 / 驳回
- **硬闸 G2/G3**：起草人自批禁用；专家建议稿标「非签字」；质检 ≠ 确认权；无人确认不移交
- **确认后交付快照须可见**（本页成功态或回公司/部门一小格；禁黑箱）
- **类型标签仅分类，不另开闸**

### 附 · 案盘 / 开案子
- 案盘：代理主 CTA 落点；列表进公司/部门
- 开案子：可可选发起持续委托；创建后进公司首页再「去当前部门」

## 4. 持续委托可点链（原型须走通）

| 步 | 名称 | UI 落点 | 用户动作 |
|---|---|---|---|
| 1 | 提目标 | 薄入口主 CTA / 开案子 | 填写业务目标 → 交给顾言 |
| 2 | 计划可调 | 计划面板（可改部门顺序/说明） | 确认或调整计划 |
| 3 | 部门执行 | 部门台（当前部） | 齐套 → G1 交卷 |
| 4 | 确认 | 确认页 | 通过 / 驳回（类型标签可见） |
| 5 | 接力 | 交付快照 + 公司下一部门 | 去下一部 / 回公司 |

**禁**：任一步只 toast 结束；跳过交卷闸或确认权；万能 Agent 窗顶替本链。
