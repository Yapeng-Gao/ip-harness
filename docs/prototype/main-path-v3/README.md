## 怎么起本地预览

需要 Node 20+（本机已验证 npm 可用）。**不含 `node_modules`**，首次需安装：

```bash
cd docs/prototype/main-path-v3
npm install
npm run dev
# → http://127.0.0.1:8767/
```

构建预览：

```bash
npm run build && npm run preview
# → http://127.0.0.1:8767/
```

建议从官网（`surface=site`）进：营销站 → 登录（企业/代理 · 首次/已有）→ 工作区。

## 页面 / 视图清单（单页 SPA，状态机切面）

入口都在 `src/App.tsx`（`src/pages/Home.tsx` 为 Vite 模板残留，未挂路由）。

### 登录前
| Surface | 说明 |
|---|---|
| `site` · MarketingSite | 官网：英雄区、部门接力演示、业务能力、可信机制、双端三深度 |
| `login` · LoginPage | 演示身份：企业研发 / 代理所 · 首次使用 / 已有工作 |

### 登录后 · 顶栏三档（IA 已收敛）

顶栏「当前项目」切换器：**首页 / 部门**等跨案面隐藏；仅 **项目列表壳 / 工作台**（及代理端客户与案件）保留。
| Mode（内部 id） | 顶栏文案 | 说明 |
|---|---|---|
| `assistant` | **首页** | 顾言委托 + 跨案待办；并入原「公司首页/工作首页」；**协同消息/客户协同**收在首页次区，不做第四主 tab；**顶栏不挂「当前项目」**（跨案面） |
| `project` | **项目** | 项目与对象（或代理端客户与案件）→ 进工作台；侧栏不再有公司首页/部门/消息；**顶栏「当前项目/案件」真切换器仅此壳与工作台出现** |
| `studio` | **部门** | 一面两段：花名册（原部门与专家）+ 工作室配置（Skill/提示词/MCP/发布） |
