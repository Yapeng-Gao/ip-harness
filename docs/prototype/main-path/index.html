主路径

  1. 宣传站
    货架七部 + 场景 + 橱窗 · CTA 登录 · 无交卷
  2. 登录
    企业 / 代理 · 样机本地会话
  3. 薄入口
    一屏一主 CTA · 待确认+弱链 · 知产负责人「交办业务目标」弱入口（#goal）
  4. 多案流水（案盘）
    代理案盘 · 案名/部门/待确认/期限红点 · 点进公司首页
  5. 开案子
    极少字段 · 可选交办业务目标 · 创建进公司首页
  6. 公司首页
    七部等宽卡 + 右侧抽屉 · 去各部门台
  7. 确认页
    ?dept= 按部 · 通过移交 / 驳回回流 · 自批禁用（G2/G3）
