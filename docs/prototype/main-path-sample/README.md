## Happy Path

1. 大厅「要你拍的」已有 2–3 条 A/C 样例 → 可点「去处理」  
2. 「上传 / 开始」→「加载样例材料」  
3. 分析结果 → **确认 · 去交底部** → 进入交底部  
4. 编制（点专家 → 1:1 / 看产出）+ 四步时间线 + 硬请示（结论+点依据摘录定位主栏）+ 侧栏底打一句  
5. 两道硬请示（事实 / 可交⑤）→ 开④→⑤工单 → 申请部接单  
6. ⑤ 见 A/B/C → 分钮 → 过线后再确认递交  
7. （可选）⑥：争点 → 缩限 → 本轮递交  

## 三刀怎么验（本轮）

| 刀 | 怎么点 | 期望 |
|---|---|---|
| ① ④台密度 | 进交底部 | 顶区四步时间线（非 pill）；硬请示含「结论」+可点「依据摘录」；摘录定位/高亮主栏段；侧栏底 composer 能打一句进 feed；feed 带头像 |
| ② 大厅有货 | 硬刷大厅 | 「要你拍的」≥2 条 A/C 样例；点「去处理」进对应部/请示 |
| ③ 编制聚焦 | 点成稿专家 | 侧栏切 1:1；「看产出」锚到技术方案段并闪一下；「回团队」恢复 |

硬请示 / 薄部 / 前台闸 **不得回退**（smoke 仍盖）。
