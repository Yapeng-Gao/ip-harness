## Happy Path

1. **登录门** → 选企业/代理所 · 已有工作 → 进入  
2. 大厅：问候计数 + **委托 composer** + **摘要芯片**（待拍/推进 → 顶栏飞层）+ 八部  
3. 交给前台 → 分析轨迹 → 确认去向 → 交底部  
4. ④：编制（1:1/看产出）+ 时间线 + 硬请示依据 + **feed 工具芯片** + composer  
5. 工单④→⑤（agent 交接条）→ ⑤ A/B/C + composer →（可）⑥ + composer

## 本轮落点（精致度 · 并行 · 定时 · 文书 · 壳导航）

| 目标 | 怎么验 |
|---|---|
| **精致度** | 顶栏变矮、卡片/主栏 padding 收紧、纸感阴影更密；整站仍墨蓝 |
| **并行任务** | 大厅「进行中」卡可点切换；④⑤⑥ 顶有任务条+轨迹回放；切案主栏跟着变 |
| **定时/催办** | 顶栏「定时」chip → 飞层假数据可点跳转 |
| **⑤⑥ 文书** | ⑤ 权项\|说明书\|差分真切换；⑥ 答复\|通知书\|差分 |
| **壳导航** | ⌘K 搜索飞层、铃通知、案切换 chip，均可点 |
