## 怎么验

1. **薄入口（缺口优先 · pages `d0bc2c6`）**：`home.html` — **有缺口**时一主 CTA=`缺口→去干活`大卡（进工作台右栏闸）；「进入本公司/案盘」**仅弱链**。无缺口/无案才用角色主 CTA（进入本公司/开案子/进入案盘）。
2. **持续委托链**：首页/公司提交目标 → `delegate.html` → `dept.html` 工作台 → 勾齐交卷 → **右栏通过/驳回** → 下一部（`pending.html` 仅软跳转）。  
3. **三档换面**：顶栏「助手」→ 侧栏与七部地图隐藏；「项目」→ 公司/部门作业面；「专业」→ **着陆 `professional.html`**（能力卡，一眼异于作业面）。**作废**同面加密度。  
4. **去该部干活**：专业页 CTA → 切回项目档并进 `dept.html` Cursor 三栏。  
5. **两工作台 B**：`dept.html?role=enterprise` 中栏见事项/已确认事实/待决策；`?role=agency` 卷宗三栏更满。**禁**文书/协同双视图。  
6. **闸与快照**：公司齐套缺口主 CTA→当前部门工作台；未齐套交卷禁用；**工作台右栏拍板**（独立确认页已废主 hops）。  
7. **后勤三页**：顶栏弱「期限」→ `docket.html`；侧栏后勤 → 期限/账单/成员；空态「本案暂无期限事件」「尚未报价」、成员仅创建者引导。
8. **示范案卡**：`welcome.html#demo-case` — 案名+当前站+距可递交微进度+交卷感；灰态非作业；Hero 不回退。
9. **品牌与纸感**：处处「虚拟知产公司」；浅色纸感；无暗色 OS 皮；无 Kimi 橙。
