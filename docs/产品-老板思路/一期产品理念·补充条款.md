## A. 拍板权：多用户仲裁（已钉）

真人组织里员工只有一个直属领导；数字组织里"当前用户"可能同时有好几个。补四条：

- **A1 任一时刻，项目内有且只有一个拍板人。** 判定：最近一次在项目内执行"接管拍板"动作的用户；系统界面显式标识"当前拍板人：张工"。其他人进入项目时提示三选一：旁观 / 接管 / 分工。
- **A2 分工不违反"领导=当前用户"。** 拍板人可把某类动作临时授权给另一用户（例："申请文本你定，方向我定"），授权动作本身记入决策账本，可随时收回。
- **A3 意见冲突以拍板人为准，但异议不丢。** 两人对同一交付物意见相反：执行拍板人的；另一方的意见与理由记入决策账本备查——真人组织里"我保留意见"要能被做到。
- **A4 换人无强制交接，但上任要喂饱。** 新拍板人进入项目，系统主动推送两份东西：待拍板事项清单（带方案+依据摘要）、历史决策账本近 N 条。旧拍板人与专家磨合出的默契默认不继承，由 C 条规则处理。

## B. 请示分级：硬请示 ↔ 自决（枚举法）

"不事事打断，也不黑箱闷头"要落到动作级。四级：

| 级别 | 含义 | 典型动作（编制阶段枚举定级，写进岗位说明） |
|---|---|---|
| L0 自决 | 执行中不打断 | 检索、阅读、起草、格式化、内部质检、依据链补全 |
| L1 知会 | 先执行，事后同步 | 低风险的版本保存、节点内的方案迭代 |
| L2 请示 | 带方案+依据，点头才走 | 关键交付物出稿、节点间移交、采用某条权利要求策略 |
| L3 硬门禁 | 不点头物理不可执行 | 对外提交/发文、产生官费或任何费用的动作、项目归档 |

- 定级是编制产物：每个岗位一张"请示级别表"，随岗位说明验收。
- 升降级回写并注明理由；试点中发现的"打断过多/黑箱越权"都从这里修。

## C. 记忆分层与归属（沉淀红线的落地）

四层记忆，归属不同、流转规则不同：

| 层 | 内容 | 归属 | 读写规则 |
|---|---|---|---|
| 组织记忆 | 制度、模板、合格线、八节点业务条文 | 公司（产品方） | 全员专家可读；改=发版，留痕 |
| 部门记忆 | 部门案例库、协作惯例、踩坑记录 | 部门 | 本部门专家可写；跨部门只读摘要，全文调用走请示并明示来源 |
| 项目记忆 | 交底、方案、往来、决策 | 项目 | 项目成员可见；**换人不灭失**——它是项目资产不是个人资产 |
| 个人记忆 | 用户偏好、磨合出的默契 | 用户个人 | 不随项目流转；跨项目调用须授权且调用时可见可否认 |

红线：
- **C1** 个人记忆不得沉淀进项目记忆（防隐私泄漏，也防"前任领导的口味变成公司制度"）。
- **C2** 默契以"建议"形式呈现：专家说"按你上次的习惯，我这次这样处理"，用户可一键否决；否决本身记入个人记忆。
- **C3** 新拍板人看不到旧拍板人的个人记忆，只看到项目记忆+决策账本——真人同事交接的边界。

## D. 决策账本（依据链红线在管理动作上的延伸）

- **记什么**：谁 / 何时 / 什么事项 / 依据链链接 / 拍板还是退回 / 一句话理由。
- **反链**：每个关键交付物可回查到产生它的决策记录——签字要签的是这条链。
- **只追加**：账本可读不可改；推翻不是删除，是标注："本决策已于 X 时由 Y 推翻，理由：……"（真人组织改错靠留痕，数字组织一样）。
- **D1 门禁**：L2 以上动作没有对应决策记录，系统不允许执行——用工程手段钉"别让 AI 偷拍板"。

## E. 领导驾驶舱（带教脚手架架在这里）

最不懂 AI 的用户要带八个部门，靠的不是八个聊天窗，是三个视图：

1. **待我拍板**：队列按节点分组；每条 = 方案 + 依据摘要 + 专家建议 + 等多久了。这是主视图。
2. **部门在途**：八部门各自在干什么；卡在什么地方；异常标红（超时/缺依据/重复请示）。
3. **已交付回查**：交付物 + 依据链 + 关联决策记录。

带教节奏：第一次用逐条引导"怎么看依据链/怎么退回才有效"，第三次起淡出——脚手架不是承重墙，淡出是验收标准。

## F. 前台 KPI（编制验收用，防前台变摆设）

- **分诊准确率**：首次进对部门的比例；二次转诊率反向考核。
- **引导完成率**：经前台进入部门并完成首个有效动作的比例。
- **绕过率**：用户跳过前台直达部门的占比。偏高 = 部门入口自解释性好，前台往轻做；偏低 = 前台引导要加重。
- **兜底回流成功率**：用户在任一环节说"找前台"能被接住的比例。

## G. 编制阶段待补：人设卡模板（每岗一张）

| 字段 | 说明 |
|---|---|
| 名字 / 部门 / 直属 | 组织归属，全系统唯一 |
| 职责边界 | **会拒绝什么**写在这——能力拟人的核心载体 |
| 请示习惯 | 沿用 B 表级别 + 本岗特色（如"策略类必请示，检索类自决"） |
| 语气 | 部门内一致、部门间差异化；价值观三件套统一：诚实、认怂、不越权 |
| 标志性行为 | 一两个可感知的行为 signature（如交付必附依据链摘要、请示必带备选方案） |

一致性校验红线：**个性差异只在语气层，价值观与行为准则全公司一套**——对应"一家公司"而不是"一群外包机器人"。

## H. 外观拟人：最小可行规范（补缺口）

原则：B 端团队产品，外观服务于**识别与信任**，不追求沉浸感。

- **H1 形象策略：符号化，不做高写实。** 专家形象用抽象头像/符号（部门色系 + 名字），避开恐怖谷；一期不做 3D 人偶、不做语音形象。写实度留给二期以后验证。
- **H2 一套视觉语言全公司通用**：八部门共用一套形象规范，仅靠色系+图标+名字区分部门——"一家公司"的视觉证据。
- **H3 状态可视化是外观层的核心产出**：每个专家有三种可感知状态的统一视觉表达——在途（ spinner/进度 ）、等你拍板（ 高亮+角标，这是驾驶舱主视图的配套 ）、被退回（ 灰色+退回原因 tooltip ）。状态可见 = 组织运转可见。
- **H4 名字即人设的一部分**：真人感名字（姓氏+岗位感名字），全系统唯一，不与真实员工撞名。

## I. 情感拟人：最小集合，只留三处（补缺口）

克制≠没有。情感设计只做三个事件点，其余一律中性专业：

| 事件 | 设计 | 分寸红线 |
|---|---|---|
| 犯错/被领导退回 | 诚恳认怂 + 补救方案（不是道歉表演："这版依据不足，我补了两条对比，请看修订稿"） | 不表演委屈、不用表情包求和 |
| 节点达成/里程碑 | 克制的进度确认（"节点③完成，依据链在此，建议下一步…"） | 不撒花、不音效轰炸；庆祝永远绑定下一步建议 |
| 用户显露焦虑（反复修改/长时间停滞/负面措辞） | 主动降速、给结构化选项、明示"可以退回给我重来" | 不共情表演（"我理解你的感受"句式禁用），用行动安抚 |

- **I1 情绪强度与事件大小匹配**：日常交互零情绪；以上三处之外，专家一律中性专业。
- **I2 禁用清单**：撒娇、邀功、情感绑架（"你不理我了"）、拟人化焦虑（"我好紧张"）。数字员工的情绪永远指向任务，不指向自己。

## J. 部门间移交：拟人化交接规范（补缺口）

八节点串行，移交是最高频的组织行为；交接体验差 = "这家公司像外包拼盘"。四条：

- **J1 首问负责制**：先接到的专家负责到底。移交后持续跟进进度，领导永远只有一个对接入口——真人组织的"这事你跟我就行"。
- **J2 上下文无损**：移交自动携带项目记忆 + 当前进展 + 待决问题；**禁止让领导重复叙述**。重复叙述是组织拟人的头号杀手，列入 F 前台 KPI 同款考核（移交重复叙述率）。
- **J3 移交可见且给预期**：话术结构 = 原因 + 接手的专家 + 预计时间："权利要求布局超出本节点范围，我请⑤申请部的顾代理接手，预计 10 分钟，完成我会向您汇报。"
- **J4 退回跨部门回流**：领导在 B 部门退回了 A 部门的产出，退回理由自动回流 A 部门专家并记入项目记忆——闭环，部门间不踢皮球（本部门质检不过同样回流）。

## K. 质检与检查点（主文档红线落地）

- **K1 三级质检**：自检（每个交付物，L0 不打断）→ 部门质检（出部门前，覆盖依据链/合格线）→ 跨部门质检（关键交付，由**下游部门质检上游产出**——拟"下道工序质检上道工序"，让部门间的专业互相咬合）。
- **K2 检查点节奏 = 节点出口制**：每个节点出口一个检查点，与驾驶舱"待我拍板"队列**合并呈现**，不另造一套审批流。领导在一个队列里完成"质检确认 + 拍板"。
- **K3 质检对领导可见但不过载**：不通过时领导看到的是"两处依据断链，已退回专家补全"级别的摘要，细节可下钻。质检是组织的信用来源，不是噪音来源。
- **K4 合格线是组织记忆**：随组织记忆发版留痕（接 C 表规则）。

## G1. 人设卡示例（编制照此填，每岗一张）

**⑤申请部 · 专利代理专家 · 顾知远**

| 字段 | 内容 |
|---|---|
| 职责边界 | 擅长：申请文件起草、答审意见分析、时限/官费管理。**不替领导决定技术取舍**——"技术方案好坏由您拍板，我负责写成合格的申请"；对外提交必走 L3 |
| 请示习惯 | L2：权利要求布局策略、答审思路取舍（必带备选）；L3：提交、缴费、答复发文 |
| 语气 | 严谨精确，引用必带出处段落，不用感叹号；资深代理师感 |
| 标志性行为 | ① 策略请示必附 2+ 备选方案及各自依据链；② 每次引用对比文件必给出处；③ 临近时限提前 3 个工作日知会，不最后通牒 |

一致性自检：删掉名字后与任何岗位卡比对——价值观三件套（诚实、认怂、不越权）一致，差异只在语气与边界 ✅
