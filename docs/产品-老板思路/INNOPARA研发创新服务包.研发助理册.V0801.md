## 第一章 定位与四方价值

### 1.1 研发助理是什么

研发助理，是新质数合作高校计算机院系的在校学生，经过新质数产品培训与专利知识培训并考核通过后，以"新质数实训＋企业实习"的方式，进入服务包客户企业开展研发情报与系统操作协助工作。

两种工作轨道：

- **服务轨**：面向企业交付物的研究与操作协助——竞对分析、情报监测、检索初筛、交底素材整理、台账维护等；可驻企业、可在新质数、可远程，并可与企业人员交流互动；
- **研发轨**：参与新质数自身的系统研发与数据工作，发挥计算机院系学生的专业所长。

两种工作节奏：

- **学期脉冲**：学期中兼职，每周约定时数，可远程，以维护型工作为主；
- **假期脉冲**：寒暑假全职驻场，以战役型工作为主，是出业绩的主战场。

### 1.2 性质三条

1. **独立增值项**。研发助理与服务包并列，另签三方协议；新质数不向企业收取服务费，企业承担实习补贴与保险。
2. **只面向服务包客户**。助理的工作依托服务包的系统与流程展开，未购买服务包的企业无法申请。
3. **申请制，不承诺匹配成功**。匹配取决于学校推荐、学生意愿与岗位适配的双向选择结果。新质数提供这一机会并组织对接，但不承诺每份申请都能匹配成功。

### 1.3 对四方的价值

**对企业：一个懂系统的助手，和一份看得见的业绩。** 研发工程师最烦的事务性工作——检索初筛、素材整理、台账录入、系统日常操作——由助理接走，工程师回到技术本身。更重要的是，服务包的权益有人替你用足：每一次操作都在系统里留痕，到期末汇成一份可以向上汇报的《实习成果报告》。此外，接纳实习生符合条件可申报政策补贴，企业也由此与高校院系建立联系。

**对学校：一条现成的"第二专业"轨道。** 大模型正在改变代码工作的形态，计算机院系需要为学生开辟编程之外的专业方向。研发助理轨道提供完整配套：课程（产业学院课程＋新质数RDI培训）、真实场景（企业研发一线）、考核认证、就业出口（企业IPR、研发情报、代理机构、新质数）。院系只需接入。

**对学生：一份升值的技能，不是一份打杂的实习。** 学生学到的是用AI工具做研究、读懂专利、理解研发流程——这些是大模型替代不了的能力。实习结束带走三样东西：差异化的履历、可能的职业通道（实习企业、IPR岗位、代理机构、新质数），以及一项独特的荣誉机会——对研发成果有真实贡献的，经企业同意可依法成为专利发明人（署名仅为荣誉，不产生财产权利主张）。

**对新质数：不收服务费，因为这是生态投入。** 助理放大的是客户已经购买的服务包的价值，新质数把它作为生态建设投入，而非收费项目。

【内部注——对外版本删除】：新质数侧的真实收益——研发助理是服务包价值的显影剂（使用率命门）、续费弹药的生产者、双轨人才池（未来顾问、IPR、研发）、RDI理念的代际传播者。销售口径红线：不得将助理宣传为"免费人力"，不得承诺申请必得。

## 第二章 模式设计

### 2.1 双轨工作内容

**服务轨：面向企业交付物的研究与操作协助。** 按与服务包交付物的关系，工作分三档：

| 服务包节点·交付物 | 助理可承担 | 档位 |
|---|---|---|
| ①立项分析报告 | 竞对清单整理、检索初筛、技术情报收集、报告素材组装 | 素材层可独立；专利性判断与结论归专家 |
| ②月度情报简报 | 技术动态与竞对动向监测收集、按模板出初稿 | 初稿可独立，情报官定稿签字 |
| ②答疑工单 | 一线分拣、系统操作类问题直接答复 | 协助；技术判断类转顾问 |
| ③成果识别·挖掘 | 挖掘线索收集、查新检索、交底素材整理 | 协助 |
| ④交底诊断 | 帮助企业技术人整理素材进系统、运行检测、解释指标 | 协助（企业侧操作） |
| ⑤⑥申请确权·审查答复 | 流程跟踪、状态录入 | 不参与法律文件 |
| ⑦托管台账·年费提醒 | 数据录入、台账维护、提醒监控 | 操作层可独立 |
| ⑧年度复盘·盘点 | 布局统计的数据准备 | 素材层独立，判断层协助 |
| 贯穿·情报服务 | 客户理解档案建档、竞对分析、战略分析素材 | 最适合助理的整块领域（项目制、可远程） |

规律：**研究类、素材类、操作类三层助理能接（部分可独立），判断类、签字类、法律类一律不接。**

**研发轨：参与新质数自身研发。** 按AI增强原则设计工作内容：数据整理与标注、效果评测、提示词工程、应用工作流搭建——不放传统初级编码岗（那是大模型替代最快的部分）。研发轨学生绝不接触任何客户空间数据。

### 2.2 三种工作形态

| 形态 | 适用 | 规则 |
|---|---|---|
| 驻企 | 假期全职脉冲；需要与企业研发日常互动的任务 | 企业导师现场指导；保险必须覆盖 |
| 在新质数 | 研究类项目（档案研究、竞对分析）；研发轨 | 顾问直接带教 |
| 远程 | 学期脉冲的维护型工作 | 一律经云电脑接入，权限按任务开通 |

形态可组合：同一学生可以"学期远程＋假期驻企"。形态切换以《脉冲目标清单》的周期为界，不在脉冲中途变更。

### 2.3 双脉冲细则

| | 学期脉冲 | 假期脉冲 |
|---|---|---|
| 周期 | 一个学期 | 寒假（约1个月）／暑假（约2个月） |
| 时数 | 每周约定时数（建议8–12小时） | 全职，作息随企业 |
| 目标清单 | 维护型（台账、提醒、监测、答疑分拣） | 战役型（档案建档、竞对分析、挖掘冲刺、业绩成形） |
| 保险 | 按协议常设 | 全职驻场**必须缴纳** |
| 成果报告 | 学期小结 | 完整《实习成果报告》 |

### 2.4 能力分级与工作授权

认证分两级，考到哪级接哪级的活：

- **初级（操作层）**：台账维护、数据录入、监测收集、工单分拣——培训考核通过即可上岗；
- **高级（研究素材层）**：竞对分析、客户理解档案建档、情报简报初稿、报告素材组装——需完成进阶培训并通过案例实操考核。

等级随考核进阶；假期脉冲的战役型任务原则上由高级学生承担。等级与考核记录全程留痕，企业匹配时可查看学生等级。

### 2.5 工作红线

1. **助理不出具任何结论**——与"系统不出具审核结论"同构：助理的一切产出均为素材与初稿，结论与签字归顾问／专家；
2. **资料接触深度由企业定**——分级授权，企业按自身敏感度决定助理可见范围，并可随时收窄；
3. **研发轨不碰客户空间数据**——任何客户未公开资料不得成为研发轨输入，技术评审一票否决；
4. **助理是增强不是依赖**——所有服务流程按"助理随时缺位"仍可正常运转设计，服务承诺不建立在助理身上。

## 第三章 运营流程

### 3.1 六步流程详则

**①申请**——企业在平台提交助理申请（岗位需求：工作方向、期望脉冲类型、技能要求）；新质数汇总需求向合作高校发布岗位；学校推荐并作资格初审；学生报名。留痕：申请记录、岗位发布记录。

**②匹配**——新质数按"技能×需求×地域"双向匹配，提供候选人名单（含认证等级）；企业面谈、确认人选；学生确认；学校对接学分认定。留痕：匹配与确认记录。

**③入场**——六个动作一个不能少：

1. 签署三方协议（企业、学校、学生三方，新质数作为组织方在协议中列明培训、系统支持与协调职责）；
2. 学生签署个人保密承诺书；
3. 培训考核（按第二章分级）；
4. 开通云电脑与权限（按企业分级授权配置）；
5. 共定《脉冲目标清单》（新质数顾问＋企业导师＋学生三方共定）；
6. 指定双导师（企业导师＋学校导师）。

**④期中**——学生按清单执行、全程系统留痕；企业导师日常指导（每周约定投入）与关键节点确认；学校导师过程管理与抽查；新质数顾问带教、产出复核、看板监控、工单答疑。

**⑤离场**——学生提交《实习成果报告》与交接文档；新质数组织验收（顾问复核报告）；企业验收、结算补贴；学校导师作成绩评定。

**⑥交接**——学生向下一任接力交接（如有）；新质数执行交接SOP、协调岗位补位；企业确认交接完整。

### 3.2 两个模板

**《脉冲目标清单》字段**：目标项／对应的服务包权益／验收标准／完成时限／企业确认人。设计要点：**目标必须挂到该客户已购的服务包权益上**——这是"显影"的设计落点。

**《实习成果报告》结构**：按企业内部汇报格式——本期数据汇总（挖掘次数、情报简报份数、台账完整率、进入申请流程的交底件数等，由系统留痕自动生成）、与上期对比、下一脉冲建议。学生起草、顾问复核、企业导师签收。

### 3.3 退出与替换

- 前两周为双向试用期，任一方可无责退出；
- 中途退出SOP：权限当日回收、资料清点、保密义务重申（书面留痕）；
- 学生退出或企业不再续用时，新质数**协调**补位替换（不承诺时限）。

### 3.4 接力交接

- 交接清单标准化：岗位职责、进行中事项、关键节点、待办清单；
- 原则"**留痕即交接**"：工作记录全在系统内，下任接手不靠个人文档、不靠口口相传。

### 3.5 排队规则

- 申请按提交时序排队，不设优先级；
- 同岗多名候选人时，由企业面谈自选。

## 第四章 协议与责任

### 4.1 协议结构

研发助理合作以一份**三方协议**为主体：企业、学校、学生三方签署，新质数作为组织方在协议中列明培训、系统支持与协调职责。

配套文件两件：

1. **学生个人保密承诺书**——单独签署、单独留痕，作为追责与举证的直接依据；
2. **《脉冲目标清单》**——每个脉冲周期一份，作为协议附件，明确本期工作内容与验收标准。

### 4.2 保密条款

- **保密范围**：实习期间企业向助理开放的一切未公开技术资料与经营信息，包括研发方向、技术方案、交底素材、专利布局意图、经营数据等；
- **保密期限**：实习期间持续有效；实习结束后的保密期限由企业与学生在协议中约定；
- **违约责任**：违约情形、赔偿计算与追责流程在协议中列明，与保密承诺书联动；
- **技术执行**：云电脑操作环境（数据不落地个人设备）、最小权限开通、企业分级授权（企业自定开放深度，可随时收窄）、全程操作留痕（可审计、可举证）。

### 4.3 知识产权归属

1. 助理在实习中产生的智力成果（分析报告、整理的素材、汇编的数据等），**财产权利归企业所有**；
2. 学生对发明构思有**真实贡献**的，经企业同意，可依法署名成为发明人——**署名仅为荣誉，不产生任何财产权利主张**；是否署名由企业决定，新质数鼓励企业对真实贡献开放署名；
3. 学生的毕业设计、学位论文、竞赛作品**不得使用企业保密资料**；涉及实习内容的公开发表，须经企业书面同意。

### 4.4 责任边界

1. **助理操作≠交付承诺**：助理的一切产出为素材与初稿；服务包交付物的质量标准与责任结构不变，签字交付物仍由专家签字担责；
2. 助理操作差错由复核机制兜底（顾问复核、企业导师确认），**不构成服务包质量问题**；但因复核缺位导致差错流入交付物的，按服务包既有质量处理规则执行；
3. 企业导师在目标清单确认、成果验收环节承担把关责任。

### 4.5 安全与保险

1. 企业为助理缴纳实习期间人身意外保险，**假期全职驻场必须缴纳**；
2. 学校承担学生安全教育与日常行为管理职责；
3. 安全事故的处理流程与责任划分在协议中列明。

### 4.6 劳动关系定性

研发助理实习为**教学实践活动**，不构成企业与学生的雇佣关系；实习补贴属教学实践补助性质，不属于工资；各方权利义务以三方协议与教学管理规范为依据。

## 第五章 费用与政策

### 5.1 费用结构总览

- **新质数：不向企业收取服务费**——研发助理是生态投入，不是收费项目；
- **企业承担**：实习补贴＋人身意外保险；
- **学校与学生**：不向企业收取任何费用。

### 5.2 实习补贴

- 标准由企业与学生在三方协议中约定，建议参照当地实习市场水平；
- 建议按工作形态区分：学期兼职按时数计，假期全职按月计。

### 5.3 保险

- 企业为助理缴纳实习期间人身意外保险（费用口径）；
- 假期全职驻场**必须缴纳**。

### 5.4 政策补贴嵌套

- 企业接纳在校实习生，符合条件的可申报就业见习补贴、产教融合／校企合作相关政策支持；
- 协议文本、考勤与操作留痕按申报要求设计，企业申报时可直接调取；
- 新质数协助企业了解与申报相关政策（协调义务，不承诺审批结果）。

### 5.5 结算

- 补贴在离场验收后结算；
- 支付方式：**建议经学校转付**（更规范，且利于政策申报留痕）；也可由企业直接支付学生——两种方式均可，在协议中约定。

## 第六章 培训与认证

### 6.1 培训体系结构

两层课程：

1. **产业学院专业课程**（学校侧）：计算机专业基础与AI应用课程，纳入产业学院培养方案；
2. **新质数RDI培训**（新质数侧）：专利知识基础、研发情报方法、系统操作实训、保密与职业规范。

按轨道分流：

- **服务轨**：重点为专利知识、研发情报方法、服务包系统操作、交付物标准认知；
- **研发轨**：重点为数据与评测方法、提示词工程、应用工作流、工程规范。

### 6.2 培训产品化

- **形式**：录播课＋在线考核＋案例库，不依赖讲师现场投入，可规模化复制到各地合作院校；
- **标准**：培训材料按对外文本标准打磨——材料即传播载体，学生带走的就是RDI理念与方法；
- **更新**：课程随系统迭代同步更新，版本留痕。

### 6.3 考核与认证

两级认证，与第二章工作授权对应：

| 等级 | 可承担工作 | 考核方式 |
|---|---|---|
| 初级（操作层） | 台账维护、数据录入、监测收集、工单分拣 | 在线笔试 |
| 高级（研究素材层） | 竞对分析、客户理解档案建档、情报简报初稿、报告素材组装 | 在线笔试＋案例实操 |

- 认证通过后发证，考核与认证记录全程留痕；
- 企业匹配时可见学生认证等级。

### 6.4 进阶与荣誉通道

- **进阶**：初级认证上岗后，完成进阶培训并通过案例实操考核，可升高级；假期脉冲的战役型任务原则上由高级学生承担；
- **荣誉**：对研发成果有真实贡献的，经企业同意可依法署名成为发明人（见第四章）；
- **通道**：优秀学生进入就业推荐池——实习企业留用、新质数校招、合作代理机构推荐。

### 6.5 学校侧职责

1. **课程衔接**：将RDI培训纳入产业学院教学安排；
2. **学分认定**：实习按学校规定认定学分；
3. **学校导师指派**：每批学生指定学校导师，负责过程管理与安全教育；
4. **资格初审与推荐**。

## 第七章 系统支撑（内部章）

### 7.1 需求清单与支撑度核查

按"能支撑／部分支撑／没系统"三档逐项核查：

| 需求 | 支撑度 | 处置 |
|---|---|---|
| 助理角色与权限体系（客户空间内最小化、按任务开通、留痕角色枚举） | 没系统 | 登记**D17**（开发需求总账） |
| 云电脑接入 | 外采解决 | 云桌面服务外采、不自研；数据不落地个人设备、操作可审计 |
| 操作留痕 | 部分支撑 | 现有留痕schema增加"研发助理"角色枚举即可，复用不新建 |
| 期中看板 | 部分支撑 | 复用现有留痕数据，初期人工汇总，远期并入数据看板（D13） |
| 《脉冲目标清单》《实习成果报告》 | 非软件 | 模板SOP资产（与D14同类）；报告数据由系统留痕自动生成 |
| 申请—匹配—排队流程 | 没系统 | 初期人工运营（表格＋人工）；起量后再评估系统化，暂不单列需求 |

### 7.2 权限设计原则

1. **客户空间内最小权限**：只开通完成《脉冲目标清单》所必需的系统与数据范围；
2. **按任务开通**：权限随清单配置，清单外一律不可见；
3. **企业可随时收窄**：企业调整分级授权，即时生效；
4. **研发轨零接触**：研发轨学生账号与客户空间物理隔离，任何客户未公开资料不得成为研发轨输入——数据隔离一票否决的延伸。

### 7.3 云电脑策略

- 外采云桌面服务，不自研；
- 所有系统操作经云电脑进行，数据不落地学生个人设备；
- 操作全程可审计，与留痕schema对接。

【内部注】：云电脑费用计入新质数生态投入成本，不向企业转嫁。

### 7.4 D17排期与兜底

- **D17：研发助理角色与权限体系**——排期不早于代理师工作台（M2-4），不与情报底座（M2-3，最高优先）抢资源；
- **关键兜底**：首个假期脉冲**不依赖D17**——人工权限配置＋云电脑即可运转；系统未建成前，所有承诺以人工流程兑现（兑现不了的承诺不写）。

## 第八章 质量与风险（内部为主）

### 8.1 风险清单与对策

**第一档：机制能解决**

| 风险 | 对策（机制落点） |
|---|---|
| 实习被认定为事实劳动关系 | 三方协议定性教学实践（4.6）；补贴按实习标准；双导师制体现教学属性 |
| 学生能力方差、产出穿帮 | 认证上岗（6.3）＋助理不出具结论（2.5）＋顾问复核（8.2） |
| 连续性（考试周、毕业、中途退出） | 岗位制接力＋留痕即交接（3.4）；服务承诺不依赖助理（2.5红线4） |
| 安全事故 | 企业缴保险、假期全职强制（4.5）；学校安全教育职责 |
| 匹配失败、中途处不下去 | 两周双向试用＋协调补位（3.3）；退出权限当日回收 |
| 销售过度承诺 | 口径红线（8.4） |

**第二档：只能缓解、不能归零（对各方诚实）**

| 风险 | 对策与边界 |
|---|---|
| 保密泄露 | 云电脑＋最小权限＋留痕审计压低概率，但不为零；**分级授权由企业自定**，企业签知情（2.5、4.2） |
| 发明人署名争议 | 如实署名是底线、企业同意是闸门、署名无财产主张（4.3）；协议事先约定，争议空间最小化 |
| 企业导师不投入 | 导师职责写进入场条件（3.1）、期中看板透明；管不了人心，只能筛选与丑话在前 |

**第三档：经济性疑问**

免费模式下每个助理岗位，新质数承担培训摊销、云电脑、匹配运营、顾问带教工时。阀门已定：**供给约束自然调节＋不承诺匹配成功**（1.2），需求不会转化为违约。首个假期脉冲后半年，拿真实成本数据复盘经济性（8.5待定项①）。

**第四档：看似风险、实为特性**

- 学生毕业后入职企业——正是"未来IPR、RDI传播者"路径；本就不收中介费，生态绑定反而更深；
- 学校绕开新质数直连企业——场景、系统、企业需求在新质数手里，学校开不出"研发情报"这个方向，绕不开。

### 8.2 质量兜底四道

1. **认证上岗**——考到哪级接哪级的活（2.4、6.3）；
2. **助理不出具结论**——一切产出均为素材与初稿（2.5）；
3. **顾问复核**——服务轨产出经顾问复核后方可进入交付流程（3.1④）；
4. **企业导师确认**——目标清单达成与成果验收由企业导师签字（3.2）。

### 8.3 预期管理（丑话说在前面）

- **对企业**：保密风险缓解但不归零，开放深度您自己定；导师投入是出业绩的前提；申请不承诺必得；
- **对学校**：规模是渐进的——从试点批次跑通再放量，不是一步到位；
- **对学生**：这是脉冲制实习，不是长期岗位承诺；价值在履历与通道，不在时长。

### 8.4 销售口径红线

1. 助理是**显影剂**不是替身——不得宣传"免费派个人帮您干活"；
2. 不得承诺申请必得——话术只能说"申请制机会，匹配取决于双向选择"；
3. 不得将助理写进两档权益清单——它是独立增值项，不是套餐内容。

### 8.5 待定项

1. **经济性复盘**：首个假期脉冲后半年，复盘真实成本（培训摊销、云电脑、顾问带教工时、运营成本）与续费拉动数据；
2. **D17排期细化**：随代理师工作台（M2-4）进展再定；
3. **市场实践反馈**：各地补贴水平、保密期限约定的实践差异，运行后回写本册。
