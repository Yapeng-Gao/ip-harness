> **产品逻辑**：[../一期-产品逻辑/02-研发立项.md](../一期-产品逻辑/02-研发立项.md)

> **一期切法**：先按「**创建项目**」落地；完整论证报告后置，不挡主链。

## 0. 一期切法：先当「创建项目」

完整论证（多路线对比、专利空间、侵权初判、竞对对照、建议路线+签字）**东西太多，一期不做满**。

**一期只保证：**

```
有一个可跟踪的「项目 / 课题」容器
  · 名称、方向一句话、负责人（可选）
  · 起止或年度归属
  · 状态：进行中 / 暂停 / 结项
        ↓
后续节点的案件、交底、申请挂到这个项目下
        ↓
⑧ 年末复盘按项目汇总研发与专利
```

| 一期做 | 一期不做满（记在老板册，后置） |
|---|---|
| 建项目、改状态、挂下游案 | 多路线对比论证报告 |
| 项目上可记「背景/目标」短描述 | 专家签字《决策论证报告》时效 SLA |
| 为⑧、③提供「按项目」聚合键 | 强制创见前置 + 鉴新撑满合格五项 |

**三种「立项」仍拆开（别把项目创建当成保护决策）：**

| | 含义 | 归哪 |
|---|---|---|
| **A. 本步（一期）** | 开一个研发项目容器 | ① 创建项目 |
| **A′. 老板完整版** | 技术路线选哪条的论证报告 | ① 后置能力 |
| **B** | 成果保护去向 | ③ |
| **C** | 单案申不申 | ⑤ 井沿 |

---

## 1. 给谁用

| 角色 | 一期 |
|---|---|
| **客户 / 总工** | 建项目、写方向、看挂在名下的案 |
| **代理师** | 协助建项；完整论证若启动，另案做人工业务（非一期系统必经） |
| **平台** | 项目主数据 + 与案件关联 |

---

## 2. 交什么 · 往哪流

**一期交付：** 项目已创建且可被下游引用（项目 ID / 名称）。  

**下游：** ②③④⑤… 产出尽量挂项目；⑦台账可按项目筛；⑧复盘「研发情况」按项目汇总。  

**不做①（一期）：** 不因未出论证报告而挡交底→申请主链。

---

## 3. 老板完整版（后置，备忘）

应客户要求才做；创见材料包 + 鉴新/商业库；合格五项见保障计划。  
创新报告三图仍为**可选零件**。详见总纲 §3.1——**不作为一期必达**。
