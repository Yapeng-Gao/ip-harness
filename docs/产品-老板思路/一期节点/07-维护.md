## 0. 业务逻辑（按老板册）

**痛点：** 专利拿证不是终点——答复期限、年费期限没人盯，错过不可逆；钱花了说不清。

**做什么：** 把在管案件的**关键期限与费用**管住——系统算期、到期提醒；每笔官费/年费/服务费可查；缴费前客户确认。旗舰再加顾问巡检兜底。

```
⑤⑥ 回流：申请号/申请日、官方通知、审查结果
        ↓
录入期限台账（以官方凭证为准，二次核对）
        ↓
系统三级提醒（到期前 30 / 15 / 7 天）
  + 费用明白账（缴费前确认）
        ↓
（旗舰）每季度顾问巡检：期限 / 状态 / 费用异常 → 有事即报
        ↓
客户配合缴费；维持/放弃拍板常衔接⑧建议
        ↓
台账数据 → 喂⑧年度盘点/复盘
```

| 档 | 老板口径 |
|---|---|
| **标准** | **系统提醒版**：自动提醒 + 明白账自查；代理师主要尽**录入义务** |
| **旗舰** | **系统 + 顾问巡检兜底**（每季度）；主动提醒异常 |

## 1. 给谁用

| 角色 | 干什么 |
|---|---|
| **客户** | 转交官方通知书；查期限与费用；缴费前确认；维持/放弃拍板（多参考⑧） |
| **代理师** | **录入**申请日/OA日/授权日等与费用；录入错致错过期限 → **代理所责任**；旗舰做巡检 |
| **平台** | 期限计算与提醒；提醒功能本身出错 → **平台责任**（恢复费用或等价补偿） |
| **研发助理（若有）** | 可承担台账录入、提醒监控等操作层 |

---

## 2. 合格纪律（保障计划）

1. **期限零错过**——答复、缴费、年费等关键期限三级提醒；旗舰加季度巡检。因我方流程失误致权利失效，按责任规则处理。  
2. **费用明白账**——官费、年费、服务费入账可查；**缴费前经客户确认**。  
3. **数据以官方凭证为准**——申请号、申请日、状态等凭证录入后二次核对（台账错一天，下游期限全错）。

## 3. 产物与系统现状

| 交付/能力 | 状态（技术册） |
|---|---|
| 期限台账 + 系统内提醒（类型较全） | **【有】** |
| 费用台账（模板人工） | **部分有**；看板 D13 暂无 |
| 录入二次确认 / 逻辑校验 | **无 → D10**（排前：录入错是最大单点风险） |
| 短信/邮件提醒渠道 | **无 → D11**（现仅系统内） |
| 案件状态机 + 客户看板 | **无 → D12** |
| 年费成本看板 / 费用预警 | **无 → D13** |
| 旗舰季度巡检 | 人工按清单【流程有】 |

**一期够用：** 期限台账能跑、三级提醒在、缴费前确认、录入纪律硬；不假装已有完整「年费管理 SaaS 看板」。

## 4. 和报告 §2.3、⑧ 怎么分

| | **⑦ 本步（托管）** | **旗舰报告 2.3** | **⑧ 复盘** |
|---|---|---|---|
| 主业 | **日常期限与年费执行** | 体检：健康度、年费决策点、释放建议（写进基线报告） | **年度**维持/放弃策略与盘点 |
| 节奏 | 持续；到期就提醒 | 出基线报告时一截 | 固定周期主动交 |
| 养/砍 | 执行缴费；放弃决策常跟⑧ | 可给「建议放哪些」当判断输入 | 逐件建议 + 客户拍板 → 回写⑦台账 |

岚雾衔接表写「⑦←2.3」＝报告可给维护**判断素材**；**老板对外⑦仍是确权资产托管**，不要把 2.3 说成⑦产品本体。

**别塞进⑦：** 侵权监测、诉讼台、拆案布局、年度情报叙事（→⑧/二期）。
