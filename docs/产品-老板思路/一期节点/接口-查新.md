# 链上接口 · 查新（可专利性检索 / 鉴新）

> **一期业务短文** · 不另占八节点对外叙事  
> **对应**：老板「鉴新」；工具参考 [`Ai检索`](../../各产品开发/Ai检索/)  
> **勿采**：[`lifecycle/nodes/01-research.md`](../../lifecycle/nodes/01-research.md) 等 nodes 模型稿当唯一规格（可作对照，事实以 Ai检索 + ④⑤用法为准）  
> **谁消费**：[04](04-交底.md) 可选喂 1+；[05](05-申请.md) **B 段**喂决策/撰写；OA 创造性答复可复用命中  
> **不是**：FTO（实施自由，二期+）；不是授权承诺；不是科技查新证明可替代可专利性结论

---

## 0. 一句话

**用可复现的检索式 + 可核验文献，回答「新不新、值不值得往下写/申」——每条结论必须绑到具体命中，禁止「查了一下没查到」。**

```
交底要点（已确认更好）
    ↓
【生成】定式/库/窗 → 多库检索 → 筛标 X/Y/… → 齐套报告
    ↓
【分析】新颖性单篇对照 · 创造性三步法 · 区别特征与效果
    ↓
消费：④ 改交底 │ ⑤ Go/No-Go + 独权区别特征 + 背景技术 │ （后）OA 可复用
```

| | **③ 挖点时的检索** | **④ 可选轻量查新** | **⑤ 正式查新** |
|---|---|---|---|
| 目的 | 代理人拆点/去向/挖掘报告对照现有技术 | 改交底（1+） | **申不申** + 撰写靶子（区别特征等） |
| 谁 | 挖掘工作台 | 交底侧 | 开案后申请案子 |
| 厚度 | 随挖点；证据分层 | 可薄 | 建议有；跳过须人认风险 |
| 算终局吗 | **否** | 否（只服务改稿） | 决策向结论须人认（仍≠授权承诺） |
| 完成标志 | 候选可核、分层诚实 | 有修订依据即可 | 报告可复现 + 人认或显式跳过 |

**为什么③和⑤都像在「查新」：** 都要对照公开文献，但**责任节点不同**——挖时防止空壳点和胡说去向；开案后要拍申不申、定独权靶子。挖过≠自动完成⑤；⑤做过≠代替③的证据作业。详见 [03 §5](03-专利挖掘.md)。

## 1. 报告怎么生成

### 1.1 输入

| 输入 | 要求 |
|---|---|
| 技术方案要点 | 最好来自**已确认**交底（问题/方案/关键特征/效果）；发明人印象中的「最接近文献」只作**起点**，不是结果 |
| 领域 / 关键词 / 分类号线索 | 中英同义、上下位；IPC/国别可配 |
| 时间窗 | 相对拟申请日/优先权日的现有技术界（口径见法 22.5；⚠ 以当期为准） |
| 库范围 | 专利库为主；按需论文/非专利；多库时同族要归并意识 |

### 1.2 生成步骤（业务）

```
1. 定检索要素：关键词组、分类号、申请人/发明人（可选）、时间窗、同族策略
2. 写检索式：可复现（布尔 / 字段 / 截词等）；保留式子与跑库记录
3. 跑库出候选 → 人工/辅助筛选
4. 标注命中：相关度 + 文献角色（见下）
5. 核验：公开号/链接可打开；不可核验不得进结论
6. 成报告：检索式 + 命中台账 + 可专利性结论（每条 binding 到命中）
```

**工具层**（合享/智慧芽等）：AND/OR/NOT、截词、位置/同句算符等是**检索式写法资产**，见 [`Ai检索/合享-检索规则`](../../各产品开发/Ai检索/合享-检索规则(1).docx) 与智慧芽帮助——产品要能留存「用了什么式、什么库」，不必在业务文复述全部算符。

### 1.3 命中怎么标（常用角色）

| 标记意识 | 含义（业务） |
|---|---|
| **最接近现有技术** | 创造性分析的起点文献 |
| **X 类意识** | 单独一篇可能破坏新颖性 / 高度相关（特征几乎全覆盖） |
| **Y 类意识** | 常与另一篇组合谈创造性启示 |
| **一般相关 / 背景** | 写背景技术用，不直接定生死 |
| **排除** | 时间界外、同族重复、不相关等，须可说明 |

（具体字母表以所内规范 / EPC 习惯 / 项目约定为准；**关键是角色清楚 + 可核验**。）

### 1.4 报告交卷物（最低齐套）

| 块 | 必须有 |
|---|---|
| **检索过程** | 库、时间窗、检索式（可复现）、筛选说明（可薄） |
| **命中台账** | 公开号、标题、相关角色、可核验链接/出处、与本案特征对照摘要 |
| **可专利性结论** | 新颖性倾向 / 创造性倾向 / 风险点；**每条结论绑定具体命中** |
| **给下游的靶子** | 建议的最接近文献；区别特征列表；可写入背景的缺陷点 |
| **签署/认领** | 谁起草、谁确认可上会或可进撰写（企业或代理按委托） |

**不做进本报告冒充的：** 授权率预测；法律意见书；正式 FTO（另链）。

## 2. 报告怎么分析

> 分析分两层：**生成时的可专利性判断**，以及 **消费时怎么用报告改交底/做决策/写权项**。  
> 交底侧「对照报告改稿」对齐 [04 §3.2.2](04-交底.md)；创造性抓手可与 [06 §3A.2](06-答复.md) 共用意识；检索手法对齐 [`Ai检索`](../../各产品开发/Ai检索/)。

### 2.1 新颖性（法 22.2 意识）

| 步骤 | 做什么 |
|---|---|
| 1 | 选定**单篇**对比文件 |
| 2 | 逐项对照本案关键/拟保护特征是否被该篇**全部**公开 |
| 3 | 有未被公开的必要特征 → 新颖性倾向保留；全部被公开 → 高风险，须缩方案或改交底/权项策略 |
| 禁 | 用两篇拼凑谈新颖性；无公开号的「感觉撞车」 |

### 2.2 创造性（法 22.3 · 三步法）

| 步 | 做什么 |
|---|---|
| 1 | 定**最接近现有技术**（用途/场景/机理尽量同向） |
| 2 | 抽出**区别特征**（落到结构/步骤/参数/关系，勿空功能化） |
| 3 | 由区别特征重定**实际技术问题**；看其他文献/公知常识有无**启示**把区别特征用到起点上 |
| 结论要素 | 区别特征 ↔ 技术效果 ↔ 是否显而易见；禁只喊「效果更好」 |

分析抓手（生成结论或日后 OA 复用）：起点是否偏移、差异是否被抽象/漏标、问题是否回溯设题、动机是否空心、公知常识是否错配——详见 06 创造性抓手表。

### 2.3 硬闸（分析与生成共用）

| 闸 | 含义 |
|---|---|
| **可核验** | 空命中 / 假公开号不得过闸 |
| **有 binding** | 禁止无文献支撑的「感觉能授权」 |
| **查新 ≠ FTO** | 可专利性不回答「实施会不会侵权」 |
| **科技查新 ≠ 可专利性** | 「未见相同报道」不能直接当「可以申请」 |
| **不编造** | 不编对比文件内容、不编实验抵消命中 |
| **确认权跟人** | 报告结论须人认领；AI 只出草稿 |

## 3. 分析之后怎么用（消费方）

| 消费方 | 怎么用报告 |
|---|---|
| **④ 交底 1+** | 以报告为尺 + **原始素材补事实**，审核并完善交底（攻击点→可替换改文 / `【待补】`）；手法见 [04 §3.2.2](04-交底.md) 与 [`系统二·场景6`](../../各产品开发/腾讯交底书完善/提示词/系统二%20辅助完善提示词.docx)；发明人确认；**不在此拍 Go** |
| **⑤-B 决策** | 风险与类型建议 → 企业 **Go/No-Go** |
| **⑤-C1 权项** | 区别特征进独权/从权取舍；过宽命中 → 收敛范围（企业拍） |
| **⑤-C2 说明书** | 最接近文献写进背景缺陷；区别与效果写清；**禁检索编造实施例** |
| **⑤-C3 / J 档质检** | 有报告才深做新创性规则；无报告则降级提示 |
| **⑥ OA** | 命中与区别特征可复用；审查员新对比文件另开分析 |

## 4. 人 / AI

| | **人必须** | **AI 可** |
|---|---|---|
| 生成 | 定范围与目的；确认式子与命中可核验；签署/认领结论 | 扩词、跑库草稿、聚类、对照表草稿 |
| 分析 | 定最接近文献、区别特征、结论是否上会 | 三步法草稿、抓手提示（须人改） |
| 禁止 | — | 空命中过闸；授权概率；用 FTO 话术代替可专利性 |

## 5. 一期做透 / 可薄

| 分档 | 内容 |
|---|---|
| **做透** | 可复现检索式；可核验命中台账；新颖性单篇 + 创造性三步法结论有 binding；能交给 ⑤-B/C1；跳过有认风险 |
| **建议同期** | ④ 用报告靶向改交底；同族折叠；中英同义扩展 |
| **可薄** | 多库极致覆盖；正式 FTO；评价报告代办；语义排序高级玩法 |
| **明示不做** | 授权承诺；把科技查新当可专利性终局 |

## 6. 场景验收

| ID | 通过标准 |
|---|---|
| **N1** | 有交底要点 → 出报告：式子可复现、≥1 条可核验命中角色清楚、结论有 binding |
| **N2** | ④ 拿报告改一版交底：修改点能指回报告；发明人确认 |
| **N3** | ⑤ 用报告做 Go + 列出拟进独权的区别特征；或显式跳过查新认风险 |
