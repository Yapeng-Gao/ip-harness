# 链上贯穿 · 情报（创新情报官）

> **不占八节点对外序号**——老板册写在「贯穿」；旗舰专属。  
> **真源**：总纲 §3.9、代理所册「贯穿·情报官」、技术册情报相关、保障计划（若有）。  
> **≠ ⑧ 复盘**（见 [08-复盘](08-复盘.md)）；**≠ 检索本身**（检索是手段，多节点共用）。  
> **产品边界**：⑧ 侧见 [一期-产品逻辑/08-复盘.md](../一期-产品逻辑/08-复盘.md) 附录 B（复盘≠情报≠检索）；本文不另开情报产品逻辑整文。

---

## 0. 情报 ≠ 检索

| | **检索** | **情报（本接口）** |
|---|---|---|
| 是什么 | **手段**：检索式、鉴新、商业库、创新报告取数… | **交付与节奏**：竞对/赛道「发生了什么 → 对您意味着什么 → 怎么办」 |
| 谁用 | **每个需要证据的节点**都可能用 | 旗舰客户 + 顾问/情报官团队 |
| 典型 | ①空间依据、②路径旁相似专利、③挖点对照、⑤查新、创新报告三图 | 格局年报、半年简报、重大信号人工说明 |
| 产出 | 命中、对比文件、疏密图、查新结论… | **签字情报报告/简报**（对经营会说话） |

**一句话：** 检索横切；情报是旗舰上的**竞对盯梢服务**。不要说「情报＝检索」。

---

## 1. 业务逻辑（情报官）

```
客户点名竞对（约 ≤5 家，年内可换）
        ↓
公开信息 + 专利动态等（商业库；底座规划中）
        ↓
年度《研发创新竞争格局分析报告》（签字）
  + 半年《竞对创新动态追踪简报》（签字）
        ↓
（偶发）重大信号 → 顾问人工说明（非自动推送台）
```

只盯点名对手；只答「对您意味着什么」；可上经营会。

---

## 2. 和各节点的关系（可被谁用）

| 节点 | 怎么碰到「检索 / 情报」 |
|---|---|
| ① 立项 | 用**检索**撑空间/竞对照；情报年报可作家底，**非**立项必经 |
| ② 激发 | 路径上可附带相似专利**检索**；≠ 情报官 |
| ③ 挖掘 | 挖点时现有技术**检索**；≠ 情报官 |
| ⑤ 申请 | **鉴新/查新**（见 [接口-查新](接口-查新.md)） |
| 创新报告 | **检索式**出三图/基线（见 [接口-创新报告](接口-创新报告.md)）——可被①②③⑧引用 |
| ⑦ 维护 | 不管情报；管期限年费 |
| **⑧ 复盘** | 自家资产年清；报告里可有薄「竞对动态对照」；**完整情报官交付不并入⑧** |
| 二期监控 | 可持续预警可从情报官加厚长出 |

## 3. 系统现状

| | 状态 |
|---|---|
| 人工 + 商业库出年报/简报 | 现阶段 |

| 自动推送情报台 | **无** |

## 4. 一期够用

- 话术分开：**⑧＝复盘**；**情报官＝贯穿旗舰**。  
- 承认检索横切、情报是竞对交付。  
- 不把鉴新/三图改名叫「情报官」。
