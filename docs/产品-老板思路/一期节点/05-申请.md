## 0. 老板册对齐（一眼）

| 项 | 口径 |
|---|---|
| **谁写** | 深度合作 **5A 级代理所**主笔；挖掘/打磨交底与撰写宜同一批人懂技术 |
| **套餐内** | 标准 1 件 / 旗舰 2 件撰写（不含官费）；超出另议 |

| **不做** | 不把「申请文件审核」当套餐签字权益对外承诺 |

## 1. 这步干什么

委托成立、交底包到手之后：**先把交底理解对并找发明人确认 →（建议）查新并拍申不申 → 定权项 → 写说明书/附图 → 质检 → 人确认后递交。**

```
④ 交卷 / 开案
        ↓
【A】读懂 → 发明人确认 → 补材料 → 放行
        ↓
【B】查新 · 申不申（可弱；建议定了再主写）
        ↓
【C1】权项 → 【C2】说明书+图 → 【C3】质检 · 确认 · 递交
        ↓
⑥ 审查答复（有 OA 时）
```

- **交出去：** 递交回执 / 案号。  
- **谁主操：** 代理人写、审；发明人确认理解、核技术有没有写歪；企业拍保护范围和是否递交。

| 业务 | 落在哪里 |
|---|---|
| 代理人理解交底 | **A** |
| 发明人确认理解 + 补料/怎么改 | **A**（主沟通） |
| 查新（决策/撰写向） | **B**；④ 可选轻检索只喂交底，≠ B |
| 独/从权与保护策略汇报 | **C1** |
| 说明书各块、实施例、附图/公式 | **C2 → C3** |
| 电/机/生医等领域差异 | **贯穿 A～C** |
| 发明人核技术、企业批范围与递交 | **C1～C3**；递交前确认在 **C3** |

## 2. 给谁用

**代理**怕交底空壳、闷头写歪、权项与说明书对不上、形式/实质审查踩雷——需要分阶段工具：理解确认、查新消费、权项树、说明书结构化、质检清单。  
**发明人**怕被问懵、看不懂权项——要先复述再确认，补材料清单化，权项/说明书用人话对照发明点。  
**企业**怕范围黑箱、稀里糊涂递交——范围取舍要可见，重大缩权要知情，递交自己拍板。

**纪律（别踩）：** 理解未确认就定独权；交底粘贴当说明书；无支持特征进独权；超出交底范围加料；无人确认就递交；把 A 当成「还在写交底」。

## 3. 怎么走

```
┌─ 申请（代理案子）──────────────────────────────┐
│  A 接案：理解复述 · 发明人确认 · 补缺 · 放行      │
│  B 查新 / 申不申（可弱）                           │
│  C1 权项：布局 · 独/从 · 与人汇报                  │
│  C2 说明书 + 附图 + 摘要                           │
│  C3 质检 · 企业确认 · 递交回执                     │
└──────────────────────────────────────────────────┘
```

A 与 C1 常来回；查新结论常直接喂 C1「区别特征写进哪」。默认「先事实对齐、再圈地、再铺说明书」，允许回流，**禁止跳过发明人理解确认就锁独权终稿**。

### 3.1 A · 接案

```
读交底
  → 代理人写「理解复述」（发明点 / 问题 / 方案 / 效果 / 必要特征 / 实施例够不够）
  → 找发明人：理解对不对？缺什么？怎么改？
  → 拿不准就讨论，禁止猜事实
  → 放行（或退回）→ 进 B / C1
```

| # | 必问 | 发明人做什么 | 产出 |
|---|---|---|---|
| 1 | 理解对不对 | 纠正错读 | 已确认理解稿 |
| 2 | 发明点 | 主次排序 | 发明点列表 |
| 3 | 技术特征 | 必要/可选/现有技术 | 特征表 |
| 4 | 缺什么材料 | 补图、参数、数据、变体 | 附件 + 修订交底 |
| 5 | 怎么调整 | 选改法 | 修订交底 + 理由 |

**汇报骨架：** 结论 → 依据 → 选项（若有）→ 请你做什么 → 不做的后果。题型：确认题 / 补料题 / 讨论题 / 通知题 / 上升题（权属、公开时点、预算 → 企业/法务）。

**放行：** 理解已确认、阻断级缺项已关或显式认风险挂起，才宜开写权项主路径。老「评估工作台 / 交底审核」手法（六项抽取、发明构思、有根原文）复用在本段，归属是**开案后代理作业**（与 [04 §4.3](04-交底.md) 分界）。

### 3.2 B · 查新与申不申

两件事：**查新（证据）** + **申不申（拍板）**。可弱，但弱也要有人认领。报告怎么生成、新颖性/创造性怎么分析：见 [接口-查新.md](接口-查新.md)。

**查新（证据）**

| 项 | 要求 |
|---|---|
| 目的 | 可专利性证据；标最接近现有技术与区别特征 |
| 输入 | A 已确认理解 / 修订交底；可复用 ④ 轻量材料 |
| 输出 | 检索式可复现；命中台账；区别特征；风险简述；结论 binding 到命中 |
| 谁认 | 代理人出稿；重大「很难授权」同步企业 |
| 可弱 | 跳过须人认风险留痕；④ 做过 ≠ B 自动完成 |
| 禁 | 空命中过关；科技查新冒充可专利性；用 FTO 代替；报授权概率 |

**申不申（拍板）**

| 决策 | 建议 | **决定** |
|---|---|---|
| 申不申 | 代理（依查新） | **企业负责人 / 授权人** |
| 发明/实用等类型 | 代理 | **企业**（预算与策略） |
| 先写再观望 | 代理 | 企业（须显式） |
| 预算/委托是否继续 | 代理报价 | 企业 |

**建议：定了申再重投 C1/C2。** 不申 → 结案归档（可转秘密等），不进撰写主路径。

**交给 C1：** 申的决议（或显式带风险继续写）；区别特征/最接近现有技术（若做了查新）；类型；跳过查新的认风险留痕。

**回流：** 命中致事实不清 → 回 A；致范围要收 → C1 与企业讨论。写说明书主要**消费 B** 写背景/区别；实施例靠发明人；**禁止用检索编造实施例**。撰写中偶发补检允许，重大新命中再报发明人/企业。

### 3.3 C1 · 权利要求

交底里的发明点/特征 ≠ 权项。本段定：哪些进独权、哪些进从权、几组独权、梯度怎么铺。

| 步骤 | 内容 |
|---|---|
| 1 | 发明点 → 保护主题（产品/方法/系统等） |
| 2 | 特征表 + 查新区别 → 独权草案 |
| 3 | 从权梯度（优选、数值、具体结构/步骤） |
| 4 | （建议）删除测试：删哪条会与现有技术撞车/无法实现 |
| 5 | 多发明点：单一性 → 一组多独权或建议分案（企业拍费用） |

**注意：** 这里是**单案权项怎么搭**（独权/从权）。  
≠ ③ 挖掘 UI「布局」=**拆案排案**；≠ 二期导航「战略布局」；≠ 旗舰图2-4 落点矩阵。

| 对象 | 汇报什么 | 谁拍 |
|---|---|---|
| 发明人 | 人话版圈地；技术是否写歪；实施例能否撑独权 | 技术事实、能否实现 |
| 企业/IPR | 范围大小、过宽无效 vs 过窄丢市场、分案费用 | **保护范围与预算** |
| 所内资深（可选） | 策略第二意见 | 不替代企业 |

先给结构图/梯度，再给法条式全文。禁止企业强压交底撑不住的范围；代理可否决明知无支持。权项初稿确认后再大规模写说明书（独权大改则说明书必跟改）。

**进 C2：** 独/从结构（初定或锁定）；发明点 ↔ 权项映射；发明人技术确认 / 企业范围确认（或显式「先写说明书再终确认」）。

### 3.4 C2 · 说明书 + 附图 + 摘要

权项圈地；说明书铺路 + 给支持。交底是原料，**不能把交底章节名直接当说明书写完**。

| # | 块 | 要问清 | 常见雷 |
|---|---|---|---|
| 1 | 名称 | 主题清楚 | 商标、夸张词 |
| 2 | 技术领域 | 分类落点 | 写成产品线名 |
| 3 | 背景技术 | 最接近 + 缺陷（常消费 B） | 贬低对手；未公开秘密当背景 |
| 4 | 技术问题 | 与交底对齐 | 空话 |
| 5 | 技术方案 | 清楚完整、能实现 | 只写结果不写做法 |
| 6 | 有益效果 | 与方案咬合 | 编造数据 |
| 7 | 具体实施方式 | 至少一条可复现；撑权项 | 空壳实施例 |
| 8 | 附图说明 | 图号标号与文字一致 | 图文对不上 |

另：摘要；权项书与说明书分件；实用新型等对附图有法定要求——该有图必须有图。

**图/式/序列：** 发明人供事实与草图；代理（或外协）出申请用图；图意仍要发明人看一眼。公式/化学式/序列表：符号定义、与实施例一致；**AI 可排版，不得编造曲线或结构**。缺事实 → 回 A / 问发明人，不靠搜论文补「做过的事」。

**分领域（主路径相同，换清单）：**

| 维度 | 电学/软件偏电 | 机械/机电 | 化学/生物医药 |
|---|---|---|---|
| A 常补 | 模块/信号/时序/算法步骤 | 装配/公差/工况/草图 | 通式/制备/表征/活性数据/模型 |
| 图/式 | 框图/电路/流程/时序 | 结构/剖视/装配 | 结构式/工艺/曲线/序列表 |
| 权项习惯 | 装置+方法；功能特征要撑实现 | 结构/位置关系取舍 | 通式/组合物/用途；数据撑范围 |
| 实施例 | 可复现配置/流程 | 可装配具体结构 | 数据厚度常决定命运 |
| 雷区 | 只写效果不写怎么做 | 「如图所示」无文字关系 | 通式宽、实施例少；编数据 |

开案标**领域模板** → 带出 A 补料、C2 图/式、C3 质检项。跨领域 = 主模板 + 附加清单。外观设计**另链**，不进本步发明/实用主路径。

**与权项咬合：** 支持（26.4 意识）；公开充分（26.3）；不超交底加料（为日后 33 留后路）。

### 3.5 C3 · 质检 · 确认 · 递交

质检对象是**申请文件**，不是交底。规则资产：[`AI专利申请文件审核规则库.xlsx`](../../各产品开发/申请文件质检/AI专利申请文件审核规则库.xlsx)（**A–J**）；产品按库分档做清单，不整表当唯一 UI。

**A–J 分类（保留边界）：**

| 类 | 审什么 | 主要输入 |
|---|---|---|
| **A** | 形式与基础规范 | 全文 |
| **B** | 语言与清楚性 | 全文 |
| **C** | 方案完整与公开充分 | 说明书、附图、必要时权项 |
| **D** | 全文一致与逻辑链 | 背景/发明内容/权项/实施例/附图 |
| **E** | 交底核心是否进申请文件 | 交底 + 申请文件 |
| **F** | 权项完整与撰写规范 | 权利要求书 |
| **G** | 说明书支持与保护范围 | 权项 + 说明书 |
| **H** | 布局与保护策略（多无直接法条） | 交底 + 权项 + 业务信息 |
| **I** | 客体、单一性、合规 | 全文 |
| **J** | 新创性与现有技术对比 | 权项 + 说明书 + 查新 |

**法律依据纪律：** 直接法定要求写专利法/细则/指南章节；**内部代理策略标明「无直接法定条款」**；条件适用项仅在造成法定后果时才挂对应法条。

**各档主干：** A 形式编号引用；B 术语与清楚；C 可实施与必要附图；D 问题—独权—效果因果；E 交底点不遗漏、概括不改歪事实；F 独权必要特征、从权引用；G 上位/功能/参数有支撑；H 独权过窄、数值限定、主题布局（策略项，企业知情）；I 客体/诚信/单一性；J **有查新才深做**，无查新降级提示、不假装已判可授权。

**一期用法：** 递交前必跑意识 **A+B+C+D+F+G**，有交底对照时加 **E**；**J** 有 B 查新时；**I** 软件/商业/实用嫌疑时；**H** 可先出高风险几条。输出区分「法定风险」vs「内部策略建议」；绿勾 ≠ 可递交。

| 谁 | 确认什么 |
|---|---|
| 发明人 | 技术叙述、实施例、核心发明点 |
| 企业 | 保护范围、公开程度、是否递交；H 类策略知情 |
| 代理 | 质量署名；拒绝明知不可支撑的范围 |

确认 → 递交 → 回执/案号 → 本步完成 → ⑥。1+ 改稿：清单回来联动改权项/说明书，重大缩权再报企业，再跑相关档。

## 4. 人和 AI 怎么分

| 纪律 | 含义 |
|---|---|
| 理解须发明人确认 | 未确认不当「可定独权」 |
| 拿不准须讨论 | 禁止猜事实写实施例 |
| 该报必报 | 阻断缺项、放行、重大缩权、范围选项 |
| 支持与公开充分 | 无说明书依据不进独权终稿 |
| 不超交底加料 | 交底没有的技术不写进申请文件 |
| 质检 ≠ 递交 | 须企业/授权人确认；须回执才算完成 |

AI 可起草复述、特征表、权项树、说明书块、预检；低置信要示弱；不得冒充发明人确认、企业授权、放行结论。

## 5. 跟前后怎么接

### ← ④ 开案应接到

交底包终稿（发明人已确认）；④-b 批准 **或** 无岗跳过标记（二选一）；领域；已知附件；委托人/发明人；委托范围（若已定）。缺项仍开案 → A 补齐并留痕。

### 段间

| 从 → 到 | 要点 |
|---|---|
| A → B | 理解确认；放行；修订交底/特征表 |
| B → C1 | 申的决议；区别特征；类型；跳过认风险 |
| C1 → C2 | 独/从结构；发明点映射 |
| C2 → C3 | 说明书+图/式+摘要齐套 |
| 回流 | C 缺事实 → A；权项大改 → 说明书跟改 |

### → ⑥ 答复交出

案号/递交回执；递交版权项+说明书+附图；查新对比与区别特征（若有）；发明点↔权项映射与版本留痕；企业范围确认记录。详见 [06-答复.md](06-答复.md)。

**分段交卷：** A — 已确认理解、特征表、补料、放行留痕；B — 查新结论或跳过认风险、申不申留痕；C1 — 权项与映射；C2 — 说明书与附图摘要；C3 — 质检、确认、**递交回执**。

## 6. 怎样算走通

| ID | 画像 | 重点 | 过线 |
|---|---|---|---|
| **S1** | 有 IPR 大企业 | A→B 查新+企业申不申→C1 企业拍范围→C2/C3 | IPR 批过交底仍须 A 理解确认；范围与递交企业可见 |
| **S2** | 无 IPR 小企业 | A 变厚→B 可弱但认风险→C1～C3 | 跳过 ④-b 后质量压在 A；老板常拍申不申/递交 |
| **S3** | 生物医药重数据 | 生医清单→通式宽度企业知情→数据撑实施例 | 无编数据；通式与实施例匹配有人认 |

共性：**理解未确认不写独权终稿；无人确认不递交。**

**容易漏、也要有：** 申请类型；单一性/分案；删除测试；术语一致；公开 vs 秘密（企业拍）；优先权/国别（可薄）；请求书著录；委托范围；版本留痕；FTO ≠ 查新（另案或外挂）；外观设计另链。
