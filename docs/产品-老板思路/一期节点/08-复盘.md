# ⑧ 复盘（年末报告）

> 老板「资产年年清」。**年末固定周期**出一份复盘报告（非应要求）。  
> **性质：报告节点**——把一年研发、专利、用系统、上下游与市场相关情况收成可拍板的年报。  
> **情报官**仍拆开：[接口-情报](接口-情报.md)（竞对专报 ≠ 本复盘）。  
> **产品逻辑**：[../一期-产品逻辑/08-复盘.md](../一期-产品逻辑/08-复盘.md)（讨论稿 · 首开；进入/结束门槛；复盘≠情报≠检索）。  
> **真源**：总纲 §3.8、客户册⑧、保障计划⑧、代理所册⑧；章节按一期业务需要加厚。

---

## 0. 这步干什么

**服务年度末主动出具复盘报告**，让老板看见：今年研了什么、专利落到哪、系统用得怎样、链上哪里断、外面市场/竞对薄对照，以及明年养哪些、往哪投。

```
① 项目台账 + 各节点案件/交底/申请/OA
  + ⑦ 确权资产（期限/年费/法律状态）
  + 系统使用留痕（登录、关键动作次数——有则用）
  + 客户访谈：经营变化、上下游诉求
  + （可选）商业库薄对照 / 情报官结论引用
        ↓
标准：《知识产权资产年度盘点》（事务性，可不签字）
旗舰：《知识产权资产年度复盘与策略报告》（专家签字）
        ↓
客户逐件拍维持/放弃 + 认下年策略要点
        ↓
回写 ⑦；策略人工带到下年 ①（项目/方向）
```

---

## 1. 报告写什么（章节骨架）

> 标准版可只做「专利情况 + 费用/期限汇总」；旗舰版尽量覆盖下列块。缺数据处标「未明确」，不编造。

### 1.1 研发情况

| 写什么 | 数据从哪来 |
|---|---|
| 本年在研 / 新建 / 结项**项目**列表（挂①） | ① 项目主数据 |
| 各项目目标一句话、阶段、有无重大转向 | 项目描述 + 访谈 |
| 项目→专利线索/交底/申请的覆盖（有没有「研了却没保护」） | ①×③④⑤ 关联 |

### 1.2 专利情况（确权资产）

| 写什么 | 数据从哪来 |
|---|---|
| 全年新申请 / 审中 / 授权 / 驳回·视撤·放弃 | ⑤⑥⑦ 台账 |
| **逐件**维持 / 放弃建议 + 理由 | 代理师整理；客户拍板 |
| 费用与期限回顾（已缴、将到期） | ⑦ |
| 家族扩展窗口（PCT/优先权/分案等）提醒 | ⑦ 期限 |

### 1.3 使用系统情况

| 写什么 | 数据从哪来 |
|---|---|
| 本年开通/使用过的能力（创见、鉴新、成稿、撰写、OA…） | 产品侧用量或顾问记录 |
| 用得多的环节 vs 几乎没用的环节 | 同上 |
| 对「团队有没有真在用」的一句话判断 + 改进建议 | 顾问归纳 |

> 目的：复盘服务是否空转，不是做产品运营大盘。无埋点则访谈+顾问台账亦可。

### 1.4 上下游情况（链是否通）

| 写什么 | 数据从哪来 |
|---|---|
| **上游**：立项/激发/挖掘 → 交底 是否接得上（断点、积压） | 各节点台账 + 访谈 |
| **下游**：交底 → 申请 → OA → 授权托管 周期与卡点 | ⑤⑥⑦ |
| 代理协同：材料往返次数、理解偏差返工（有则记） | 顾问记录 |
| 比完整情报/供应链分析**更浅**：只写「本企业创新链」上下游，不写行业供应链长文 |

### 1.5 市场情况（薄，可引用情报）

| 写什么 | 数据从哪来 |
|---|---|
| 与本公司方向相关的市场/产品节点变化（客户口述为主） | 访谈 |
| 点名竞对本年专利/公开动态**摘要**（薄对照） | 商业库；或**引用**情报官年报段落 |
| 对下年布局的启示（几条，要可执行） | 顾问归纳 |

**别吞情报官：** 格局深挖、四维信号、点名竞对专报 → [接口-情报](接口-情报.md)。⑧只保留「够支撑维持/放弃与下年策略」的薄市场块；有情报官交付则**引用不重做**。

### 1.6 结论与下年

- 维持/放弃拍板清单（回写⑦）  
- 下年策略：优先级、时机、方向（可作下年①项目输入）  
- （旗舰）专家签字

## 2. 给谁用

| 角色 | 干什么 |
|---|---|
| **客户（老板/总工）** | 读报告；补经营与市场口述；**逐件拍**维持/放弃；认下年要点 |
| **代理师** | 汇总五块素材；出建议与理由；旗舰签字；**主动**按年交付 |
| **平台** | ①⑦与案件聚合；用量统计（有则接）；模板/聚合器规划中 |

---

## 3. 合格意识

1. 专利与费用块与⑦台账**全量一致**（完整度受台账制约）。  
2. 每件维持/放弃有明确建议与理由；拍板留痕。  
3. 研发块能按①项目对齐；对不上的标缺口。  
4. 系统使用、上下游、市场：有数据写数据，无则「未明确」+ 影响说明。  
5. （旗舰）下年策略具体可执行，可回流①。  
6. 不与情报官年报重复灌水；引用标明出处。

---

## 4. 和⑦、情报、①

| | 关系 |
|---|---|
| **①** | 复盘「研发情况」按项目汇总；下年策略喂新建/调整项目 |
| **⑦** | 日常期限年费；⑧年底经营决策；拍板回写⑦ |
| **情报官** | 分开；⑧市场块可引用，不替代专报 |
| **检索** | 手段（薄对照），不是⑧本体 |

---

## 5. 系统现状 · 一期够用

- 现阶段：人工模板拼报告；聚合器/画像底座规划中。  
- 一期够用：按年交出标准盘点或旗舰复盘；五块有则写、无则标缺；维持/放弃有理由；话术⑧＝年末复盘报告，≠情报官。
