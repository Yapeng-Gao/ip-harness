## 文风

像给人看的产品说明，**不像**节点规格书、也不像培训教材里的「痛点表」。

| 少写 | 改成 |
|---|---|
| 进入/离开/本站/硬闸/口径/force | 这步干什么、交什么、别搞混 |
| 「谁用、解决什么疼」 | 短散文：代理这边…研发这边… |
| ⑤-B、Go、disclosure | 业务中文 |
| 文首长训、nodes 权威 | 一句参考链接即可 |

**①～⑧ 已写**；复盘与情报已拆；检索横切 ≠ 情报官交付。
