## 0. 老板册对齐（一眼）

| 项 | 口径 |
|---|---|
| **系统** | OA 分析与答复辅助【有/试用】；策略选项要对客户可见 |

## 1. 这步干什么

**官方通知来了、期限卡着：** 把每条意见拆成争点，选争辩 / 缩限 / 分案等策略，写答复并递交。**保护范围怎么让，企业拍板。**

```
⑤ 已递交 / 进审查
        ↓
收文（补正 / 一通·二通… / 驳回…）
        ↓
【A】拆争点 → 【B】定策略（重大缩限企业拍）→ 【C】起草 → 【D】审核确认递交
        ↓
下一通 / 授权→⑦ / 驳回→复审或放弃（一期可薄）
```

- **开干条件：** 已递交，收到须答复的官方通知（实审请求等可薄挂期限意识）。  
- **本轮交出去：** 答复已递交有回执（或官费闭环）；或授权/驳回/视撤已登记。  
- **谁上场：** 代理人拆点、写策略、写稿；企业拍让不让范围、递不递交；发明人按需补事实/数据。

**不是：** 写一封漂亮回信；预测授权率；把交底/说明书重写充数；在这里首次起草权项（那是⑤）。

---

## 2. 给谁用

**代理**期限紧、意见绕、怕超范围改、怕策略没留痕——要争点清单、策略选项、修改边界提示、陈述草稿、期限可见。  
**发明人**不懂审查在问什么却被要补实验——要人话争点 + 可执行的补料清单。  
**企业/IPR** 怕代理闷头缩权、授权了却没用——**范围损失要可见可选**，策略理由清楚，递交自己拍。  
**审核** 不想通读碰运气——按争点查覆盖、超范围、证据（老「OA答复审核」落 D 前段）。

**纪律：** 超期无升级；超原申请范围加料救命；无策略理由全盘接受审查员缩限；AI 编法条/编对比文件；无人确认就递交答复。

## 3. 怎么走

```
┌─ 答复 ──────────────────────────────────────────┐
│  A 收文：登记期限 · 拆争点 · 对齐申请/对比文件    │
│  B 策略：逐条策略 + 企业拍重大缩限                  │
│  C 起草：修改文本/对照表 · 意见陈述书               │
│  D 审核确认递交：清单 · 企业授权 · 回执             │
└──────────────────────────────────────────────────┘
```

老产品「OA 答复」≈ A+B+C；「OA 答复审核」≈ D 前段。新产品按**一轮 OA 闭环**统一。

### 3.1 A · 收文与解读

**必备：** 审查意见/补正/驳回等原文；现行申请文件（权项+说明书，从 05 或案卷）；通知书列明的对比文件（有则齐，缺则标风险）；历史陈述/上一轮修改（二通及以后）。

**中立解析 vs 策略（必须分岗，禁止混做）**

| 阶段 | 做什么 | 禁止 |
|---|---|---|
| **中立解析** | 只从材料抽结构、拆争点、还原审查员推导链 | 出抗辩策略；补外部知识；推断未写效果；改审查员原意 |
| **策略生成** | 在解析上给争辩/修改/组合选项与推荐 | 编造未披露方案/数据；虚构对比文件；改写审查员结论 |

申请文件速览固定抽：**技术问题 — 技术方案 — 有益效果**（术语跟原文）。装置：部件—连接—功能；方法：步骤—顺序—条件；系统：模块—交互—数据流。

**争点最小字段**

| 字段 | 说明 |
|---|---|
| 争点编号 | 与意见条目对应；不跨法条、不跨对象硬并 |
| 类型 | 新颖性/创造性/清楚/支持·充分公开/形式/实用性/其他 |
| 涉及权项 | 权利要求几 |
| 法条 | 审查员援引的（22.2/22.3/26.3/26.4/33…）；原文无则记「无」，**禁止补号** |
| 对比文件 | 公开号/篇名；无则「无引用」 |
| 逻辑链 | **引用依据 → 对照 → 评价理由 → 结论**（缺环标「原文未明确」） |
| 细分问题 | 短语（如「公知常识断言空心」） |
| 隐含期待 | 原文明确要求才填；否则「无」 |
| 期限 | 以通知书为准 |

对齐：争点 ↔ 申请文件、对比文件；陈述起草后 ↔ 争点映射（每条意见须有对应段落，否则标「未覆盖」）。缺材料列清单；紧急可带缺失风险继续但须人认。

### 3.2 按法条怎么分析（解析阶段仍不编造）

识别到某类争点后，分析盯这些**骨架**（条号以通知书 + 权威法规库为准，部署前复核当期文本）。手法对齐 [`OA答复-提示词终稿`](../../各产品开发/OA答复/OA答复-提示词终稿.docx)。

| 主题 | 常对法条 | 分析主干 |
|---|---|---|
| 新颖性 | 22.2 | 单篇对比是否公开**全部**特征；禁止两篇拼新颖性 |
| 创造性 | 22.3 | **三步法**：最接近 → 区别特征 → 实际技术问题 + 显而易见 |
| 公开不充分 | 26.3 | 技术人员能否实现；缺口→障碍→结论 |
| 支持/清楚 | 26.4 等 | 权项是否得说明书支持；用语是否清楚 |
| 修改超范围 | 33 | 修改能否在原说明书/权项找到依据 |
| 形式/其他 | 细则、22.4 等 | 按指摘逐项 |

多类型并存 → **拆最小单元**，禁止把 26.3 混进创造性判断。

**创造性（22.3）· 三步法 + 抓手**

还原链（只据原文）：最接近现有技术 → 区别特征（落到结构/步骤/参数）→ 实际技术问题 + 显而易见性。  
理由类型：公知常识 / 技术启示 / 拼凑 / 等同替换 / 回溯设题。

| 环节 | 可抠的线索 |
|---|---|
| 起点 | 最接近选偏；动机前提不足 |
| 差异 | 被抽象/等同；漏差异；错对照 |
| 问题 | 过宽；回溯设题；未由差异导出 |
| 动机 | 只说「容易想到」；相反教导；组合代价未评 |
| 公知常识 | 工程选择冒充基础事实 |
| 效果 | 差异—效果—问题链缺失 |
| 修改入口 | 收敛切断组合；边界/非等同；术语对齐 |

**公开不充分（26.3）· 诊断入口**

缺口（参数/步骤/结构/数据/边界…）→ 实施障碍 → 结论。

| 亚型 | 修改倾向 | 争辩倾向 |
|---|---|---|
| 参数缺失 | 补定义或收敛已披露区间 | 已披露未引用 |
| 步骤不可操作 | 补顺序/触发 | 原文已有被漏读 |
| 结构不清 | 补连接/数据流 | 附图已有 |
| 功能无手段 | 补步骤/模块 | 未唯一实现 ≠ 无实现 |
| 数据不足 | 补最小要素或收敛主张 | 缺数据 ≠ 无法实现 |

**硬事实：** 26.3 靠「事后往说明书加新内容」通常救不了（33）——优先争辩已有披露或**缩到已披露范围**。

**新颖性（22.2）：** 单篇对照；漏特征/错对照可争；特征全公开则缩限加区别（企业拍）。  
**清楚/支持（26.4）：** 清楚用说明书已有表述；支持过宽则缩到实施例能撑处。

**法规怎么用：** 结论有根（通知书或法规卡片）；主题封闭；语气保守（禁「必然授权」）；可追溯引用；不做授权概率/一键终稿冒充已确认。

### 3.3 B · 策略

答复首先是**决策**，其次才是写字。每个争点：**争辩 / 修改 / 组合** 三方向、每方向多选项，再给推荐——产品上选项可见、推荐可驳，最终人选定。

每条策略写清：**名称 · 答复逻辑 · 采用原因 · 归属方向**。

| 方向 | 含义 | 谁拍 |
|---|---|---|
| 争辩 | 基本不改或微澄清；拆逻辑链 | 代理建议；企业知情 |
| 修改 | 缩限/澄清/删权项 | **重大缩限企业拍** |
| 组合 | 改一点 + 争一点 | 范围变动部分企业拍 |
| 补实验数据 | 效果/创造性需要 | 发明人供数；企业知公开风险 |
| 分案 | 单一性或止损另案 | **企业拍**（新费用） |

**约束意识：** 能争辩就不改；能改就不分案；但争辩期望低时硬撑 = 多一轮成本——代理给利弊，企业拍。

| 事项 | 建议 | **决定** |
|---|---|---|
| 技术争辩站不站得住 | 代理 | 代理对质量负责 |
| **保护范围缩多少** | 选项+利弊（缩前/缩后人话） | **企业** |
| 是否接受审查员方案 | 代理 | **企业** |
| 延期/放弃 | 代理/流程 | **企业** |
| 是否递交本轮答复 | 代理 | **企业授权** |

**修改边界（进 C 前）：** 33 — 不超原说明书和权项记载；针对通知书缺陷改，不顺手乱改未指摘权项；主动修改窗口与实审时机有关，过窗不能当普通答复改。

**进 C 前交出：** 每争点逻辑链 + 选定策略 + 理由；拟修改要点（特征从说明书哪来）；重大缩限企业确认或显式「先起草再终确认」；发明人补数清单。

### 3.4 C · 起草

| 产出 | 要求 |
|---|---|
| 修改后申请文件（若有） | 权项为主；说明书必要时；不超 33 |
| 修改对照表 | 有改则建议必有 |
| 意见陈述书 | 三段式（下） |
| 证据附件 | 对比摘录、实验、公知常识材料；可追溯 |

**意见陈述三段式**

| 段 | 写什么 |
|---|---|
| **一、修改说明** | 改了哪项、加/删什么、依据在说明书何处 |
| **二、争点分析** | 逐条：审查员观点 → 申请人意见 → 法律/指南依据 → 结论 |
| **三、证据** | 对比分析、实验、公知常识——创造性忌只讲道理不摆证据 |

逐点对照、专业克制；不情绪化；不写「必然授权」。AI 可拆点、逻辑链、选项、草稿、法规卡片检索；人必做策略选定、超范围判断、数据真伪、企业范围确认。

### 3.5 D · 审核 · 确认 · 递交

按**争点单元**查：

| 层 | 查什么 |
|---|---|
| 覆盖 | 每条意见有对应答复 |
| 策略一致 | 陈述与修改一致 |
| 超范围/新风险 | 未引入原申请没有的技术方案 |
| 证据 | 引用真在附件里 |
| 形式 | 期限、签章、齐套（细则以官方为准） |

**≠ 05 申请文件规则库 A–J：** 那服务于递交前写稿质量；这里审**本轮答复是否覆盖争点、是否超范围**。答复大改权项/说明书时可抽跑 05 的 A/F/G 联检，但不把整库当 OA 审核主路径。

| 谁 | 确认什么 |
|---|---|
| 发明人（需时） | 技术解释、数据属实 |
| 企业 | 策略与范围；**授权递交** |
| 代理 | 质量与不超范围 |

递交 → 回执 → 本轮完成 → 继续 OA（回 A）/ 授权（⑦）/ 驳回（复审或放弃，一期可薄）。

**期限与轮次：** 以通知书为准；产品须可见、可催、超期升级；一通、二通各自独立片段；延期企业拍；实审请求等同属审查程序期提醒（可薄）。

## 4. 跟前后怎么接

### ← 05

案号/递交回执；递交版权项、说明书、附图；查新对比与区别特征（若有）；发明点↔权项映射与版本；企业范围确认记录（缩权历史）。

### → ⑦ / 驳回支路

授权 → 进年费/维持（⑦）；下一通 OA → 本轮陈述与修改进案卷，新通知书开新 A；驳回 → 复审期限提醒（一期可只提醒）。

## 5. 怎样算走通

| ID | 画像 | 过线 |
|---|---|---|
| **R1** | 一通创造性，建议缩限 | 争点清；缩前缩后人话给企业；企业拍后再递交；对照表+陈述+回执 |
| **R2** | 审查员读歪，纯争辩 | 策略=争辩；引用说明书定位；无超范围加料；企业知情递交 |
| **R3** | 要补实验数据 | 发明人供数并确认；陈述引用有来源；**无编数据**；公开风险企业知情 |

共性：**超期有升级；重大缩限无企业拍不递交；不超范围。**

| 成功 | 失败 |
|---|---|
| 争点清、策略留痕、范围有人拍、按期递交有回执 | 超期视撤无预警；超范围修改；黑箱缩权；AI 对搓无人认 |

## 6. 一期深度

| 做透 | 中立解析与策略分岗；争点逻辑链；法条骨架（至少 22.2/22.3/26.3/26.4）；策略选项+企业拍范围；三段式陈述；审核覆盖；回执；期限可见 |
| 建议有 | 三步法/26.3 抓手清单；争点↔陈述映射；法规卡片有根；审核问题清单 |
| 可薄/后置 | 复审全文；无效宣告；多国同族看板；官费代缴自动化 |
| 不做 | 授权率预测；不可改终稿冒充已确认 |

**不做：** 首次写权项/说明书（⑤）；交底成稿/IPR 批交底（④）；年费主作业（⑦）；完整复审/无效建模。
