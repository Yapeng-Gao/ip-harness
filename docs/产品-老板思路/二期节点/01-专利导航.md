# 二期 · 专利导航

> 不进第一期八节点，但属于**完整专利生命周期**。  
> 样例：[`燕东微专利导航执行摘要（三页版）.pdf`](../../材料/燕东微专利导航执行摘要（三页版）.pdf)、[`基于Linux的服务器操作系统技术专利导航报告.pdf`](../../材料/基于Linux的服务器操作系统技术专利导航报告.pdf)。  
> **和一期③挖掘里的「布局」不是一回事**——见文末对照。

---

## 1. 这步干什么

站在**产业 / 技术赛道 / 本公司（或某主体）组合**上，回答：

- 这个领域专利格局怎样（全景）  
- 技术枝和申请人摊在哪（导航图）  
- 哪里密、哪里相对空、自己短板在哪（空白与补强）  
- 风险先查什么、组合往哪布（战略布局建议；可含攻防姿态）

交出的是**研判与建议报告**，不是交底，也不是把自家研发资料拆成创新点清单（那是一期③）。

```
选定赛道 / 主体 / 问题（格局？风险？补强？）
        ↓
技术分解 → 检索与统计 → 全景 + 导航图
        ↓
空白/短板 · 对手与诉讼环境 ·（可选）FTO 排查优先级
        ↓
布局与管理建议（往哪补、海内外、质量指标…）
```

---

## 2. 给谁用

- **企业老板 / IP / 战略**：组合强不强、出海有没有筹码、明年补哪。  
- **代理 / 情报顾问**：出导航报告、季度监控。  
- **研发 / 产品**：知道哪些方向公开密、立项前先盯哪些风险点（常接到 FTO 深做）。

小企业很少一上来就买厚导航；旗舰、上市/出海、平台型公司更常见。

---

## 3. 里面几块分别是什么

| 块 | 在问什么 | 样例里长什么样 |
|---|---|---|
| **行业/技术全景** | 赛道技术怎么拆；申请量、增速、国别、谁多 | Linux 报告：产业概述 + 全球/中国态势 |
| **专利导航图** | 全景落到可对照的结构/图上 | 燕东微：技术方向构成；Linux：按模块拆开 |
| **空白点 / 短板** | 哪相对稀、和自己能力是否匹配；自己哪枝弱 | 燕东微：硅光发明少、境外为 0 |
| **风险与排查优先级** | 先查什么（红黄绿），**不是**已经认定侵权 | 燕东微：FTO 三级优先级 |
| **战略布局建议** | 往哪补强、发明/境外比例、监控清单、攻防筹码 | 后续工作方向表；「量够质弱境外无」一类结论 |

进攻/防守在这里是**组合与对抗层面的说法**（有没有交叉许可筹码、主要靠无效还是规避等），不是挖掘产品里给单个创新点贴的「防御」标签。

---

## 4. 交什么

视厚度：

- **执行摘要**（如燕东微三页）：组合基本面、技术画像、诉讼环境、排查优先级、核心结论与下一步。  
- **全文导航报告**（如 Linux 近百页）：研究概况 → 产业 → 整体态势 → 分技术 → 重点申请人 → 本主体与竞对对照 → 研判与建议。

纪律（样例已有）：事实 / 推断 / 未检索到要分层；「未发现诉讼」≠ 不存在；技术分类口径要写清。

---

## 5. 跟一期怎么接

| 从导航 | 可以接到 |
|---|---|
| 补强方向、空白关注点 | ② 激发种子；或研发立项议题 |
| 「某枝要多申发明」 | ③ 挖掘时盯自家资料是否覆盖该枝；或直接进④写点 |
| 红/黄排查点 | **二期 FTO** 深做（claim chart 等） |
| 对手监控清单 | 一期⑧ 复盘/情报，或二期监控站加厚 |

**不要：** 把导航报告当成交底；把「空白」写成「一定能授权」；把导航「布局」说成挖掘里的拆案布局。

---

## 6. 「布局」三义对照（钉死）

| | **二期 · 专利导航** | **一期③ · 挖掘 UI「布局」** | **旗舰图2-4** |
|---|---|---|---|
| 输入 | 赛道/主体/公开专利大数据 + 公司组合 | **自家研发资料** | 基线报告竞争与产品相关度 |
| 核心问题 | 地图、空白、风险、战略上往哪布 | 这些**点**拆几案、主外围、顺序、类型 | 未来 12 个月优先落哪些方向 |
| 「布局」含义 | 组合/海内外/攻防补强 | **拆案排案** | 落点优先级（喂挖掘任务书） |
| 主操 | 顾问/情报 + 企业战略/IP | 代理/IP 工作台 | 报告交付；再进③作业 |
| 一期做不做 | **二期** | **一期做通** | 嵌在基线报告里（非导航厚册） |

---

## 7. 二期怎样算有

- 能按样例结构出一版「导航（可先摘要）」：全景 + 对本主体的结论 + 下一步动作。  
- 文内明确区分事实/推断；空白≠可授权；排查优先级≠侵权结论。  
- 与③挖掘、与 FTO 的边界写得清，销售和交付不混成同一产品。

**一期不做**完整导航产品；材料里的 PDF 作口径与验收参照。
