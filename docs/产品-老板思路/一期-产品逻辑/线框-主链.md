# 主链线框

> **可点原型**：[线框-主链.html](线框-主链.html)（浏览器直接打开）  
> **对齐**：[交互大纲.md](交互大纲.md) · [主链故事板-④⑤⑥.md](主链故事板-④⑤⑥.md)  
> **性质**：低保真结构验收 · **非**视觉定稿 · **非** `apps` 样机

## 含哪些屏

同一壳：**顶栏（部门名 + 合格线 + 回大厅）+ 主栏交付物 + 侧栏①请示②依据③对话**。低保真，页面不缺。

| 屏 | 布局要点 |
|---|---|
| 页面地图 | 一期页面总表 |
| 首次进入 | 短表 + 进大厅 |
| 大厅 | 待办、接待、目标入口、八部、案卷条、设置 |
| 老板待办 | A 待拍 / B 催办 / C 进行中 |
| 接待 | 材料 + 去向建议 + 确认去哪部 |
| ①～⑧ 工作台 | 各部主栏物件不同，壳相同；**⑤须露出 A理解 / B查新·申不申 / C撰写递交** 三段与硬请示分钮 |
| ①②③⑦⑧ 薄合格线 | 进得去 + 合格线一句话 + 禁超卖（厚做未冻） |
| ④→⑤ 工单 | 打包方、三线分词 |
| 案卷 | 材料 / 检查表 / 工单 / 判断痕迹 |
| 设置 | 重开部门说明 |
| 情报说明 | 非第九部门 |
| B1 B2 B5 B6 B7 | 跳部、挡回、不申、超期、只读不拍 |

## 怎么用

1. 浏览器打开 `线框-主链.html`  
2. 顶栏切屏，或按主链/支路按钮走  
3. 对照交互大纲 §8 打勾  

## 不做

高保真视觉；账号组织树；官报真通道；接入 apps 壳。①～⑧ 工作台页都在，主链④⑤⑥交互步更完整。
