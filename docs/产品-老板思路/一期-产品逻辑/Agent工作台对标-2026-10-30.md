界面要点：左栏多任务并行 · 中栏对话（标题+消息+输入）· 右栏结果面板（产物/文件/变更/预览）· Ask / Plan / Craft 模式。

## 可搬模式（各 3–5 条）

### Kimi（截图壳感 + agent 首页/台）

1. **进厅有事可办**：问候 +「今天 N 件事」计数，待办带标签/期限/CTA（home）。
2. **统一委托入口**：大 composer「交给…」+ 快捷目标 chips，不是空目录墙。
3. **谁在做**：多专家横排头像 + 主/协 + 状态 pill（workbench）。
4. **主栏交付 / 侧栏确认**：文书主产出 + 待确认卡真闸（硬请示可揉合）。
5. **登录/壳**：身份选择 +「继续推进」叙事；色不跟橙（纸墨墨蓝）。

### Codex（agent 命令中心）

1. **驾驭一队 agent**：多线程/多任务可切换，上下文不丢。
2. **主栏 = 产物/diff，侧栏 = 对话+轨迹**：人审产出，不在聊天气泡里找成稿。
3. **工具/技能轨迹可见**：agent 在干什么可扫一眼（读文件、写段、跑检）。
4. **审查队列感**：Automations / 完成后进待你审，对齐「要你拍的」。
5. **贴底 composer 始终可用**：对当前 agent / 团队发一句就能驾驭。

### WorkBuddy

1. **三区**：任务列表 | 对话区 | 结果面板（产物预览）。
2. **一句话派活**：自然语言进任务，不是表单迷宫。
3. **多任务并行切换**：侧栏任务轨（咱们揉合为案卷/进行中，不抄成跨案经营 IA）。
4. **可验收结果**：右栏文件/变更可点，对齐主栏文书。
5. **模式感**（Ask/Plan/Craft）：可后期揉合；一期样机用「汇报/请示/执行」语气区分即可。

## 本轮落点（2026-10-30 · 精致度五刀）

样机 README 同步。诚实一句：**密度与驾驭入口又近了一截，仍未追上 Kimi/Codex/WorkBuddy 真产品壳精致度。**

1. 精致度：字阶/间距/卡片阴影收紧，减演示页空旷感（纸墨墨蓝不变）。
2. 并行任务：大厅进行中可切；部台任务条 + 轨迹回放；切案主栏/请示跟变。
3. 定时/催办：顶栏 chip → 轻量飞层（假数据 port 上屏）。
4. ⑤⑥ 文书：权项|说明书|差分（⑥：答复|通知书|差分）真切换分页感。
5. 壳导航：搜索 / 通知 / 案切换飞层可点。
