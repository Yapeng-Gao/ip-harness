## 0. 一期薄合格线（已冻 · 勿厚做）

| 项 | 钉死（一期只认这些） |
|---|---|
| **进得去** | 大厅⑧门可点进（年末/阶段窗口）；要竞对年报应指去**情报接口**，不硬塞⑧ |
| **合格线一句话** | 复盘报告已交用户确认 + 维持/放弃**逐件拍**（或显式「本轮只读不拍」留痕） |
| **禁超卖** | ⑧ ≠ 情报官 ≠ 检索节点；只读不拍**不得**回写⑦；不编造台账没有的数据 |

厚做（五块齐全旗舰、聚合器大盘）仍讨论稿。细节见 §9.1 / §13。

## 1. 部门职责

按**年末固定周期**（或用户认的阶段窗口）把一年（或本阶段）的研发、专利资产、系统使用、创新链上下游与薄市场对照，收成一份**可拍板的复盘报告**。

**硬产出：** 年末/阶段**复盘报告**——至少覆盖意识上的五块：**研发 / 专利 / 系统使用 / 上下游 / 市场（薄）**；标准版可只做「专利 + 费用/期限」；旗舰尽量五块齐全。  
附带：维持/放弃建议清单 → 用户逐件拍 → **回写⑦**；下年策略要点可作①输入（人工带到下年即可）。

**不做：**  
- 把⑧当成**情报官**主场（竞对格局年报、半年简报、点名竞对专报 → [接口-情报](../一期节点/接口-情报.md)）  
- 把⑧当成**检索节点**（检索是横切手段；鉴新/查新/三图另见接口）  
- 日常期限年费托管（那是⑦）；单案 OA（⑥）；首次交底/申请撰写（④⑤）  
- 编造台账没有的数据；用「未明确」处灌水伪装完整

## 2. 产品里有谁（只三类）

| | 说明 |
|---|---|
| **用户** | 真人（老板/总工/代理/IP…谁登录谁是用户）；读报告、补口述、**逐件拍**维持/放弃、认下年要点 |
| **部门** | 复盘部；进门看见名册与工作台 |
| **专家** | **全部是 Agent**；能一个办完不硬拆 |

没有「真人专家席」与用户并列。旗舰《复盘与策略报告》对人签字＝服务交付另走，不进产品编制；系统内可出报告稿与建议。

### 2.1 谁主持——部门负责人（不是前台）

| | 现实 | 本产品 |
|---|---|---|
| **前台** | 大厅引导、领到某部 | 只在大厅 ([01](01-接待与引导.md))；**不进部内派活** |
| **部门负责人** | 科室主办：对接、拆活、盯进度、汇总 | 复盘部 **Agent**（名：部门负责人） |

前台领进门、交案卷；进部后换负责人。用户要「竞对年报」时，负责人应说明走**情报接口**，不硬塞进⑧主路径。

```
用户 ←→ 部门负责人（主持、分配、汇总汇报）
              ↓
     聚合 / 研发块 / 专利块 / 系统·链·市场 / 结论拍板 …（可串可并）
用户也可 ←→ 某专家（盯细块）· 随时看产出
```

惯用上代理更常主操汇总；企业侧常来补经营口述与拍维持/放弃——**系统不按身份锁**。

## 3. 编制：能一个就一个，要拆就拆

均为 Agent。

| 专家 | 对应业务块 | 职责 |
|---|---|---|
| **部门负责人** | 全程 | 收件/门槛、定标准 vs 旗舰、分活、冲突汇总、组织拍板与回写⑦ |
| **聚合专家** | 开卷 | 从①⑦与案件台账拉齐清单；标缺口「未明确」；不编造 |
| **研发块专家** | **研发情况** | 按①项目：在研/新建/结项、覆盖到交底/申请的缺口 |
| **专利块专家** | **专利情况** | 新申/审中/授权等与⑦一致；逐件维持/放弃建议+理由；费用期限回顾 |
| **系统·链专家** | **系统使用 + 上下游** | 用量或顾问台账；链上断点/积压（浅于供应链长文） |
| **市场薄对照专家** | **市场（薄）** | 客户口述 + **引用**情报官段落（若有）；不重做竞对专报 |
| **结论专家** | **结论与下年** | 拍板清单、下年策略要点；组织回写⑦ / 备注喂① |

活少可合并（如「报告专家」兼多块）；逻辑上仍按上表。市场块若无情报可引、用户也不要口述 → 标「未明确」，**不**因此去跑一整份情报官年报冒充⑧。

### 3.1 边界（硬钉）

| | 本部门 | 不是 |
|---|---|---|
| **复盘报告** | 自家资产年清 + 五块意识；可拍维持/放弃与下年要点 | 竞对格局深挖、四维信号、点名竞对专报 |
| **市场块** | 薄对照；够撑维持/放弃与下年几条启示 | 情报官年度/半年交付本体 |
| **引用情报** | 标明出处、不重做 | 把情报全文灌进⑧当「加厚复盘」 |
| **检索** | 可选薄对照手段（商业库摘要等） | ⑧本体；鉴新/查新主路径 |
| **⑦** | 拍板结果回写台账 | 日常年费催缴主作业在⑦ |
| **①** | 研发块按项目对齐；策略可作下年输入 | 在⑧里新建完整立项论证 |

**一句话：** ⑧＝年末/阶段**自家复盘报告**；竞对年报/动态 → **情报接口**；检索横切 ≠ 情报 ≠ 复盘。

### 3.2 合并呈现 · 时序（薄）

| 活量 | 呈现 |
|---|---|
| 标准盘点 | 「复盘专家」兼聚合+专利块+结论（+负责人） |
| 旗舰五块 | 分块专家可分席；市场块无料则「未明确」 |

```
门槛 → 聚合 → 分块成稿 → 用户读稿 →【硬】逐件拍或只读不拍 →（已拍则）回写⑦ → 结束
```

## 4. 必做 · 选做

| | 内容 |
|---|---|
| **必做** | **进入门槛**（§6）→ 出**复盘报告**（至少专利+费用/期限；旗舰尽量五块）→ **维持/放弃建议有理由** → 用户**逐件拍**（或显式认「本轮只读不拍」留痕）→ 结束检查表（§9.1） |
| **强建议** | 研发块挂①；系统使用与上下游有则写、无则「未明确」；市场薄块（口述和/或引用情报） |
| **选做** | 商业库薄对照；引用情报官年报/简报段落；旗舰专家签字（套餐另走）；阶段复盘（非自然年末，须用户认窗口） |

**不能跳过：** 进入门槛检；报告与⑦专利/费用块**全量一致意识**（台账缺则标缺，不编）；结束时留下「是否已拍 / 回写⑦状态」。

**标准 vs 旗舰（产品钉法）：**  
- **标准**：《知识产权资产年度盘点》——事务性；专利+费用/期限为主；可不做人签字。  
- **旗舰**：《知识产权资产年度复盘与策略报告》——五块尽量齐 + 下年策略可执行；对人签字另走。  
缺数据处标「未明确」+ 影响说明，不编造。

### 4.1 请示矩阵（薄）

| 事项 | 档 |
|---|---|
| 聚合拉台账、分块起草、标「未明确」、拟维持/放弃理由 | **自决** |
| 是否引用情报段落、标准 vs 旗舰建议 | **建议后请示** |
| **确认报告可读版**；**逐件维持/放弃**或**只读不拍**；认下年要点；是否回写⑦ | **硬请示** |

Agent 不得冒充「已逐件拍板」「已回写⑦」「情报官专报已由⑧代交付」。

### 4.2 部间谁打包 / 回写（薄）

| 方向 | 谁 |
|---|---|
| → ⑦ 维持/放弃状态 | **⑧ 部门负责人**组织回写（仅已拍）；只读不拍则**明确不回写** |
| → ① 下年要点 | 软交接备注；不在⑧做完整立项 |
| ← 情报 | **引用**已有段落；不派⑧去跑情报官专报 |

### 4.3 手法真源

| 层 | 路径 |
|---|---|
| 业务章程 | [一期节点/08-复盘.md](../一期节点/08-复盘.md) |

## 5. 领域

复盘按**客户组织/台账范围**开卷，不按单案领域死锁。  
单案领域差异体现在专利块理由与研发覆盖说明——**不改变**「聚合 → 分块成稿 → 拍板回写」主路径。

## 6. 进门门槛：有可复盘的对象与窗口

> 通则见 [00 §6](00-用户与系统.md)。大厅点进⑧ ≠ 已过门槛。

**开写报告主作业前：** 须明确**复盘窗口**（年末或用户认的阶段）+ 至少有可依托的**资产/案件线索**（⑦台账和/或①项目和/或案件列表），不是空卷写「年度总结」。

### 6.1 进入检查表（开写前）

| 必备 | 说明 |
|---|---|
| **复盘窗口** | 自然年末，或用户确认的阶段起止；写入案卷 |
| **范围确认** | 本次覆盖哪些主体/台账（本企业、本委托包等）；用户认 |
| **台账线索** | ⑦ 确权/审中清单 **或** ① 项目列表 **或** 案件台账，至少一类非空可聚合 |
| **目标确认** | 标准盘点 / 旗舰复盘；是否本轮要拍维持/放弃 |
| **来源记录** | 前台领进 / 大厅直达 / ⑦ 提醒年清 / 顾问主动开卷 |

### 6.2 两种进法 · 收件

| 来源 | 做法 |
|---|---|
| 前台领进 | **继承**前台字段；核进入检查表差额 |
| 大厅直达 | **短收件** + 进入检查表 |
| ⑦「年底该清」提醒 | 继承⑦范围；仍核窗口与目标 |
| 用户只要「竞对动态/年报」 | **不进⑧主写**；说明走情报接口（可从⑧给链接/工单式说明，不假装已开复盘） |

### 6.3 门槛不过

| 轻重 | 动作 |
|---|---|
| **重**（无窗口、无任何台账/项目线索） | 补范围或回前台/⑦先建台账；**不假装已开写报告** |
| **中**（有专利台账但①项目对不齐） | 可开写；研发块标缺口；不挡专利块 |
| **轻**（无系统埋点、无情报可引） | 留痕「未明确」；系统/市场块可薄或跳过意识项 |

### 6.4 进部后分流（不是一律开写）

| 问题类型 | 谁主责 | 动作 |
|---|---|---|
| **要竞对专报 / 格局年报** | 情报接口 | 说明≠⑧；引用已有则市场块可摘，**不重做** |
| **只要查新/鉴新** | 查新接口 / ⑤ | 不进⑧ |
| **日常年费逾期** | ⑦ | 回⑦；⑧不替代催缴 |
| **单案 OA** | ⑥ | 回⑥ |
| **台账明显不全** | ⑦ / 顾问 | 先补台账或报告中显式「完整度受限」 |

**禁止：** 把情报官交付塞进⑧当硬产出；用检索命中列表冒充复盘报告；无台账却编造全年专利数字。

## 7. 部内怎么干

1. 负责人与用户对齐：窗口、标准 vs 旗舰、是否本轮拍维持/放弃、有无情报可引。  
2. 核对 **进入检查表**；不过则 §6.3。  
3. **聚合**：①×⑦×案件；缺口标「未明确」。  
4. 分块成稿（能一个就一个）：研发 → 专利 → 系统 → 上下游 → 市场（薄）→ 结论。  
5. 用户确认报告可读版本（或分段确认）。  
6. **逐件拍**维持/放弃（或认本轮不拍留痕）→ 回写⑦。  
7. 下年策略要点备注案卷（可人工带到①）；旗舰签字另走。  
8. 走完 **结束检查表**。

```
进入门槛通过
    ↓
聚合台账（标缺）→ 五块成稿（标准可薄）→ 用户读稿
    ↓
逐件维持/放弃（或认不拍）→ 回写⑦ → 下年要点备注 → 结束
```

**市场块纪律：** 优先客户口述 + 引用情报；商业库仅薄摘要；**禁止**在⑧内展开完整情报官年报流程。

并行冲突（例如专利建议与经营口述矛盾）由负责人汇总选项给用户，不私下定案。

### 7.1 人与 Agent（产品钉法）

见 §4.1 请示矩阵。补充：Agent 低置信须示弱（尤其覆盖率、放弃理由）；**不得冒充**台账已全量、拍板已完成、情报专报已交付。

## 8. 向用户汇报什么

| 节点 | 汇报 | 用户常拍 |
|---|---|---|
| 进入门槛 | 窗口/范围/标准·旗舰能否开写 | 补台账 / 改窗口 / 改走情报 |
| 聚合 | 清单完整度、缺口 | 认范围；是否继续 |
| 研发 / 系统 / 上下游 | 覆盖与断点（有则） | 补口述；认「未明确」 |
| 专利块 | 逐件建议与理由；费用期限 | **维持 / 放弃** |
| 市场薄 | 口述摘要；情报引用（若有） | 是否采纳启示；不要⑧代做专报 |
| 结论 | 下年要点草稿 | **认要点**或改；是否回写⑦ |

## 9. 多次不行 · 缺料 · 结案

| 情况 | 做法 |
|---|---|
| 表述/结构不好，数据够 | 限定焦点改报告 → 再读 |
| **台账关键件对不上 / 费用数对不上** | 回⑦核；不空转「优化文笔」 |
| **经营/市场事实没有** | 访谈补；仍无 → 标「未明确」，不编 |
| 用户要完整竞对年报 | **转情报接口**；⑧市场块最多引用 |
| 用户暂不拍维持/放弃 | 可出报告；结束检查表记「未拍」；**不**假装已回写⑦ |

**「本轮只读不拍」＝有效结束路径：** 报告已交用户确认 + 显式留痕 → **可标本部门本轮完成**；**不得**回写⑦维持/放弃状态。之后若要拍，再开一轮或补拍回写。

**不能：** 未过进入门槛标「已复盘」；无拍板却把放弃写进⑦；把情报官未交付说成⑧已含专报。

### 9.1 结束检查表（标本部门完成）

| 必备 | 说明 |
|---|---|
| 进入门槛记录 | 窗口、范围、标准/旗舰 |
| **复盘报告正文** | 至少专利+费用/期限；旗舰尽量五块 |
| 与⑦一致意识 | 专利/费用块已对台账或显式「完整度受限」 |
| 维持/放弃 | 已逐件拍 **或** 用户认「本轮只读不拍」留痕 |
| 回写⑦ | 已拍则回写状态可见；只读不拍则**明确未回写** |
| 下年要点 | 有则入案卷；无则备注「未做策略块」 |
| 缺口与引用 | 「未明确」项；情报引用出处（若有） |
| ≠ | 情报官专报齐套；⑦日常催缴办结；①立项论证成文 |

### 9.2 走通画像（薄）

| ID | 画像 | 产品上必须看见 |
|---|---|---|
| **Y1** | 有台账、代理主操年清 | 进入窗口；专利块对⑦；逐件建议+用户拍或认不拍 |
| **Y2** | 小企业、台账薄 | 标准盘点可；缺口「未明确」；不编数字；系统/市场可极薄 |
| **Y3** | 旗舰且已有情报官交付 | 市场块**引用**不重做；⑧仍交复盘报告本体 |

共性：**⑧交出复盘报告；竞对专报不在⑧硬产出里。**

### 9.3 容易漏（产品意识清单）

| 项 | 产品意识 |
|---|---|
| 标准 vs 旗舰 | 开卷就认；勿默默按旗舰灌水 |
| 阶段复盘 | 须用户认窗口；话术仍叫复盘报告 |
| 家族扩展窗口 | 专利块提醒即可；深 PCT 不在⑧做完 |
| 系统使用 | 无埋点则访谈/顾问台账；目的＝服务是否空转 |
| 上下游 | 只写本企业创新链断点，不写行业供应链长文 |
| 情报引用 | 出处；禁止整份专报粘贴冒充五块齐全 |
| 回写⑦ / 喂① | 拍板回写可见；策略到①可人工 |

## 10. 依据链

| 环节 | 要求 |
|---|---|
| 聚合 | 条目可对回①/⑦/案件；禁编造件数 |
| 专利建议 | 理由可核（法律状态、费用、布局意图等）；拍板留痕 |
| 研发/链/系统 | 有数据写数据；无则「未明确」+ 影响 |
| 市场 | 口述可溯；情报引用标出处；检索命中若用须可核 |
| 结束 | 结束检查表齐 |

## 12. 用语对照

| 业务章程 | 产品逻辑 |
|---|---|
| 年末复盘报告 / 资产年年清 | ⑧硬产出；标准盘点或旗舰复盘 |
| 五块：研发/专利/系统/上下游/市场 | §1 + §3 编制；标准可薄专利块 |
| 情报官分开 | §3.1；竞对年报/动态 → 接口-情报 |
| 检索是手段 | ≠⑧本体；≠情报 |
| 维持/放弃回写⑦ | 结束门槛与 §9.1 |
| 下年策略喂① | 软交接；不在⑧做完整立项 |
| 主动按年交付 | 产品支持顾问开卷；不强迫用户每日进⑧ |

## 13. 一期够用

用户↔负责人↔专家；进入检查表；五块意识（标准可薄）；人拍维持/放弃；回写⑦；结束检查表；Y1–Y3；**复盘≠情报≠检索**钉清。

**一期可薄：** 聚合器/画像底座、系统埋点大盘、复盘会仪式、基线表自动比对。  
**不做：** 情报官专报并入⑧；用⑧替代⑦催缴；在⑧内做完整查新/申请/OA；编造台账数据。

## 附录 B · 复盘 ≠ 情报 ≠ 检索（边界一页）

> 产品逻辑边界挂此；情报侧产品逻辑**不另开整文**，见业务 [接口-情报](../一期节点/接口-情报.md)。

| | **⑧ 复盘** | **情报官（贯穿）** | **检索** |
|---|---|---|---|
| 是什么 | 年末/阶段**自家**资产与链上情况报告 | 点名竞对「发生了什么→意味→怎么办」 | 手段：命中、查新、三图取数… |
| 硬产出 | 复盘报告 + 维持/放弃拍板痕迹 | 签字年报/半年简报等 | 命中与结论素材 |
| 市场/竞对 | **薄**；可引用情报 | **厚**；专报主场 | 可被⑧或情报调用 |
| 谁主场 | 复盘部 | 旗舰贯穿能力（大厅不设第九部） | 多节点共用 |

**禁止话术：** 「⑧就是情报官」「做完复盘就等于交了竞对年报」「情报＝去检索一下」。
