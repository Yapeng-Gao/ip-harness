## 5. 带教 · 沉淀（理念红线 · 设计钉 · 一期薄）

> 全部门默认遵守；交互稿再细化 UI。不另开专家席。

| | 钉法 |
|---|---|
| **带教** | 脚手架：首次进部可多一句「本步要你拍什么」；熟客/代理直达、可跳过长分诊与重复说明；**不是**价值承重墙 |
| **沉淀** | 优先留**判断痕迹**（硬请示选项+理由摘要、认风险留痕、全绿/过线摘要）；不把「点了多少按钮」当核心资产 |
| **示弱** | 低置信须标明存疑/建议复核（各部已有意识句）；不硬给假绿勾 |
| **交互语言** | 对外：专家 / 部门 / 请示；不默认「模型 / Prompt / Agent」 |

一期可薄：风格标签、长期「懂我」记忆、Agent 毕业通道——记入故事板 14 问，不阻塞编制收束。
