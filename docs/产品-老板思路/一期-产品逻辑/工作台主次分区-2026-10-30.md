## 1. 一句话

**工作台是「文书作业台 + 领导拍板台」**：主栏持有交付物；**拿不准 / 关键关 / 硬请示 / 重要节点一律以对话流「汇报」气泡**出现（结论 + 依据链 + 可选则），不落侧栏表单卡；侧栏只做编制/composer 驾驭。一键黑箱不上屏。

## 2. 主展示 vs 次要

### 2.1 主展示（首屏必须看见 · 最大面积）

| # | 物件 | 为什么是主 | skill / 大纲依据 |
|---|------|-----------|------------------|
| 1 | **主栏交付物**（④交底书 / ⑤权项·说明书 / ⑥答复·对照） | 用户拿到后要签字/改稿；产物旁置，不活在气泡里 | 大纲原则 8、§4.4.2；理念「交付物可核验」；RDI 第一步交付物清单 |
| 2 | **对话流汇报气泡**（结论 + 依据链 + 确认/改/暂停） | 领导只在关键节点拍板；未确认不得推进下游；**凡拿不准/关键关/硬请示/重要节点都进对话流，不藏侧栏表单** | 理念 §3–5「别让 AI 偷拍板」；理念条目 04；大纲 §5.1；RDI 第四步 P0 人类签字；Leslie 钉：汇报进对话流 |
| 3 | **依据链入口**（可点 → 主栏定位） | 领导能签字的前提是底稿完整 | 理念 T4 / 条目 04；大纲 §4.4.8；RDI 第三步依据链固定格式 |

### 2.2 次要（默认可折 / 飞层 / 轻量收）

| # | 物件 | 放哪 | 规则 |
|---|------|------|------|
| 1 | **进行中案切换** | 壳顶单行薄轨 | 常显但矮；轨迹进飞层 |
| 2 | **编制 / 专家名册** | AI 区可折条 | 主笔可展；老板轻量默认藏 |
| 3 | **负责人身份** | 编制横滑席一行（`single-rail`） | **只出现一次**；不另起 lead-bar 双身份 |
| 4 | **团队动态 / 闲聊** | 对话流可滚 | 与汇报气泡同轨；硬请示也是汇报气泡，不再侧栏另钉 |
| 5 | **段进度时间线** | 主栏顶薄条或轻量藏 | 服务定位，不抢文书 |
| 6 | **带教 / 工具芯片 / 检索示意 / 版本切换** | 飞层或折叠 | 带教淡出（理念 11）；获取类不挡判断类 |
| 7 | **操作记录** | 案卷抽屉 | 考勤表 ≠ 判断档案（理念 10；工程审计） |

## 3. 区域划分

```
┌─ 壳顶（矮 · 常显）─────────────────────────────────────┐
│ 回大厅 · 部名 · 合格线 · 案名/期限/偏好 chip │ 进行中薄轨 │
├──────────────────────────────┬──────────────────────────┤
│ 【主栏 · 最大】                │ 【AI 右栏 · 驾驭】        │
│ 交付物全文 / 分页 / 差分      │ ① 编制横滑席（负责人一行）│
│ 质检锚点 / 版本可切（次）     │ ② 对话流：汇报气泡（主） │
│ 期限/偏好不落主产出正文       │    · 拿不准/关键关/硬请示   │
│                              │    · 结论+依据+可选则     │
│                              │ 底：composer 钉底（辅）  │
└──────────────────────────────┴──────────────────────────┘
```

### 3.1 壳顶

- **放**：部名、合格线状态、案名/期限 chip、进行中薄轨（无「密度」三钮；轻量/主笔靠进部默认与点编制/主产出）。  
- **不放**：全宽身份墙、编制墙、密度三钮、主产出上的期限条；硬请示不进壳顶。  
- **高**：尽量矮；带教一条可关。

### 3.2 主栏（文书 · 最大）

- **宽**：`1fr` 吃满剩余；右栏固定约 **320–340px**（不抢主栏）。  
- **放**：当前段主产出；版本「当前稿 / 上一确认稿」；diff 对照；锚点高亮。  
- **轻量态**：只读/结论摘要优先；大编辑控件可收。

### 3.3 AI 右栏（驾驭）

| 序 | 层 | 内容 | 布局约束 |
|---|---|---|---|
| 1 | 编制席 | 负责人 + 专家横滑（`single-rail`） | **负责人只此一行**；无独立 lead-bar |
| 2 | **对话流** | **汇报气泡**（拿不准 / 关键关 / 硬请示 / 重要节点）+ 追问 / 自决 | 气泡含结论 + 依据（来源·推演·对比·置信）+ 可选则；**不落侧栏表单卡** |
| 底 | composer | @材料 + 一句话驾驭 | **钉在 AI 区底**；辅，不是唯一中心 |

**Leslie 钉（样机）**：凡拿不准、关键关、硬请示、重要节点，一律以对话流汇报消息出现；不要漏、不要只藏在侧栏表单。

## 5. 密度态（同一壳 · 无 UI 三钮）

轻量 / 主笔由进部默认与点编制/主产出切换，**壳顶不放密度切换钮**。

| 态 | 主栏 | AI 区 |
|----|------|-------|
| **老板轻量** | 文书可读；时间线可藏 | 汇报气泡仍在对话流首屏；编制可折 |
| **主笔** | 全文可改；结构旁路可开 | 对话展开；编制可展 |

禁止：用换壳假装换身份；轻量态藏掉硬请示/汇报气泡。

## 7. 验收（本文件对应样机）

- [ ] 主栏面积明显大于 AI 栏；文书首屏可读；期限/偏好不在主产出正文
