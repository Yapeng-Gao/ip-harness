## 1. 部门职责

把在管案件的**关键期限与费用**管住：以官方凭证为准录入台账 → 系统算期并提醒 → 费用可查、**缴费前用户确认** →（旗舰）季度巡检兜底。

**硬产出（持续）：** 期限台账条目（可核）+ 到期提醒状态 + 费用明白账条目（缴费确认留痕）。  

**不做：** 写新案/答 OA 正文；侵权监测/诉讼台；年度策略复盘叙事（⑧）；把报告 2.3「体检建议」说成⑦产品本体；假装已有完整年费 SaaS 看板（D12/D13 缺口见业务文）。

---

## 2. 产品里有谁（只三类）

| | 说明 |
|---|---|
| **用户** | 谁登录谁是用户；查期限/费用、缴费前确认、维持/放弃拍板（多参考⑧） |
| **部门** | 维护部（确权资产托管） |
| **专家** | 全部 Agent；能一个办完不硬拆 |

套餐/旗舰「顾问巡检」对人签字＝服务交付另走；系统内可出巡检清单与异常汇报。  
组织里要「代理录入 + 企业拍缴费」→ **换人登录**或同一人兼拍留痕（[00 §6.1](00-用户与系统.md)）。

### 2.1 谁主持——部门负责人（不是前台）

| | 本产品 |
|---|---|
| **前台** | 大厅分诊；不进部内派活 |
| **部门负责人** | 收件/门槛、分活、盯提醒升级、汇总异常、组织缴费确认与巡检汇报 |

```
用户 ←→ 部门负责人
           ↓ 分配
     录入核对 / 期限提醒 / 费用明白账 /（旗舰）巡检 …（可串可并）
用户可 1:1 某专家 · 随时看台账与费用
```

惯用上代理更常主操录入；企业侧常来确认缴费与维持/放弃——系统不锁身份。

## 3. 编制：能一个就一个，要拆就拆

| 专家 | 对应业务段 | 职责 |
|---|---|---|
| **部门负责人** | 全程 | 收件/门槛、分活、冲突汇总、盯超期升级、组织确认与汇报 |
| **录入专家** | **A** | 以官方凭证登记申请号/申请日、OA 日、授权日、状态等；**二次核对**意识；错一天下游全错 |
| **期限专家** | **B** | 算关键期限；挂三级提醒；超期升级可见；回写与⑤⑥期限意识对齐 |
| **费用专家** | **C** | 官费/年费/服务费入明白账；缴费前推确认；不代拍缴不缴 |
| **巡检专家** | **D（旗舰）** | 按清单查期限/状态/费用异常 → 有事即报；标准档可无此岗 |

活少可合并（如录入+期限、费用+负责人）；逻辑上仍分岗。  
**硬纪律：** 录入以**官方凭证**为准；未二次核对不得当「已可信台账」对外承诺零错过。

### 3.1 边界

| | 本部门 | 不是 |
|---|---|---|
| 期限 | 答复/缴费/年费等关键期可见、可催、超期升级 | ⑥ 答复正文与策略；完整复审建模 |
| 年费/官费 | 提醒 + 明白账 + 缴费前确认 | 自动代缴已接通官报（实现后置）；完整成本看板（D13 缺口） |
| 状态 | 台账状态字段可更新 | 完整案件状态机 + 客户看板已交付（D12 缺口） |
| 养/砍 | 执行缴费；放弃后更新台账 | ⑧ 年度维持/放弃策略本体；报告 2.3 体检当主业 |
| 情报 | — | 竞对监测、侵权诉讼台（另链/二期） |

### 3.2 合并呈现 · 时序（薄）

| 活量 | 呈现 |
|---|---|
| 标准档 | 「托管专家」兼 A+B+C（+负责人） |
| 旗舰 | 另开巡检席 D |

```
门槛 → A 录入·二次核对 → B 挂期限提醒 → C 明白账 →【硬】缴费确认（有应缴时）；D 按季可选
```

持续运行态：提醒/升级可见，非一次性交卷绿灯。

## 4. 必做 · 选做

| | 内容 |
|---|---|
| **必做** | **进入门槛**（至少一件可入账官方要素，§6）→ **A** 凭证录入 + 二次核对 → **B** 关键期限挂提醒 → **C** 相关费用入账；**缴费前用户确认** |
| **强建议** | ⑤递交当日申请号/申请日入账；⑥通知/回执当日对齐期限；授权后年费链立刻挂上 |
| **选做（旗舰）** | **D** 季度巡检；异常主动汇报 |
| **选做（薄）** | 短信/邮件外发渠道（D11 缺口：现可仅系统内）；多国同族年费一览 |

**缴费确认不能跳过（有应缴时）。** 未确认不得标「已代用户决定缴纳」。  
**录入二次核对不能当可有可无**——业务钉最大单点风险（D10）；一期至少产品层强制「核对留痕」，自动化校验可后补。

**本部门合格线（产品钉法）：**  
不是⑤「过线」或⑥「D 过线」那种一次性交卷绿灯，而是**托管纪律过线**：关键要素在台账且可核凭证 → 关键期限已挂提醒 →（有费用时）明白账可查且缴费经用户确认。  
台账【有】≠ 看板已交付；**未建看板不得写成已交付年费管理系统**（对齐业务 §3、§6）。

**提醒渠道（一期钉法）：** 产品负责**系统内**三级提醒可见可催；短信/邮件等外发 **D11 缺口**，不在本文承诺已接通。

手法（期限算法、巡检清单细目）→ [业务章程](../一期节点/07-维护.md) + 保障计划/代理所册；**产品逻辑不抄全文**。

### 4.1 能力真源与缺口（勿超卖）

| 层 | 状态（对齐业务） | 产品怎么说 |
|---|---|---|
| 期限台账 + 系统内提醒 | **【有】** | 主路径可承诺「台账能跑、三级提醒在」 |
| 费用台账 | **部分有**（模板人工） | 明白账可查；不假装 D13 看板已上 |
| 录入二次确认 / 逻辑校验 | **无 → D10** | 产品层先做人/Agent 核对留痕；自动校验后补 |
| 短信/邮件提醒 | **无 → D11** | 仅系统内；外发后置 |
| 案件状态机 + 客户看板 | **无 → D12** | 状态字段可薄；不写「看板已交付」 |
| 年费成本看板 / 费用预警 | **无 → D13** | 费用条目+提醒；不写完整成本看板 |
| 旗舰季度巡检 | 流程有、人工清单 | 选做 D；系统可出清单与异常汇报 |

### 4.2 两档（老板口径 · 产品层）

| 档 | 产品必须看见 |
|---|---|
| **标准** | 系统提醒 + 明白账自查；录入义务可见；缴费前确认 |
| **旗舰** | 标准全部 + **D 季度巡检**（期限/状态/费用异常 → 有事即报） |

## 5. 领域

继承案卷领域即可；维护主路径不因领域改 A→B→C。  
生医等年费/维持节奏若有差异 → 附加提醒清单，不另开部门。

## 6. 进门门槛

> 通则见 [00 §6](00-用户与系统.md)。大厅点进⑦ ≠ 已过门槛。

**开干主作业前：** 通常须有**至少一件可入账的官方要素**（受理回执/申请号、官方通知、授权证书、缴费通知等）或⑤⑥回流字段。  
仅有交底、尚未递交 → 应去⑤，不在此假装已有确权/审中资产可托管。  
还在写答复正文 → 主作业在⑥；⑦只收期限/回执回流。

### 6.1 进入检查表

| 必备 | 说明 |
|---|---|
| 入账对象 | 案件/项目可识别（案卷或申请号） |
| 官方凭证或可信回流 | 回执/通知书/授权文件/缴费通知等；或⑤⑥已回写字段 |
| 关键日意识 | 申请日 / OA 期限日 / 授权日 / 年费基准日——缺则列清单，不空算期 |
| 来源记录 | ⑤当日回流 / ⑥回执·通知 / 大厅自带 / 前台领进 |
| 档位（若适用） | 标准 / 旗舰（影响是否派 D） |

### 6.2 收件对照

| 来源 | 做法 |
|---|---|
| **⑤ 递交成功** | **当日**继承申请号、申请日等入台账（与 [05 §7 / §9.1](05-申请.md) 对齐）；核进入检查表 |
| **⑥ 回执 / 通知 / 授权·驳回** | 更新期限与状态；答复期限与回执对齐；授权→挂年费链 |
| 前台领进 | 继承前台字段；核差额 |
| 大厅直达（上传证书/年费单/「别超时」） | 短收件 + 进入检查表 |
| ⑧ 维持/放弃拍板回写 | 更新费用与期限台账；不重做⑧叙事 |
| 无申请号且未递交 | 拒开托管主路径；建议⑤ |

### 6.3 门槛不过

| 情况 | 动作 |
|---|---|
| 无可核凭证且无⑤⑥回流 | 不进入 A 主作业；引导补传或回上部门 |
| 有申请号无申请日（或关键日矛盾） | 列缺项；**禁止**用猜测日挂正式提醒当真源 |
| 仅要「年底复盘报告」 | 引导⑧；⑦可提供台账底数，不做复盘正文 |
| 仅要竞对情报 | 另链；≠⑦ |

### 6.4 进部后问题分流

| 问题类型 | 谁主责 | 动作 |
|---|---|---|
| 缺凭证 / 日期对不上 | A | 二次核对；以官方为准改台账；留痕 |
| 提醒未挂上 / 算错期 | B | 重算；超期升级；不得静默 |
| 费用说不清 / 未确认就想标已缴 | C + 用户 | 补明白账；**缴费前确认** |
| 要写答复 / 改权项 | ⑥ / ⑤ | 开工单离开⑦主路径 |
| 要年度养/砍策略 | ⑧ | ⑦执行回写；不做策略长文 |
| 录入错致风险 | 负责人汇总 | 按业务责任口径暴露；产品先保证可追溯 |

### 6.5 期限 · 提醒 · 超期升级（产品钉法）

| 规则 | 含义 |
|---|---|
| **期限真源** | 以官方凭证 / 通知书记载为准；登记进台账 |
| **三级提醒** | 到期前 **30 / 15 / 7** 天（业务口径）；部门内与负责人汇总可见 |
| **可催** | 临近节点提醒当前用户；渠道一期以系统内为主（D11） |
| **超期升级** | 逾期未处理 → 状态升级可见（不得静默）；选项含补救路径 / 放弃等（**用户拍**） |
| **与⑥分工** | ⑥ 盯本轮答复作业与部内催办；⑦ 管资产级台账与跨事件期限总账——可双向对齐，不互相替代正文作业 |
| **⑤当日入账** | 申请号/申请日等**递交当日**入⑦；晚入＝不合格路径意识 |

## 7. 部内怎么干

1. 负责人对齐：目标＝权利不掉线（期限+费用明白）；档位（标准/旗舰）。  
2. 核对进入检查表；⑤当日回流优先落 A。  
3. **A** 凭证录入 → **二次核对留痕**。  
4. **B** 挂关键期限与三级提醒；与⑥本轮期限对齐（若有）。  
5. **C** 费用入明白账；应缴时推用户确认后再标缴费意向/已缴（实缴通道实现后置）。  
6. （旗舰）**D** 按季度巡检 → 异常汇报用户。  
7. ⑧拍维持/放弃后 → 回写台账；有新 OA → 期限入账并可由用户开⑥。

```
进入门槛通过
    ↓
A 凭证录入·二次核对 → B 期限·三级提醒 → C 明白账·缴费前确认
    ↓ 旗舰
  D 季度巡检（有事即报）
    ↓
  持续托管；⑧拍板回写；新通知 → 更新台账（正文作业回⑥）
```

**禁止：** 无凭证猜日期挂正式真源；未确认缴费却标用户已同意缴纳；把看板缺口写成已交付；把⑦做成情报站或⑧复盘主场；⑤已递交却长期不入台账。

### 7.1 请示矩阵（薄）

| 事项 | 档 |
|---|---|
| 抽字段、算期、挂提醒、费用分项、巡检清单 | **自决** |
| 超期升级选项、旗舰巡检异常处理建议 | **建议后请示** |
| **二次核对矛盾确认**；**缴费前确认**；超期程序选择；维持/放弃执行（常接⑧拍板） | **硬请示** |

Agent 低置信须示弱；**不得冒充**已二次核对、用户已同意缴费、看板能力已上线。

### 7.2 部间谁接 / 谁回写（薄）

| 方向 | 谁 |
|---|---|
| ← ⑤/⑥ 回流 | **⑦ 负责人**接要素；录入/期限专家落账 |
| ← ⑧ 维持/放弃拍板 | 负责人/录入更新台账状态 |
| → 不主动开⑥正文 | 期限催办可链用户去⑥；答复本体在⑥ |

## 8. 向用户汇报什么

| 节点 | 汇报 | 用户常拍 |
|---|---|---|
| 进入 / 录入 | 入账了哪些；缺哪张凭证 | 补传；确认矛盾字段 |
| 提醒 | 下一个关键截止日；三级节点 | 知情；安排缴费/答复（答复正文去⑥） |
| 费用 | 明白账分项；应缴金额与名目 | **是否缴**；服务费异议 |
| 超期升级 | 已过期项与选项 | 补救 / 放弃等 |
| 巡检（旗舰） | 异常清单 | 逐项是否处理 |
| 与⑧衔接 | 台账底数供复盘；⑧拍板结果回写确认 | 维持/放弃后是否更新台账 |

## 9. 多次不行 · 缺料 · 结案

| 情况 | 做法 |
|---|---|
| 录入反复对不上 | 停用猜测日；追官方凭证；升级负责人汇总 |
| 提醒骚扰或漏提醒 | 调配置（产品不锁死天数以外的文案）；漏提醒按超期升级暴露 |
| 费用争议 | 分项对凭证；不抹账 |
| 用户暂不缴费 | 暂停缴费动作；**期限仍可见催办**（§6.5） |
| 「结案」含义 | ⑦多为**持续托管**；单笔动作（录入完成/本笔缴费确认/本季巡检）可勾结束检查表，不等于资产退出 |

### 9.1 结束检查表（按动作勾选）

**（1）单笔录入完成**

| 必备 | 说明 |
|---|---|
| 凭证引用 | 可回指回执/通知/证书等 |
| 关键字段 | 申请号、关键日、状态等已落 |
| 二次核对留痕 | 人或 Agent 核对记录；矛盾已关闭或认风险 |
| 期限已挂 | 本笔触发的关键期已进 B |
| ≠ | 已授权承诺；看板大屏已有 |

**（2）单笔缴费确认完成**

| 必备 | 说明 |
|---|---|
| 明白账分项 | 官费/年费/服务费可分列 |
| 用户确认 | 缴费前确认留痕 |
| 台账回写 | 意向/已缴状态与日期（实缴通道后置则标「确认待缴」亦可） |
| ≠ | 用户未拍却标已缴；D13 成本看板已交付 |

**（3）旗舰季度巡检完成**

| 必备 | 说明 |
|---|---|
| 巡检清单跑过 | 期限/状态/费用 |
| 异常已报或「无异常」留痕 | 有事即报 |
| ≠ | ⑧年度复盘正文 |

### 9.2 走通画像（产品验收意识 · M1–M3）

产品过线用 §9.1；对齐业务「期限零错过 / 明白账 / 官方凭证」：

| ID | 画像 | 产品上必须看见 |
|---|---|---|
| **M1** | ⑤刚递交 | **当日**申请号/申请日在⑦台账；二次核对留痕；后续期限可挂 |
| **M2** | ⑥来了通知/回执 | 期限入账；三级提醒可见；正文作业不在⑦冒充已答 |
| **M3** | 授权后首年年费 | 年费链路挂上；明白账可查；**缴费前用户确认**；标准档无强制 D，旗舰有巡检入口 |

共性：**无凭证不瞎算期；无确认不代缴决定；看板缺口不超卖。**

### 9.3 容易漏（产品意识清单）

| 项 | 产品意识 |
|---|---|
| ⑤当日入账 | 与申请部结束检查表硬对齐 |
| OA 多轮 | 每通期限独立条目或可区分轮次；勿只留最后一次 |

| 维持/放弃 | ⑧拍板后必须回写⑦ |
| 服务费 vs 官费 | 明白账分列 |
| 外发提醒 | D11；勿写已短信必达 |
| 看板/状态机 | D12/D13；台账有 ≠ 看板有 |
| ≠2.3 / ≠⑧ / ≠情报 | 边界见 §3.1、§11 |

## 13. 一期够用

用户↔负责人↔专家；进入检查表；A 凭证录入+二次核对 → B 三级提醒 → C 明白账与缴费确认；⑤当日入账；⑥回流对齐；结束检查表按动作；M1–M3；缺口 D10–D13 **照实写、不超卖**。

**一期可薄：** 短信/邮件外发、自动逻辑校验、完整状态机与客户看板、年费成本看板、多国同族、官费代缴自动接通、复审期限深度建模。  
**不做：** 把看板当已交付；把⑦做成情报/⑧复盘/2.3 体检产品；答复/申请正文；无凭证瞎算期；未确认代拍缴费。
