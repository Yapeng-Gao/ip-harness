# Kimi 复用清单（2026-10-30）

> **对照截图（只读）**：`tools/_tmp_shots/mpv2-close/v3-kimi-{home,workbench,projects,site,login}.png`  
> **样机落点**：`docs/prototype/main-path-sample/` · 六维见 [高保真六维](高保真六维-2026-10-30.md)  
> **原则**：借 **壳感 / 委托链 / 可信交付 / 密度与精致度 / 可 port 能力**；**IA 仍是老板大厅八部**。不整仓替换、不抄跨案经营首页、不把 Kimi 橙当品牌色。

---

## 0. 怎么用本清单

| 标记 | 含义 |
|---|---|
| **直接复用** | 形态/交互可按截图落地到样机或后续实现（改名、改色即可） |
| **揉合复用** | 取理念或局部控件，接到咱们八部 / 硬请示 / 双角色 |
| **能力 port** | 基础设施可搬（定时任务等），不重造 |
| **禁抄** | 会冲咱们 IA / 理念 / 品牌；对照即可 |

## 3. 样机头像 / 多专家展示（本轮落点）

对照 `v3-kimi-workbench`「谁在做」，样机④须满足：

| 验收句 | 落点 |
|---|---|
| 编制按真编制露头，不卡死 ≤3 | 交底部 demo **5–6** 席（负责人+成稿+润色+检索选做+质检〔+可选顾问灰显〕） |
| 头像岗＝人像，不是纯色块字 | `main-path-sample/avatars/*.jpg` 照片圆头像；字头像仅作回退 |
| 主/协 + 状态 pill | 主/协标签；已完成 / 进行中 / 待审 / 未请来 |
| 质检席单独可辨 | `kind:qc` 不与成稿合并名片 |
| 可点聚焦 | 点名片 → `activeExpert`；侧栏动态仍辅 |
| 色不跟 Kimi 橙 | 纸感底 + 墨蓝主色；状态用绿/琥珀/灰 |

**禁**：把多专家做成「名片旁挂一句」；禁把跨案首页抄成大厅。

## 4. 六维对照（复用边界）

| 维 | 借 Kimi | 守咱们 |
|---|---|---|
| 1 业务逻辑 | 确认/退回可见 | ④⑤⑥ 硬请示；禁界面步骤冒充业务 |
| 2 产品理念 | 一家公司·持续委托 | 八部大厅；专家向**当前用户**汇报 |
| 3 产品逻辑 | 委托链、过线≠递交 | 进入/合格线/工单；⑤A/B/C |
| 4 产品设计 | 谁在做、确认卡 | 编制可见、质检分席、硬请示真闸 |
| 5 产品形态 | 密度、三栏工作台、头像岗 | 纸墨非 Kimi 橙；非灰框线框 |
| 6 使用成本 | 待你处理优先 | 主路径短；少黑话 |
