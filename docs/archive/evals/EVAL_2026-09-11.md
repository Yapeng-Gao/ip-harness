## 1. 作业中台（中台）

范围：Login、Dashboard `/`、Pipeline、CaseLibrary、CaseDetail、Docket、Billing、Sidebar/Layout、ProductSwitcher。**不含** `/workbench/*` 办理流。

### 布局 · 4
- Mail 感侧栏（白底 + `list-row-active` slate inset）已落地；洞察默认折叠、工作台阶段可折叠，密度可控。
- `Layout` 跳过链接 + `#main` 地标齐全。
- 扣分：Dashboard 仍 ~620 行「看板博物馆」（期限 / Agent 运行 / 漏斗 / 动态 / 重点案件 + `<details>` 健康度），首屏主任务不够唯一。

### 页面逻辑 · 3
- PageHeader「下一动作」在 Docket / CaseLibrary 等列表页立住；CaseDetail 已收成 **主：在工作台办理 + 次：通过闸门 + 更多**。
- 扣分：Dashboard 同时卖「继续办理 / 期限 / Agent 运行 / 漏斗 / 重点案件」，下一动作被淹没；`StageWorkbench` 仍保留 `?hub=1` 薄入口（虽默认重定向）。

### 业务逻辑 · 4
- Docket 中国发明期限、Billing `issueInvoice`/`payInvoice` 经 `dispatchCommand`，与 Agent 共用命令面（见 `COMMANDS.md`）。
- 租户可见性、待付款拦截示意清楚。
- 扣分：Monitor「风险总览」与 Docket / Watch 仍三页信息重叠（文案已区分，IA 仍冗余）。

### UI · 4
- 主色 token 近黑（`--color-primary-600: #0f172a`）；`flat-card` / `cta-work` 在中台列表广用；Login 去渐变英雄。
- 扣分：`index.css` 仍保留 `.soft-card` 定义（页内已不用，易回潮）；部分页 `rounded-xl` CTA 与 Agent `rounded-md` 不完全同构。

### UX · 3
- 习惯路径「待办→工作台 / 期限→Docket」通；ProductSwitcher 分段可用。
- 扣分：Dashboard 空态写「从 IP Agent 发起」、CaseDetail 横幅写「IP Agent」，与 Switcher「IP 办理」混称；侧栏项仍偏多。

### 优势
1. 去 indigo / Sparkles 后与 Agent 视觉令牌基本对齐。  
2. 领域命令 + 租户隔离示意扎实。  
3. CaseDetail CTA 墙已从五枚收口。

### 具体问题（3–5）
1. **Dashboard 入口墙未清干净** — `src/pages/Dashboard.tsx`：Agent 运行块 + 阶段漏斗 + 最近动态 + 重点案件常驻；应默认只留「下一动作 + 期限压力」，其余折叠或下沉。  
2. **产品命名混用** — Switcher/Login「IP 办理」vs Dashboard L163 / CaseDetail L162「IP Agent」。  
3. **Monitor 页价值弱** — `src/pages/Monitor.tsx`：只读汇聚，办理深链到 Watch/Docket；可考虑并入 Docket 筛选或降为子视图。  
4. **StageWorkbench 残留** — `src/pages/StageWorkbench.tsx`：`?hub=1` 薄入口增加认知噪音。  
5. **soft-card 死代码** — `src/index.css` L111+：未引用类仍在，易被复制回页面。

### 优先修复
1. Dashboard 首屏只保留 1 主 CTA + 三格指标 + 期限列表。  
2. 全仓统一对外名「IP 办理」（或统一回「IP Agent」并改 Switcher）。  
3. 删/并 Monitor 或 StageWorkbench hub。

## 2. SaaS 工作台

范围：`/workbench`、WorkbenchHome、七条 Flow、FlowChrome、StageWorkbench（办理向）。

### 布局 · 4
- 统一骨架：`FlowHeader → CasePicker → Stepper? → SplitDraft`；Maintain/Watch 已补 Stepper；Home 待办/阶段入口分页签，不再叠网格。
- 扣分：FlowChrome ~929 行上帝组件；左表单/右文书在短流程（Maintain）略空。

### 页面逻辑 · 4
- Research 空命中阻断、Intake Go/No-Go、Draft 权项+filing 清单、Prosecution Docket 回写横幅清晰。
- `nextActionsForStage` 纠偏「撰写/OA → 去立项」已核实。
- 扣分：Watch 告警区仍是「1 主 + 更多」但更多里动作多；Intake 报价与费用中台边界靠文案解释。

### 业务逻辑 · 4
- `HandoffActionBar` 角色/模式/发票停权/必填清单驱动交接；`checkedRequired` 动态条件已落地。
- 扣分：**VersionPanel「附批注并退回」与 HandoffActionBar 退回区双入口**（`VersionPanel.tsx` / `FlowChrome.tsx`），企业审核路径不唯一。

### UI · 4
- 工作台路径 **0 indigo / 0 soft-card**；`cta-work` + `flat-card` + slate Stepper。
- 扣分：主钮仍偏 `rounded-xl`+抬影，略软于 Agent `rounded-md`；FormBlocks 注释债可忽略。

### UX · 4
- Home「办理首条待办」正确；成功 Toast「下一步」习惯已立且方向对。
- 扣分：七流同构后仍有能力重叠（退回）；Watch 英文夹杂已清但「更多」菜单认知成本仍在。

### 优势
1. 闸门与交接是全仓最强业务叙事之一。  
2. Anti-slop 在工作台主壳已真正生效。  
3. ClaimDiffView / VersionPanel / 阶段下一步 helper 实用克制。

### 具体问题（3–5）
1. **双退回入口** — `src/components/workbench/VersionPanel.tsx` + `FlowChrome.tsx` `HandoffActionBar`：择一主入口，另一处只读历史。  
2. **FlowChrome 体积** — `src/components/workbench/FlowChrome.tsx`（~929 行）：Stepper/Toast/Handoff/CaseHeader 宜拆，降低改闸门风险。  
3. **Watch「更多」仍挤** — `src/pages/workbench/WatchFlow.tsx`：关闭/调研案/维权线索可再降级或按角色裁剪。  
4. **StageWorkbench** — 与中台重复入口（见上）。  
5. **圆角令牌** — FlowChrome `btnPrimary` 与 PageHeader/`cta-work` 圆角不完全一致。

### 优先修复
1. 退回路径单入口。  
2. 拆分 FlowChrome（工程债，挡迭代）。  
3. Watch 更多菜单按角色再砍一刀。

## 3. Agent 平台

范围：`/agent/*` — AgentShell、Home、SessionWorkspace、SessionsList、Catalog、Skills、HarnessOverview。

### 布局 · 4
- Mail 窄侧栏 + 顶栏 + Outlet；会话页 Timeline / ConfirmBar / Composer / 右栏默认关，密度好。
- 扣分：激活筛选时侧栏叠「清除」条略高；窄屏无抽屉（演示桌面可接受）。

### 页面逻辑 · 5
- 目标→人选/案件→建会话；确认门角色序、换人清空门、无案琥珀条、失败重试、写回 toast——主闭环最强。
- Catalog 搜+空态、Skills 可启动、Harness 可行动出口齐全。

### 业务逻辑 · 4
- 与中台共用 `dispatchCommand`；HITL 闸门差异化；`actor: agent` 审计可对比。
- 扣分：Skills「能力」与 Catalog 详情工具列表高度重叠；归档无确认/撤销 toast（误触风险）。

### UI · 4
- 「IP 办理」近黑标、`cta-work`、flat 列表、Confirm `border-l-4` 琥珀、ContextPanel 发丝分区——主路径不再像 ChatGPT 壳。
- 扣分：Harness / Skills 仍偏「产品说明/工程师目录」；Catalog 虽降为行尾「开始」，网格目录感仍在。

### UX · 4
- 「开始办理」唯一实心、确认态 Composer 降级、中台同步翠绿条可点案件/工作台——习惯路径清晰。
- 扣分：对外仍混用「IP Agent」活动文案（`AgentContext.tsx`）；归档一键无撤销。

### 优势
1. 会话工作区是三面里页面逻辑最完整的闭环。  
2. 去 AI 模板味收口最彻底（相对中台早期状态）。  
3. 与中台命令面打通，演示「表单 vs Agent」可比。

### 具体问题（3–5）
1. **Skills ↔ Catalog 重叠** — `src/pages/agent/AgentSkills.tsx` / `AgentCatalogPage.tsx`：建议能力并入目录详情，侧栏「能力」降级或隐藏。  
2. **归档无轻确认** — `AgentSessionsList.tsx` / `AgentShell.tsx`：缺「已归档 · 撤销」toast。  
3. **活动/横幅仍写 IP Agent** — `src/context/AgentContext.tsx`、CaseDetail 横幅：与壳品牌「IP 办理」不一致。  
4. **Workspace / Shell 体积** — `AgentSessionWorkspace.tsx` ~680、`AgentShell.tsx` ~700：编排债。  
5. **Harness 参考页** — `AgentHarnessOverview.tsx`：可再缩短为一段说明+列表（积木感已减弱但仍是 About 页）。

### 优先修复
1. 合并或降级 Skills。  
2. 归档撤销 toast。  
3. 统一品牌文案为「IP 办理」。
