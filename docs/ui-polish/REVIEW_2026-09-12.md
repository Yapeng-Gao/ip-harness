**技能对照摘要**

- **Apple HIG / apple-design**：侧栏 + 8pt 感间距、克制阴影、清晰「下一步」达标；仍缺部分光学层次（长 muted 元数据）。
- **make-interfaces-feel-better**：concentric radius / surface tokens 大体到位；tabular-nums 在 KPI/步进有体现；press scale / 部分 composer `outline-none` 未统一。
- **web-design-guidelines**：focus 替换多数合格；`transition-all` 仍有零星；icon-only 控制大体有 `aria-label`；对比度（次要灰字）与 disabled CTA 说明是主要缺口。

## 总评理由

Wave1–3 把壳与 token 拉齐，Deep W4–W6 把工作台内页 / mid 节点流水线 / Agent catalog·session 抬了一层，Dashboard v2-top 把首屏「下一步」做成可演示的行动单元。  
**尚未 Go**：次要文对比与 Agent Confirm 主 CTA 易误读（P0），流水线空列主导 + catalog 展开密度 + 会话上下文默认折叠（P1）会在干系人走查时显「样机未完工」。样机诚实空态本身合格，但演示数据过稀放大了壳好里空。

## P0（必须改）

### P0-1 · Dashboard 次要文 / 优先条元数据对比与可扫性
- **问题**：Inbox 副行与优先条 SLA/风险常为低对比灰字或一条拼接长串，首屏「扫一眼懂风险」失败。
- **验收标准**：次要文相对卡面 ≥4.5:1；SLA / 风险 / 谁该动 拆成独立 chip 或标签字段，禁止单行 muted 堆叠。
- **URL / 证据**：`http://127.0.0.1:5173/` · `docs/ui-polish/dashboard-v2-top/full-after.png` · `hero-after.png`

### P0-2 · Agent 会话 Confirm 主 CTA 状态可读
- **问题**：「需要你确认」强提示与主发送按钮视觉权重/禁用态不匹配，易被当成坏掉的主按钮。
- **验收标准**：禁用时内联可见原因；当前合法下一步始终有明确文案；禁止无标签的「死」主按钮。
- **URL / 证据**：`http://127.0.0.1:5175/agent/sessions/sess-oa-1`（及 intake 会话）· `docs/ui-polish/deep-w6/session-agent-intake-after.png` · `wave3/agent-session-after.png`

## P1（应改）

### P1-1 · Pipeline 空列主导
- **问题**：演示租户下多数阶段空 dashed，1–2 张卡淹没在空列里，看板读成「未做完」。
- **验收**：空列可折叠 / 「显示空阶段」开关，或评审租户 ≥4 阶段各 ≥1 卡。
- **URL**：`http://127.0.0.1:5173/pipeline` · `deep-w5/pipeline-after.png`

### P1-2 · Catalog 展开六段 meta 密度
- **问题**：卡片外壳已抛光，展开后「何时用/输入/输出…」呈墙字。
- **验收**：定义列表或两列 meta 网格 + 标签弱化；超高可「更多」折叠。
- **URL**：`http://127.0.0.1:5175/agent/agents` · `deep-w6/catalog-overview-after.png`

### P1-3 · 会话上下文 / 产物默认折叠
- **问题**：`rightOpen=false`，待确认会话默认看不到产物面板（W6 REPORT 自承）。
- **验收**：待确认会话首次进入自动展开一次，或常驻「上下文」chip 显示未读产物数。
- **URL**：`http://127.0.0.1:5175/agent/sessions/:id`

### P1-4 · Docket warn/critical 态证据不足
- **问题**：CSS 态已备，当前样例多为 done/default + 少量逾期，走查看不到完整轨色矩阵。
- **验收**：评审租户可见 ≥1 warn、≥1 critical 行，轨色可区分并留证。
- **URL**：`http://127.0.0.1:5173/docket` · `deep-w5/docket-after.png`

### P1-5 · Workbench tip / banner 叠层
- **问题**：intake/research 等多 tip + 红灯 + 表单 + 草稿列争抢首屏。
- **验收**：同视口最多一条 sticky tip；info vs blocker 视觉分级；blocker 不得落在折线以下。
- **URL**：`http://127.0.0.1:5174/workbench/intake/c5` · `/workbench/research/c2`
