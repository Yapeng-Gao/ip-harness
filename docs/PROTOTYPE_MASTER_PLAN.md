# IP Harness 原型总方案（可按表执行）

> **口径冻结**：本阶段**只做前端样机 + 内存业务状态机**，**不做**真后台（无真库 / ES / 向量 / GPU / Spark / SSO）。  
> **日期**：2026-09-13 · Owner：平台总控  
> **分支**：`dev`

---

## 0. 总原则

| # | 原则 |
|---|------|
| 1 | 壳 ≠ 微服务；新能力默认**新 Vite 壳或独立平面文档**，端口 app 内固定，**不改** `APP_PORTS` 除非总控开闸 |
| 2 | 样机要有**可点业务闭环**（对标 ai-infra / ai-data / doc-harness），禁止空表单 |
| 3 | 人用 UI 与 Agent 工具尽量**同一契约形状**（先检索面） |
| 4 | 训练语料（ai-data）≠ 检索语料/检索引擎（search） |
| 5 | 办案写库唯一远期入口：DomainCommand → case-core（**本期不写码**） |
| 6 | 执行顺序：规格短文 → 可点样机 → UI/业务短评 → P0 排修 → 下一包 |

## 4. 检索引擎逻辑方案（人对齐 + Agent · 已开做）

### 4.1 对标（用法）

- 智慧芽：检索式 + 语义 + 同族去重/过滤；人 Web + API。  
- Innojoy：简单 / 表达式 / AI 智能；字段算符丰富。  

### 4.2 样机必须有的闭环

见 `architecture/search/deep-demo.md`：`keyword | semantic | query` → `SearchRun` → `Hit[]` → 过滤/同族 → 详情 → 工作篮 → Agent JSON 形状。

### 4.3 与 ai-data

| | search | ai-data |
|--|--------|---------|
| 给谁 | 人 + Agent 检索 | 训推数据集 |
| 产物 | Hit / 工作篮 | dataset version |
| 壳 | :5182 | :5181 |

### 4.4 远期存储分层（只记方案，不建）

湖（列存 Parquet）→ 元数据行存（PG）→ 倒排 + 向量 → **唯一** Search API。

## 4.5 产业全景（D4）能力判断（2026-09-13 定调）

> 用户诉求：用专利 + 论文 + 公开资料，维护**行业/领域**全景——以汽车为例：整车组成系统 → 再拆零配件多层；行业组织；企业、业务线、地位；专利布局；竞品；防卡脖子 / 防专利围剿；找前沿并提前布局。**很关键。**

### 结论（一句话）

| 层级 | 能否做 | 说明 |
|------|--------|------|
| **样机演示** | **能** | 单垂直域（如汽车）种子图谱：树 + 企业卡 + 专利密度热力 + 竞品雷达 + 卡脖子/前沿标注；全内存；诚实「非全球实时库」 |
| **可售真产品（全行业持续维护）** | **不能只靠现有壳** | 缺独立「产业知识/实体」能力面，不是把 search 结果画成图就够 |

### 现有资产够用的部分

- Search Hit / 工作篮 / corpus 入库形状（已有样机）→ 全景下钻文献的**入口**  
- ai-data：只训推语料，**不是**产业图谱主存  

### 必须新增的产品能力（真落地才建；样机可 mock 外形）

| ID | 新能力面 | 干什么 | 样机期 |
|----|----------|--------|--------|
| L1 | **产业分类树 / 技术分解树（Taxonomy）** | 行业→系统→子系统→零件多层；可版本化 | 汽车一棵种子树可点 |
| L2 | **实体主数据（企业 / 业务线 / 产品）** | 企业档案、业务线、地位标签、集团关系 | 种子 20～50 家 |
| L3 | **多源入库（专利+论文+公开资料）** | 与 search corpus 同源或旁路；字段对齐实体 | 假 ingest 任务 |
| L4 | **产业知识图谱 / 关联层** | 零件↔专利↔企业↔竞品↔标准 | 预置边；无真图数据库 |
| L5 | **分析图层** | 布局热力、卡脖子点、围剿圈、前沿空白、建议布局 | 规则+种子标注，非真模型 |
| L6 | **全景产品壳** | `apps/landscape:5186` 人用 + Agent 同形状查询 | W5 样机 |

### 样机验收（W5 / D4）最小闭环

1. 选域「汽车」→ 展开 ≥3 层树（整车→动力→电驱动…）  
2. 点节点 → 相关企业列表（地位标签）+ 专利布局示意 + 竞品对照  
3. 卡脖子 / 围剿 / 前沿 三类洞察卡（种子文案可点）  
4. 下钻到假 Hit（可链 search 形状）→ 可进工作篮占位  
5. 横幅诚实：种子域 · 无全球实时产业库  

### 排期影响

- **不插队打断 W2 FTO**：全景依赖「树+实体+分析」规格先写清，仍放 **W5**，但规格可与 W2 **并行起草**（架构包 `architecture/landscape/` 提前）。  
- 真落地时：L1–L5 是**新产品能力**，建议独立服务面（industry-graph / entity），全景壳只消费 API——与 case-core 同级另立项。
