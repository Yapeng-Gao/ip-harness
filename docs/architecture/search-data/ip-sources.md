# IP 多源：专利 / 论文 / 公开资料

## 1. 源类型

| 类 | 例 | 更新 | 风险 |
|----|----|------|------|
| 官方专利 bulk/API | 国别局、区域局 | 周/日 | 格式多、法律状态延迟 |
| 商业专利库 | （采购后） | 合同约定 | 许可绑定产品面 |
| 论文 | 开放库 / 出版商 API | 日/周 | 全文许可 |
| 标准 / 法规 | 标准组织 | 低 | 版权 |
| 网页/新闻/年报 | 定向抓取 | 高 | robots、噪声 |

## 2. 字段对齐要点

- 所有源映射到 `SearchDocument`；无法映射进 `ext` 并声明 `mappingVersion`  
- 机构消歧：规则表 + 可选实体服务，供 landscape 复用  

## 3. 与业务壳

| 壳 | 怎么用检索数据 |
|----|----------------|
| search | 主 UI |
| FTO / mining / inspire | Hit 工作篮 |
| landscape | 树节点挂文献密度与下钻 Hit |
| ai-data | 仅经**导出作业**要切片，不共享写权限 |
