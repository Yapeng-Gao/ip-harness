# 增量、版本、质量与合规

## 1. 索引版本

- `indexVersion`：embedding 模型、分析器、字段映射、构建时间、文档计数、checksum  
- 查询别名 `search_current` → 指向活跃版本；发布=别名原子切换  
- 回滚：别名指回上一代（湖与对象不删）  

## 2. 质量门禁（入库）

| 检查 | 失败策略 |
|------|----------|
| 必填（title 或公开号） | quarantine |
| 解析覆盖率（权利要求空） | 可先 metadata 索引，标记 `partial` |
| 重复 contentHash | 合并 aliases |
| PII 强特征（邮件/电话过量） | quarantine 或脱敏后再索引 |
| 许可证不允许检索 | 拒绝索引，仅审计存证 |

## 3. 合规

- 源合同 / 开源许可证矩阵  
- 出口管制与禁爬名单  
- 访问审计：谁查了哪些 hit（Agent 工具同样记）  

## 4. 运维作业

- 日增量、周全量校验、月重建演练  
- 毒样回放、解析器灰度  
- 与样机「强制下次失败」对应：演练失败注入开关（仅非生产）

## 5. 增量管道（落地）

| 模式 | 适用 | 要点 |
|------|------|------|
| 快照全量 | 初期/重建 | 湖分区按日；Indexer 重放 |
| 增量游标 | 官方 API | `watermark` 存 L2；失败可重放 |
| 文件落地检测 | FTP/对象投放 | 内容 hash 去重 |

失败：死信队列 + 人工；**不**静默丢文献。

## 6. 质量门禁（入库）

| 检查 | 失败策略 |
|------|----------|
| 必填字段（标题或公开号） | reject |
| license 未知 | quarantine |
| 重复 `contentHash` | merge / skip |
| OCR 置信过低 | 降权索引或只进湖不进热索引 |

## 7. 合规

- 机器人/禁爬名单；保留来源 ToS 摘录链接于 Source 记录  
- 个人信息：公开专利正文通常可检索；**非公开交底**不得进检索平面（走 case 脱敏）  
- 审计：IngestJob、下线、导出训练 三类强制日志
