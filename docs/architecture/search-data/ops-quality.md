# 增量、版本、质量与合规

## 1. 索引版本

- `indexVersion`：embedding 模型、分析器、字段映射、构建时间、文档计数、checksum  
- 查询别名 `search_current` → 指向活跃版本；发布=别名原子切换  
- 回滚：别名指回上一代（湖与对象不删）  

## 2. 质量门禁（入库）— 失败策略冻结

| 检查 | 失败策略（冻结） |
|------|------------------|
| **必填缺失**（无 title **且** 无公开号/等价主键） | **`quarantine`**（进隔离区，不进热索引；保留湖/对象与 Job 审计，可人工补全后重放） |
| 解析覆盖率（如权利要求空） | 可先 metadata 索引，标记 `partial` |
| 重复 `contentHash` | merge aliases / skip 重复正文 |
| license 未知或不允许检索 | **`quarantine`**（未知）或 **拒绝热索引、仅审计存证**（明确不允许） |
| PII 强特征（邮件/电话过量） | `quarantine` 或脱敏后再索引 |
| OCR 置信过低 | 降权索引，或只进湖不进热索引 |

### 2.1 必填失败：为何冻结为 quarantine（非 reject）

- **`reject`**：易被理解成静默丢弃，不利补数与审计回放。  
- **`quarantine`（冻结）**：文档不服务查询，但对象/湖/IngestJob 可追溯；补字段后重放 Indexer。  
- 实现须：**quarantine 队列与生产索引物理或别名隔离**；监控 quarantine 增长率。

## 3. 增量管道

| 模式 | 适用 | 要点 |
|------|------|------|
| 快照全量 | 初期/重建 | 湖分区按日；Indexer 重放 |
| 增量游标 | 官方 API | `watermark` 存 L2；失败可重放 |
| 文件落地检测 | FTP/对象投放 | 内容 hash 去重 |

失败：死信队列 + 人工；**不**静默丢文献。

## 4. 合规

- 源合同 / 开源许可证矩阵；Source 记录挂 ToS 摘录链接  
- 机器人/禁爬名单；出口管制名单  
- 公开专利正文通常可检索；**非公开交底**不得进检索平面（走 case 脱敏）  
- 访问审计：谁查了哪些 hit（Agent 工具同样记）  
- 审计强制：IngestJob、下线、导出训练  

## 5. 运维作业

- 日增量、周全量校验、月重建演练  
- 毒样回放、解析器灰度  
- 非生产可留失败注入开关（对应样机演练）；生产默认关  

## 6. 验收清单

- [ ] 必填失败路径 = **quarantine**（文档与实现一致，无 reject 歧义）  
- [ ] `indexVersion` 含 embedding/分析器指纹  
- [ ] 可回滚别名切换  
- [ ] quarantine 与生产索引分离  
- [ ] 导出训练走独立作业 ID
