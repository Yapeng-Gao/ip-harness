# 评测与安全

## 1. 评测集分层

| 层 | 内容 |
|----|------|
| 任务回归 | 摘要/改写/拆解/工具调用等固定集 |
| 安全红队 | 越权结论、泄密诱导、越狱 |
| 幻觉/引用 | 给定片段是否乱引公开号 |
| 检索辅助 | 可与 search-data 金标共享文献号（非默认训练集） |

## 2. 门禁（阶段内）

- 先冻结评测集再刷训  
- 不达标不进下一阶段（见 [overview](./overview.md) 阶段门禁）  

## 3. 安全数据与策略

- 拒答/边界样例全程混入 SFT 与偏好，不只最后贴补丁  
- 系统提示与产品免责声明对齐  

## 4. 发布门禁（Go/No-Go）

| 门 | 失败则 |
|----|--------|
| 任务回归不低于上一 Release −ε | No-Go |
| 安全红队高危 = 0 | No-Go |
| 幻觉/乱引用抽检超阈 | No-Go |
| 许可证与数据版本审计完整 | No-Go |

## 5. 人性化指标之外

- 延迟/成本仅作观测，不替代质量门  

## 6. 验收

- [ ] 评测集分层表完整  
- [ ] 冻结与泄漏防控有动作项
