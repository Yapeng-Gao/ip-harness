# 评测与安全

## 1. 评测集分层

| 层 | 内容 |
|----|------|
| 烟雾 | 格式、拒答、基本摘要 |
| 任务 | FTO 草稿、交底结构化、query 改写等金标 |
| 回归 | 通识+旧版本对比 |
| 红队 | 越权法律意见、隐私、危险指引 |
| 检索联合 | RAG 是否胡编引用（可与 search 金标联动） |

## 2. 门禁

- 训练 Job 成功 ≠ 可发布  
- Release 前：必过烟雾+红队；任务集不低于基线  
- 退化则阻断别名切换（同 search index 别名思想）  

## 3. 安全数据与策略

- 训练：拒答/纠正 SFT + 安全偏好对  
- 推理：系统提示、工具白名单、输出过滤  
- 产品：所有 FTO/侵权相关 UI 固定「非法律意见」  

## 4. 人性化指标之外

- 记录 **诚实不确定**（模型说不知道）优于装懂  
- 引用率、可核对率纳入 RAG 任务分


## 4. 发布门禁（Go/No-Go）

| 门 | 失败则 |
|----|--------|
| 任务回归不低于上一 Release −ε | No-Go |
| 安全红队高危 = 0 | No-Go |
| 幻觉/乱引用抽检 | 超阈 No-Go |
| 许可证与数据版本审计完整 | No-Go |

## 5. 验收

- [ ] 评测集分层表完整  
- [ ] 冻结与泄漏防控有动作项
