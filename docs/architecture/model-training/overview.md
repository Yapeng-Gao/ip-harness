# 训练全景

## 1. 阶段链（推荐）

```text
（可选）领域继续预训练 CPT
    → SFT（指令/任务）
    → 偏好对齐（DPO / RLHF 等）
    → （可选）工具调用 / RAG 专项 SFT
    → 评测门禁 → 发布（ai-infra Release）
```

基座可外购通用模型；自研预训练仅在有明确语料与算力预算时立项。

## 2. 平面职责

| 平面 | 职责 |
|------|------|
| **ai-data** | 采集清洗、配比 Recipe、质量门、发布 dataset version、血缘 |
| **ai-infra** | GPU、训练 Job、checkpoint、评测 Job、模型 Registry/Release |
| **search** | 可提供**脱敏导出**源，不承担训练 |
| **case-core** | 仅脱敏导出管道；无案主键进训 |

## 3. 原则

| # | 原则 |
|---|------|
| 1 | 每个训练 Job **钉死** `datasetId@version` + `recipeId` + 超参清单 |
| 2 | 先评测集冻结，再刷训练集（避免泄漏） |
| 3 | 安全/拒答数据全程混入，不只在最后贴补丁 |
| 4 | 长文专利要有专门切片策略（见 data-prep） |
| 5 | 样机横幅诚实：无真训 |

## 4. IP 域目标能力（产品对齐）

- 检索式理解、权利要求解读、对比与风险表述（FTO 辅助，非法律意见）  
- 交底→发明点、扩召、摘要/改写、附图描述（配合 figure 流程）  
- 工具调用：search / 工作篮形状（与 Agent 契约一致）

## 5. 阶段门禁（冻结心智）

| 从 → 到 | 必须满足 |
|---------|----------|
| CPT → SFT | 域困惑度/续写抽检过线；无 license 污染 |
| SFT → 偏好 | 任务评测集冻结；格式/拒答基线达标 |
| 偏好 → 发布 | 安全红队 + 回归；无严重奖励黑客 |
| 任一 → 下一 | Job 记录 `dataset@version` + recipe + commit |

## 6. 与检索的关系

- 检索金标可复用为 RAG/改写评测，**不是**训练集默认来源。  
- 从 search-data 进训必须经导出作业 → ai-data 质量门。
