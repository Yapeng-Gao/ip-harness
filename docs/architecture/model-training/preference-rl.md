# 偏好学习与强化学习

## 1. 方法选择（产品默认）

| 方法 | 数据 | 适用 | 备注 |
|------|------|------|------|
| **DPO / IPO 类** | 偏好对 | **默认先做** | 成本与稳定性较好 |
| RM + RLHF/PPO 等 | 偏好 + 在线采样 | 需要细奖励时 | 另立子项 |
| RLAIF | 模型标注偏好 | 扩量 | 须人工抽检 |

## 2. 数据需求

- 成对（chosen/rejected）或排序；覆盖有用性与安全  
- IP 场景：FTO 表述克制、权利要求质量、拒答是否得当  

## 3. 奖励信号（若走 RL）

- 规则分 + RM；监控奖励黑客与过度拒答  

## 4. 偏好对构造

| 来源 | 说明 |
|------|------|
| 专家两两比较 | 贵但准 |
| 模型多样本 + 规则打分 | 扩量；防模式坍塌 |
| 用户点踩（产品后） | 持续学习；严格脱敏 |

## 5. 风险

- 奖励黑客、过度拒答、谄媚  
- 门禁：安全集 + 有用性集同时看  

## 6. IP 场景注意

- 偏好标签不得等同「法律意见已确认」  
- 与 FTO/挖掘产品文案一致：辅助非替代执业  

## 7. 验收

- [ ] 方法表有默认推荐（DPO/IPO 类优先）  
- [ ] 与 SFT 检查点衔接写清
