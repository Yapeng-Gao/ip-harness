# 课表、持续学习与平台衔接

## 1. 课表（Curriculum）

| 周序（例） | 内容 |
|------------|------|
| W1 | 短指令、格式、拒答 |
| W2 | 摘要/改写/简单对比 |
| W3 | 长文分段 + RAG |
| W4 | 工具调用 search |
| W5 | 偏好对齐 |
| W6 | 红队修复 + 回归 |

每阶段固定评测切片，不达标不进下一阶段。

## 2. 持续学习

- 新专利周更 → **不强行日更全量 CPT**；优先新 SFT/偏好增量  
- 灾难遗忘：混旧锚点数据  
- 回滚：模型 Registry 保留 N 代 Release  

## 3. 与现有文档的接口

| 动作 | ai-data | ai-infra |
