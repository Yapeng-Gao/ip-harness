# 监督微调（SFT）

## 1. 目标

把模型训成「会按指令做 IP 任务」：摘要、权利要求拆解、检索 query 改写、对比表草稿、交底结构化、拒答与引用格式等。

## 2. 数据形态

- 指令 / 输入 / 输出三元组（可含工具调用 trace）  
- 金标与合成数据配比见 [data-types-and-mix](./data-types-and-mix.md)

## 3. 任务族（建议覆盖）

| 任务 | 输入 | 输出要点 |
|------|------|----------|
| 摘要 | 说明书/权利要求 | 限长、可引用句 |
| Query 改写 | 自然语言 | 关键词/表达式草稿 |
| 特征拆解 | 产品描述 | 特征列表（FTO 上游） |
| 交底结构化 | 自由文本 | 背景/点/效果 |
| 对比表草稿 | 多文献片段 | 结构化表；非法律结论 |
| 拒答 | 越权法律结论请求 | 拒答+改求助人 |
| 工具调用 | 用户意图 | search 工具 JSON |

## 4. 质检

- 格式 schema、引用公开号可解析、禁编造法条  
- 训练/验证/测试无文献号交叉泄漏检查  

## 5. 与 ai-infra

- Job 类型 `train.sft`；钉死 `dataset@version` + recipe + 超参清单  

## 6. 验收

- [ ] 每任务有 ≥N 条金标（N 在 Recipe 钉死）  
- [ ] 泄漏检查为规格必达项
