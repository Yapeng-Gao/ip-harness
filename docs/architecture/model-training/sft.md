# 监督微调（SFT）

## 1. 目标

把模型训成「会按指令做 IP 任务」：摘要、权利要求拆解、检索 query 改写、对比表草稿、交底结构化、拒答与引用格式等。

## 2. 数据形态

| 格式 | 用途 |
|------|------|
| `messages[]`（system/user/assistant） | 主格式 |
| 可选 tool_calls | 检索/结构化输出 |
| 输入含长专利时 | 截断/分段+指针（见 data-prep） |

## 3. 任务族（建议覆盖）

1. 查询改写 / 表达式生成  
2. 摘要与关键句抽取  
3. 特征↔权利要求对比（**草稿**，非法律结论）  
4. 交底分段与发明点候选  
5. 灵感扩召（可弱监督）  
6. 安全拒答与「非法律意见」声明  
7. JSON/表格结构化输出  

## 4. 质检

- 人工抽检比例 + 自动规则（空答、泄露 system、违法建议）  
- 难度分层：易/中/难，课表先易后难（见 curriculum）  

## 5. 与 ai-infra

Job 类型 `train.sft`；产出 checkpoint → 候选模型；未过评测不进 Release。


## 4. IP 任务清单（SFT 覆盖）

| 任务 | 输入 | 输出要点 |
|------|------|----------|
| 摘要 | 说明书/权利要求 | 限长、可引用句 |
| Query 改写 | 自然语言 | 关键词/表达式草稿 |
| 特征拆解 | 产品描述 | 特征列表（FTO 上游） |
| 交底结构化 | 自由文本 | 背景/点/效果 |
| 拒答 | 越权法律结论请求 | 拒答+改求助人 |
| 工具调用 | 用户意图 | search 工具 JSON |

## 5. 验收

- [ ] 每任务有 ≥N 条金标（N 在 Recipe 钉死）  
- [ ] 训练/验证/测试无文献号交叉泄漏检查脚本（规格要求存在）
