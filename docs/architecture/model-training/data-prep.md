# 数据怎么准备

## 1. 端到端步骤

1. **立项与许可证审查**（无许可不进湖）  
2. 采集 / 脱敏导出（case 仅走导出管道）  
3. 清洗、去重、过滤、质量打分（ai-data）  
4. 按任务切片与配比采样（Recipe）  
5. 冻结评测切分 → 发布 `dataset version` + manifest  
6. ai-infra Job 只读该 version  

## 2. 长专利策略

| 策略 | 用途 |
|------|------|
| 按章节/权利要求项切 | SFT 样本 |
| 滑动窗口 + 标题上下文前缀 | CPT |
| 检索段落作 RAG 块 | RAG 专项；保留 doc id |

## 3. 合成数据

- 允许扩量，但须比例上限与人工抽检  
- 禁止用未授权商业库原文做合成种子  

## 4. 泄漏防控

- 文献号 / 家族级划分 train/val/test  
- 评测集发布后禁止再并入训练 Recipe  

## 5. Tokenizer

- 评估专利号、化学式、IPC 碎片是否被过度切分  
- 需要则领域词表或预处理规范化（实施另立 spike）  

## 6. 交付物

- Recipe YAML/JSON、manifest checksum、质量报告、许可清单  

## 7. 验收

- [ ] 许可审查为硬步骤  
- [ ] 切片策略与 SFT 任务表对齐
