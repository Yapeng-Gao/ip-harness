# 预训练 / 领域继续预训练（CPT）

## 1. 目标

- **从零预训练**：学通识+领域语言；成本极高，默认不作为 IP 产品第一路径  
- **领域 CPT**：在通用基座上继续训专利/论文/标准语料，提升术语与长文稳定性  

## 2. 数据需求

| 类型 | 内容 | 备注 |
|------|------|------|
| 专利全文/题录 | 多国、多年代 | 许可证！ |
| 论文/教材/标准 | 开放许可优先 | |
| 通用重放 | 按配比混入防遗忘 | 对 CPT 重要 |
| 代码/公式 | 可选 | 说明书附图流程 |

**不要**：未脱敏案件正文、客户机密、无许可商业库文本。

## 3. 准备要点

- 去重（文档级+段落近重）、语言识别、乱码/OCR 垃圾过滤  
- 打包：document → token 序列；packing；长度裁剪策略  
- 记录 `tokens`、`epochs`、`mixture` 进 version 元数据  

## 4. 成功判据

- 领域困惑度/掩码准确率相对基座下降  
- 下游 SFT 同等数据下指标提升  
- 通识回归集不崩（防灾难遗忘）


## 4. 数据与算力注意

- 专利全文重复极高：强去重 + 按族/号降采样  
- 中英配比写入 Recipe；代码/数学外域数据按需混入防退化  
- Checkpoint 策略：按 token 或按评测；保留可回滚点  

## 5. 验收

- [ ] 默认路径写清「外购基座优先」  
- [ ] CPT 与从零预训练分节，避免混谈预算
