# 预训练 / 领域继续预训练（CPT）

## 1. 目标

- **从零预训练**：学通识+领域语言；成本极高，默认不作为 IP 产品第一路径  
- **领域继续预训练（CPT）**：在通用基座上灌专利/论文语料，改善术语与长依赖；**推荐作为可选增强，而非 Day-1**

## 2. 数据需求

- 大规模无标注文本（专利全文、论文、标准摘要等），强 license 门禁  
- 去重、降采样同族/复刊；中英配比写入 Recipe  

## 3. 准备要点

- 切分与打包（见 [data-prep](./data-prep.md)）  
- 验证集与测试集先冻结，防泄漏  

## 4. 数据与算力注意

- 专利全文重复极高：强去重 + 按族/号降采样  
- 中英配比写入 Recipe；代码/数学外域数据按需混入防退化  
- Checkpoint：按 token 或按评测；保留可回滚点  

## 5. 成功判据

- 域困惑度/续写抽检相对基座改善  
- 下游 SFT 同数据下收敛更快或分数更高  

## 6. 验收

- [ ] 默认路径写清「外购基座优先」  
- [ ] CPT 与从零预训练分节，避免混谈预算
