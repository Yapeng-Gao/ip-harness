# 数据类型与配比

> 配比为**起始建议**，需用验证集校准；写入 Recipe 版本，禁止口头改配比。

## 1. 数据类型总表

| ID | 类型 | 主要阶段 | 形态 |
|----|------|----------|------|
| T1 | 无监督领域文本 | CPT/预训练 | 纯文本/文档 |
| T2 | 通用重放 | CPT | 纯文本 |
| T3 | 指令 SFT | SFT | messages |
| T4 | 工具调用 SFT | SFT | messages+tools |
| T5 | 偏好对 | DPO/RL | prompt+chosen+rejected |
| T6 | 可验证奖励样本 | RL | prompt+score/rule |
| T7 | 安全/拒答 | SFT+偏好 | 双形态 |
| T8 | 评测金标 | Eval | 输入+参考/rubric（**不进训**） |
| T9 | RAG 专项目 | SFT | 带检索上下文的回答 |
| T10 | 长文切片课 | SFT/CPT | 分段+定位 |

## 2. 阶段配比起点（token 或条数占比）

### CPT（若做）

| 类型 | 占比 |
|------|------|
| 专利/标准/论文（许可内） | 60–75% |
| 通用重放 | 20–35% |
| 代码/结构化 | 0–10% |

### SFT

| 类型 | 占比 |
|------|------|
| IP 任务指令 T3 | 45–55% |
| 工具调用 T4 | 15–25% |
| RAG T9 | 10–15% |
| 安全拒答 T7 | 8–12% |
| 通用助手（防崩） | 5–10% |

### 偏好（DPO）

| 类型 | 占比 |
|------|------|
| 任务质量对 | 50–60% |
| 安全对 | 20–25% |
| 风格/简洁对 | 10–15% |
| 工具正确性对 | 10–15% |

## 3. 规模量级（指导）

| 阶段 | 量级感 |
|------|--------|
| CPT | 十亿–百亿 token 级才有意义；更小则改做 SFT |
| SFT | 数万–数十万高质量对话往往优于百万脏数据 |
| 偏好对 | 数千–数万对起；安全对要覆盖攻击面 |
| 评测 T8 | 先冻数百–数千题，分任务切片 |

## 4. Recipe 元数据（ai-data）

```text
recipeId, stage, mix[], seed, sampleRules, excludesEvalIds[], licenseGate
```

发布训练用 dataset version 时必须挂 `recipeId`。
