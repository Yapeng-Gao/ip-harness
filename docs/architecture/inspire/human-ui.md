# 创新激发 · 人机 UI（:5185）

## 1. 路由

| 路径 | 步骤 |
|------|------|
| `/` | 输入台（问题/技术点） |
| `/sparks` | 扩召结果墙 |
| `/favorites` | 收藏 |
| `/send` | 送交底 / 送挖掘 |

## 2. 交互

### 输入

- 单框或多行；「激发」按钮。  
- 状态：`idle → expanding → ready | empty`。

### 扩召墙

- ≥ 6 张 `SparkCard` 网格；可「再来一批」（换种子组合）。  
- 卡上：收藏 / 取消收藏。  
- 可选展示假相关公开号。

### 收藏

- 列表管理；空态引导回扩召。

### 送出

- 多选收藏 → 「送交底」或「送挖掘」。  
- toast + 事件；深链 mining:5184 / doc-harness:5178。  
- 文案禁止「已创建交底案」。
