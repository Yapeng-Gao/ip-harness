# 创新激发 · 概览

> **样机诚实**：卡片文案来自种子拼装，非模型生成。  
> **波次**：W5（可与 landscape 并行实现）。

## 1. 定位

- **激发**：从问题/技术点做**广度**扩召，产出可收藏灵感卡。  
- **挖掘**（:5184）：把交底收敛成可评分发明点并送立项——激发「送挖掘」只传卡片文本/种子 id，**不**在激发壳内打分建案。

## 2. 边界

| 邻居 | 关系 | 禁止 |
|------|------|------|
| **mining** | 「送挖掘」深链 + 事件；可带收藏卡摘要 | DomainCommand |
| **search** | 可选「相关公开」假 Hit 挂卡 | 重造检索 |
| **doc-harness** | 「送交底」占位深链 | 写 PatentCase |
| **ai-infra / LLM** | 本期不接 | 真补全 API |
| **case-core** | 无写路径 | 建案 |

## 3. 对象

| 对象 | 含义 |
|------|------|
| `SeedPrompt` | 问题/技术点输入 |
| `SparkCard` | 灵感卡：标题、钩子句、可选标签/假 Hit |
| `Favorites` | 收藏的 card id 列表 |
| `SendIntent` | 送交底 / 送挖掘 事件 |
