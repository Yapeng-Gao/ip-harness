# FTO 人机 UI（:5183）

> **样机诚实**：五步向导或左侧步骤条；数据假。  
> **落地目标（远期）**：步骤态可恢复；今日刷新可失。

## 1. 路由草案

| 路径 | 步骤 | 说明 |
|------|------|------|
| `/` | 入口 / 项目列表 | 一个默认「样机项目」即可 |
| `/features` | ① 产品特征拆解 | 可编辑特征表 |
| `/hits` | ② 检索命中 | 种子篮 +「从 Search 示意导入」 |
| `/matrix` | ③ 对比矩阵 | 特征 × 文献 claim |
| `/risk` | ④ 风险等级 | 汇总 + 可覆盖 |
| `/report` | ⑤ 报告 Confirm | 预览 → Confirm → 草稿只读 |

`*` → `/`。侧栏或顶栏步骤指示当前步；未完成前步可警告但允许跳（样机）——**发布报告前**须矩阵+风险有值。

## 2. 各步交互要点

### ① 产品特征拆解

- 表格：`id` / 名称 / 描述 / 可选「技术关键词」。  
- 操作：增行、删行、上移下移。  
- 空表禁止进入报告 Confirm（可进矩阵但标红）。

### ② 检索命中

- 默认加载 **种子篮**（≥ 3 条 `SearchHit` 形状，字段对齐 [search/agent-api-shape](../search/agent-api-shape.md)）。  
- 「从 Search 工作篮导入」：若无跨口数据，则 toast 说明 + 仍用种子（对齐 search/FTO 深链占位；**不**假装 localStorage 跨端口）。  
- 可移除命中；至少 1 条才能进矩阵。

### ③ 权利要求对比矩阵

- 行 = 产品特征；列 = 文献（或文献×独立权利要求摘要）。  
- 单元格：短文本比对结论示意（`可能覆盖` / `未涉及` / `需人工`）+ 可选假 claim 片段。  
- 「自动填假比对」按钮：按关键词重叠生成单元格（非真引擎）。

### ④ 风险等级

- 按特征或按文献汇总：`low` / `medium` / `high` / `unclear` 色点。  
- 允许人工覆盖；覆盖记 `overridden: true`。  
- 全局风险 = max 或显式选择。

### ⑤ 报告 Confirm

- 预览：项目名、特征摘要、命中列表、矩阵摘要表、风险结论、免责声明（样机非法律意见）。  
- **Confirm** 后锁定草稿为 `confirmed`；可「复制 Markdown」；**不**调用 DomainCommand。  
- 取消回到可编辑。

## 3. 深链（只读）

- 顶栏：`检索 search → http://localhost:5182`。  
- 不改 search / 五壳代码。
