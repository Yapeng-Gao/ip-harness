# 人机 UI（:5182）

> **样机诚实**：布局与交互对标智慧芽/Innojoy **用法**；数据为假。  
> **落地目标**：三模式共用结果管道与过滤模型。

## 1. 三模式（入口切换，同一结果态）

| 模式 | 人感知 | 样机行为 |
|------|--------|----------|
| **语义 / 智能** | 自然语言描述技术点 | 关键词抽假 token → 打分排序种子命中 |
| **关键词** | 布尔/邻近简易式（`AND`/`OR` 示意） | 字段匹配内存索引 |
| **高级 / 表格** | 字段行（标题/摘要/申请人/IPC/日期…） | 表单 → 同一 `SearchQuery` |

模式切换**不丢**已填查询草稿（内存）；切换后仍走同一 `runSearch`。

## 2. 结果区

| 元素 | 说明 |
|------|------|
| 命中列表 | 公开号、标题、申请人、日、IPC、假相关度 |
| 详情抽屉 | 摘要假文 +「同族」入口 |
| 空态 / 过多 | 诚实文案；无真库超时 |

## 3. 过滤（侧面或顶栏）

建议维度（均可点，改的是内存 result set）：

- 日期区间、文书类型、IPC 前缀、申请人、法律状态（示意枚举）、同族折叠开/关  

过滤是 **Query 的一部分**（写入 `filters`），以便 Agent API 复现同一结果形状。

## 4. 同族

- 列表可「按同族折叠」；展开见成员公开号行。  
- 样机：`FamilyGroup { familyId, members[] }` 预置；**非**真 INPADOC。  
- 点击成员只切换详情，不跳外链真库（可外链占位 disabled）。

## 5. 路由草案

| 路径 | 页 |
|------|-----|
| `/` | 检索工作台（模式 + 查询 + 结果） |
| `/families/:familyId` | 同族详情（可选深链） |
| `/saved` | 收藏空态（不写 case） |

横幅：`样机 · 无真检索后台 · 用法对标智慧芽/Innojoy`。
