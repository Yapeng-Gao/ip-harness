# 附图 · 概览

> **样机诚实**：生成 = 模板/几何占位 + 短延迟；编辑 = 本地画布状态机。  
> **冻结**：生成与编辑必须同时可点；禁止「只出一张图看一眼」。

## 1. 为何独立能力

专利附图需要：**出草图**与**改草图**（标注、图层、撤销、版本）。  
doc-harness 已是文档+Agent 三栏；附图画布交互重，默认 **另壳 :5187**，再通过「挂文档章」深链回写示意。

## 2. 壳选型

| 方案 | 何时用 | 代价 |
|------|--------|------|
| **A. `apps/figure:5187`（推荐默认）** | Owner 边界清、画布全屏、与撰写解耦演示 | 多一个 Vite；挂章靠深链/事件占位 |
| **B. 挂 doc-harness 模式** | 人力紧、必须同屏改章节+附图 | 易挤三栏；仍须满足双闭环，勿只做侧栏预览 |

**本规格按 A 写 IA**；若总控改挂 B，路由可改为 doc-harness 内 `/figure/*`，状态机不变。

## 3. 边界

| 邻居 | 关系 | 禁止 |
|------|------|------|
| **doc-harness** | 版本资产「挂到某 DocumentRevision / 章节」示意 | 改五壳；真 SSO |
| **case-core** | 不写案；挂章 ≠ DomainCommand | 假装已写入 PatentCase |
| **ai-infra** | 无真文生图；不申请 GPU | 接真文生图 API（本期） |
| **search / fto** | 可选上下文来自工作篮/特征（种子） | 重造检索 |

## 4. 核心对象（样机）

| 对象 | 含义 |
|------|------|
| `FigureContext` | 用户输入：标题、部件列表、可选章节引用 |
| `FigureAsset` | 一版附图：`id` / `rev` / 画布文档 JSON 或 SVG |
| `Layer` | 背景草图 / 标注 / 引导线… |
| `Annotation` | 序号气泡、引出线、文字标签 |
| `HistoryStack` | 撤销/重做 |
