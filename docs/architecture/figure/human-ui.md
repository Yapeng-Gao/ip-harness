# 附图 · 人机 UI

> 默认壳：`apps/figure:5187`。

## 1. 路由草案

| 路径 | 页 |
|------|-----|
| `/` | 项目/资产列表（种子 1～2 个） |
| `/new` | ① 上下文：标题、部件、可选「关联章节」假下拉 |
| `/generate/:draftId` | ② mock 生成：进度 → 出草图 |
| `/edit/:assetId` | ③ 画布编辑（主战场） |
| `/versions/:assetId` | ④ 版本时间线；可恢复旧版 Confirm |
| `/attach/:assetId` | ⑤ 挂文档章：选假 doc/章 → 事件+深链 doc-harness |

## 2. 生成台（必须可点）

- 填上下文 → 「生成草图」。  
- 状态：`idle → generating → ready | failed`（1～2s 假延迟）。  
- 产出：预置模板之一（爆炸图框 / 流程图框 / 简单零件轮廓）+ 自动放 2～3 个标注占位。  
- **禁止**只显示「已生成」无进入编辑的死链；成功后主按钮 = **打开画布编辑**。

## 3. 画布编辑（必须可点）

| 能力 | 样机行为 |
|------|----------|
| 选中 / 拖动标注 | 改坐标，入 history |
| 添加标注 | 点工具 → 画布落点 |
| 图层 | 至少 2 层：草图 / 标注；可显隐 |
| 撤销 / 重做 | 栈深度 ≥ 10 步示意 |
| 保存版本 | 生成新 `rev`，列表可见 |

编辑器可用 SVG + React 状态，或轻量 canvas；**不**引入真专业 CAD。

## 4. 挂文档章

- 下拉假 Document / 章节（对齐 doc-harness 种子名即可）。  
- 确认 → toast + 事件日志「已挂章（样机）」；可选 `window.open` doc-harness URL 占位。  
- **不**调用 DomainCommand。

## 5. 深链

- 顶栏：`文档 doc-harness → :5178`。  
- 不改 doc-harness 业务码（除非总控另派挂载 PR）。
