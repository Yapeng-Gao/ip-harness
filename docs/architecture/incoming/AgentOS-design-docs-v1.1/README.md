## 核心设计原则（速记）

1. **一任务一沙箱，引擎随沙箱生灭**——用户状态在 workspace，不在引擎
2. **代码做裁判，LLM 做选手**——能写成 validator/公式的绝不写进 prompt
3. **Team = Domain 同一运行时**——领域包只是把自由协作固化成 SOP
4. **HITL = 执业责任人签批**——无签批产物禁止导出（系统强制）
5. **绝不静默重跑**——熔断/ escalate 一律人工接管，全程留档
