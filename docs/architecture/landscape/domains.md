# 能力面 L1–L6

> **样机**：mock 外形即可。  
> **真落地**：L1–L5 建议独立服务面（industry-graph / entity）；壳只消费 API。

| ID | 能力面 | 干什么 | 样机期 |
|----|--------|--------|--------|
| **L1** | 产业分类树 / 技术分解树（Taxonomy） | 行业→系统→子系统→零件多层；可版本化 | 汽车一棵种子树可点 |
| **L2** | 实体主数据（企业 / 业务线 / 产品） | 档案、业务线、地位标签、集团关系 | 种子企业卡 |
| **L3** | 多源入库（专利+论文+公开资料） | 与 search corpus 同源或旁路；字段对齐实体 | 假 ingest 任务空态/一条假进度 |
| **L4** | 产业知识图谱 / 关联层 | 零件↔专利↔企业↔竞品↔标准 | 预置边；无真图 DB |
| **L5** | 分析图层 | 布局热力、卡脖子、围剿圈、前沿空白、建议布局 | 规则+种子标注，非真模型 |
| **L6** | 全景产品壳 | `apps/landscape:5186` 人用 + Agent 同形状 | W5 样机 |
