## 1. 用户诉求（冻结）

用专利 + 论文 + 公开资料维护**行业/领域**全景。以汽车为例：

- 整车组成系统 → 再拆零配件 **多层**  
- 行业组织；企业、业务线、地位  
- 专利布局；竞品  
- 防卡脖子 / 防专利围剿  
- 找前沿并提前布局  

## 2. 为何独立壳（L6）

- 不是「把 search 结果画成气泡图」；需要 **Taxonomy + 实体主数据 + 关联 + 分析图层**。  
- ≠ [ai-data](../ai-data/README.md)（训推语料仓）。  
- ≠ case-core 写案；全景默认只读分析。  
- Search Hit / 工作篮 = 下钻文献**入口**，不是图谱主存。
