# 产业全景 · 人机 UI（:5186）

## 1. 路由草案

| 路径 | 页 |
|------|-----|
| `/` | 域选择（默认锁「汽车」；其他域 disabled +「另立项」） |
| `/tree` | 行业/技术分解树（主画布） |
| `/nodes/:nodeId` | 节点详情：企业 + 布局 + 竞品 + 洞察 |
| `/orgs/:orgId` | 企业档案（业务线/地位） |
| `/insights` | 卡脖子 / 围剿 / 前沿 列表 |
| `/ingest` | 多源入库示意（假任务） |

## 2. 主画布（树）

- 左：可展开树（≥3 层）。  
- 中：选中节点摘要（专利密度假热力条、企业数、竞品数）。  
- 右或下：洞察卡入口。  

## 3. 节点详情（点树节点）

| 块 | 内容 |
|----|------|
| 企业列表 | 地位标签：`leader` / `challenger` / `niche` / `supplier`（示意） |
| 专利布局 | 假热力或简单柱条（按年/IPC 种子） |
| 竞品对照 | 2～4 家对照表 |
| 洞察 | 卡脖子 / 围剿 / 前沿 各至少可点一条种子文案 |
| 文献 | 假 `SearchHit[]`；「加入工作篮」占位（事件或 toast；不强制跨口） |

## 4. 诚实

- 非汽车域：灰显。  
- 横幅见 overview。  
- 深链 search:5182（只读）。
