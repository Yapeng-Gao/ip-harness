# 业务模式（Domain 收敛壳 · 先规格再样机）

> **冻结（2026-09-21 · 总控开令）**：**先规格再样机**；本轮 **只 docs**，禁改 `apps/**`。  
> **定位**：专利 **业务用户**主路径——「我的案子 + 该我批的确认」。是 **Domain Pack 的壳收敛**，不推翻 Pack 16 席 / HITL×8 权威。  
> **消 4 痛**：认知负担 · Catalog 超市 · 样机泄漏 · Solo/Team/租户/总控噪音。  
> **对齐**：[patent-pack-design](../domain-packs/patent-pack-design.md)（权威）· [agent-patent-shell](./agent-patent-shell.md)（专家/双文件）· [agent-layers](./agent-layers.md)（双产品）· [agent-platform-gap](./agent-platform-gap.md)。  
> **样机诚实**：无真 LLM / 真 case-core / 真沙箱；进度与 Confirm **必须同源真闭环**（禁假阻塞、禁状态分叉）；端用户 **禁 mid 可点深链**。

## 3. 案子向导（主路径）

**主 CTA**：`新建案子` → 向导（3～5 段）→ 进入案子工作台。  
**禁止**主 CTA =「选专家组队」。

### 时间线阶段（建议 5 段）↔ HITL×8

| 阶段（上屏） | 用户一句话 | 默认席动作 | 映射 HITL |
|--------------|------------|------------|-----------|
| **1. 准备** | 弄清要不要做、方向对不对 | 可选：更多专家（全景/挖掘…）；默认可跳过 | ①布局（若启用布局） |
| **2. 立项** | 决定做不做、做到哪 | 查新 → 立项 | ④查新结论 · **②立项**（`go_nogo`） |
| **3. 撰写申请** | 交底→写申请→附图 | 交底 · 撰写 · 附图 | ③交底 · ⑤权项 |
| **4. 递交** | 材料齐了交出去 | 递交（+可选 FTO） | authorize/file 闸（非 HITL×8 编号但须确认） |
| **5. 审查答复** | 有审查意见再处理 | 审查答复（**仅已递交后解锁**） | ⑥OA 策略 |

⑦年费 · ⑧交易：Phase，向导不进主路径；「更多」灰显。

每段主按钮用人话：`继续查新` / `确认立项` / `确认交底` / `确认权利要求` / `确认递交` / `确认答复策略`。

## 4. 「待我确认」收件箱

| 元素 | 规格 |
|------|------|
| 入口 | 顶栏铃铛 / 「待我确认」；案子页内嵌同列表过滤 |
| 一行 | 案子名 · 要确认什么（人话）· 谁准备好的 · 时间 |
| 点开 | 左：摘要；右：**成果**（可读）+ **过程**（可折起，默认先成果）+ 主按钮确认/退回 |
| 空态 | 「暂无需要你确认的事项」 |
| 数据 | 与 HITL/Confirm **同一状态源**；确认后进度条与收件箱同步消失该项 |

## 7. 纪律（样机也必须）

1. **Confirm 真闭环**：点确认 → 同一 store 更新进度/收件箱/阶段锁；禁「按钮亮着但状态不动」；禁假阻塞 toast。  
2. **进度同源**：时间线、待确认、侧栏当前步读同一 `caseProgress`（名可变）。  
3. **禁专家截入**：未立项完成不得进递交/OA；OA 仅「已递交」后。  
4. **禁 mid 可点深链**给业务用户。  
5. **样机诚实一句**（页脚或关于）：「演示环境：进度与确认为样机闭环，非真递交局端。」  
6. 双文件心智可保留在专家工作台；业务默认先看**成果**，过程折叠。
