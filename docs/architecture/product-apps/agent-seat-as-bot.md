## 2. IA（钉死）

```text
┌──────────┬──────────────────────────────────────────────┐
│ 侧栏     │  席工作面（点席进入）                          │
│ · 案子   │  ┌─ 会话（主）人 ↔ 本席 bot · 脚本回合 mock ─┐ │
│ · 席列表 │  ├─ 成果     NN_<key>.md                      │ │
│   查新…  │  └─ 办理过程 NN_<key>_worklog.md              │ │
│ · 群聊   │  推进体感 = bot 回合里「干活/交卷」             │
│   （入口）│  交卷步 → 本案「待我确认」；确认 → 主链前进    │
└──────────┴──────────────────────────────────────────────┘
```

| 面 | 规格 |
|----|------|
| **侧栏席列表** | 默认 7 + 已加更多；点席 = **切到该席独立会话**（`projectId=caseId` 下该 expert 线程） |
| **席工作面 · 会话** | **主区**；人发话 + 席 bot 脚本回合；体感「跟这个 bot 聊 / 它在交卷」 |
| **席工作面 · 成果** | `NN_*.md`（与 [agent-patent-shell](./agent-patent-shell.md) 同源命名） |
| **席工作面 · 办理过程** | `NN_*_worklog.md`；过程面板可折，默认先成果或跟会话并排 |
| **本案群聊** | L2 感；与单席**并存**（本刀可最小入口占位；非删单席） |
| **Catalog** | `/agent/catalog`；进本案席位 **同一 projectId**（焊接口径不变） |

**禁止**：

- 点席 = 只切主链阶段 pill / 假 tab，而无该席会话  
- 把「待我确认」当成席工作面唯一内容（闸口保留，但不独占）  
- 交卷写进另一套确认宇宙（必须本案 store）  
- 回退 `/agent` 开聊空态或拆掉席列表焊接

## 3. 状态机

```text
[席会话 idle]
    │ 人发话 / 点「让它干活」（样机脚本回合）
    ▼
[席 bot 干活中] ──追加会话气泡──► 成果/worklog 随步可见更新
    │
    │ 当前步 triggersHitl（交卷步）
    ▼
[已交卷 · 本案 HITL pending] ──人确认──► [主链进度前进 · 该席 done]
    │                         ──人退回──► [席会话 · 可再改再交]
    │ 非交卷步
    └──► 仍在本席会话 · stepIndex+1 · 可继续聊/干活
```

| 状态 | 存哪 | 上屏 |
|------|------|------|
| 席线程 `messages` + `stepIndex` | ProjectFolder 线程（`caseId`=`projectId`） | 会话气泡 · 只读步骤条 |
| 成果 / worklog 正文 | 由 `stepIndex` + 双文件样机骨架递进（可叠 `faa7bd2`） | 双文件面板 |
| 待确认项 | **本案** BusinessCase confirm store | 铃铛 / 席旁闸口 / 收件箱 |
| 主链 `stageId` / `doneSeatIds` | 同 store；**仅确认后**更新 | 顶栏阶段条 · 侧栏席绿点 |

**同源纪律**（继承业务模式 §7）：确认 → 收件箱消失该项 + 进度前进 + 侧栏同步；禁假阻塞。

## 4. 与旧「推进一步」关系

| | 旧（焊接 + `faa7bd2`） | 新（席=bot） |
|--|----------------------|--------------|
| 主交互 | 按钮「完成本步 / 交卷待确认」 | **会话回合**；bot 脚本里干活/交卷 |
| 步进 | `advanceSeatWork` 抬 `stepIndex` | **同函数可复用**；由会话「交卷/干活」触发，勿另开状态宇宙 |
| 双文件 | 随 `stepIndex` 追加段落 + 过程日志 | **保留**；会话主导、面板仍真更新 |
| HITL | 交卷步 → `prepareConfirm` 本案 | **不变** |
| 主链 | 确认后前进 | **不变** |
| 文案 | 完成本步 / 交卷待确认 | 会话侧用人话「继续整理」「交卷请你确认」；可保留次级按钮作快捷（非唯一入口） |

**迁移原则**：不删 `advanceSeatWork` / 双文件随步；把「推进」从**主 CTA**降为**会话内动作或次级快捷**，体感改为「跟席 bot 聊」。

## 5. 样机回合（mock）

- 无真 LLM；回合剧本绑定席 `ExpertStepDef.script` / tool preview。
