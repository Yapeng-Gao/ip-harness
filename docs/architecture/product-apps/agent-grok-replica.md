# 通用壳 · Grok Bot 复刻（优先）

> **冻结（用户 · 优先）**：**先复刻 Grok Bot**。暂停扩项目/专利花活；把 `/agent` **通用壳**做成 Grok 对标。  
> **心智**：助手列表 + 一对一聊天 —— **不是** Catalog / 会话列表拼盘。  
> **样机诚实**：mock bot/消息即可；写库仍 HITL；禁真 LLM。  
> **对齐**：[agent-entry-modes](./agent-entry-modes.md)（通用自由）；本波**不**抢做项目模式深化。

## 1. 范围

| 做 | 不做（本波） |
|----|--------------|
| `/agent` 通用壳视觉与交互对标 Grok | 扩项目夹 IA、焊专利步骤条、角标墙 |
| 左 bot 列表 · 主消息流 · 底 sticky composer | 把 Catalog/sessions 当默认主屏 |
| 点 bot 一对一；新建 bot | 强制先选 Catalog 再聊 |
| 转发/互通 | 可次级，不挡主路径 |

项目模式路由可维持现状，但**默认落地与主视觉以通用 Grok 壳为准**。

## 2. 布局（冻结）

```text
┌──────────┬─────────────────────────────┐
│ 窄侧栏    │  主区：当前 bot 消息流        │
│ bot 列表  │                             │
│ · 头像    │                             │
│ · 名称    │                             │
│ · 选中态  │─────────────────────────────│
│ [+] 新建  │  底栏：sticky composer       │
└──────────┴─────────────────────────────┘
```

| 区 | 规格 |
|----|------|
| **左窄侧栏** | bot 行：头像 + 名；选中高亮；顶部或底部「新建」；少装饰、少角标 |
| **主区** | 仅当前 bot 的消息气泡流（用户/助手）；干净留白 |
| **底栏** | `position` sticky；单行/多行输入 + 发送；不堆二次入口 |

## 3. 交互

| 动作 | 行为 |
|------|------|
| 点侧栏 bot | 切换一对一线程；主区换流 |
| 新建 bot | 进简单命名（mock）；侧栏出现新项并选中 |
| 转发 | 次级：消息菜单「转发给…」即可；无则本波可延后 |
| 绑案 | **若保留**：极弱（小字/菜单项）；**不得**占主视觉 |

## 4. 视觉纪律

- 干净、少产品文案、少「样机/Pack/角标」墙（诚实一句可放极淡顶栏或设置里）。  
- 对标心智 = **Grok 助手列表 + 聊天**。  
- **禁止**默认屏同时堆：Catalog 大卡、sessions 表、项目夹、专利步骤条。

## 5. 与既有路由

| 路由 | 本波角色 |
|------|----------|
| `/agent` | **主路径** = 本复刻布局 |
| `/agent/bots/:id` | 可选深链；可与 `/agent`+选中态等价 |
| `/agent/compose` | 若在，降级或并入主 composer |
| `/agent/projects*` | 不删；不抢默认、不本波深化 |
| `/agent/sessions` | 次级历史；勿代替侧栏 bot 列表 |
| `/agent/agents` | Catalog 管理；勿默认落地 |

## 6. 验收

- [ ] 打开 `/agent` 即见窄侧栏 bot 列表 + 消息流 + sticky composer  
- [ ] 点 bot 切换一对一  
- [ ] 可新建 bot（mock）  
- [ ] 主屏无 Catalog/sessions/项目拼盘感  
- [ ] 绑案若在则极弱
