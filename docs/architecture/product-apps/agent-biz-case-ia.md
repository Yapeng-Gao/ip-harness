## 1. 一句话

业务案页 = **左栏（案子列表 + 本案席，可折叠）+ 右栏（席工作面以会话为主）**；工程词默认藏；右上**只一主 CTA**；进度只走一条（会话 /「让它干活」→ `advanceSeatWork`）。

---

## 2. 三刀（钉死）

### 刀 1 · 两栏

```text
┌─────────────────┬────────────────────────────────────────┐
│ 左栏（可折叠）   │  右栏 · 席工作面                        │
│ · 案子列表      │  顶：案名 +【单一主 CTA】（见刀 2）      │
│ · 本案席位      │  主：人 ↔ 本席 bot 会话                  │
│   查新…审查答复 │  次：成果 / 办理过程 → 抽屉或次 tab      │
│ · 群聊入口      │  （非第三栏；保持可进 room）             │
│ （阶段极简可并入）│  席内步骤 pill = 只读（见刀 3）         │
└─────────────────┴────────────────────────────────────────┘
```

| 钉 | 口径 |
|----|------|
| **两栏** | 左 = 案子列表 + 本案席（可折叠）；右 = 席工作面 |
| **禁止第三栏** | 群聊**不**开成常驻第三栏；侧栏/左栏保留 **可进 room** 入口即可 |
| **右栏主区** | **会话为主**；成果 / 办理过程 → **抽屉或次 tab**（非与会话三等分主链） |
| **顶栏阶段** | **极简**（一行阶段名）**或并入左栏**；勿再占一整条可点主链 pill 墙抢 CTA |

**禁止**：

- `[案子侧栏][席轨][工作面]` 视觉三栏常驻  
- 群聊拆成第三工作栏  
- 顶栏阶段 pill 墙与右上主 CTA / 席步骤条抢「推进」语义  

### 刀 2 · 藏工程词 · 单一主 CTA

| 钉 | 口径 |
|----|------|
| **藏席 bot 角标** | 默认不上屏「席 bot」字样/角标；详情或 `?debug=1` 可展 |
| **藏工程文件名** | 默认不上屏 `disclosure_pack` / `08_*.md` / `NN_*_worklog.md` 等；成果·办理过程用业务名；**详情可展**文件名 |
| **右上只一主按钮** | 有待确认 → **「去确认·…」**；否则 **「让它干活」** 或交卷步 **「交卷」**（人话） |
| **专家台降次级** | 「专家台 · 本案」不得与主 CTA 并列同级；链到 `/agent/projects/:id/bots/:seat` 或 Catalog，**次级/更多** |
| **会话内 chip** | 「让它干活 / 交卷请确认」可留在作曲器旁作**同路径快捷**（仍走 `advanceSeatWork`），不另开第二主按钮宇宙 |

**禁止**：

- 顶栏主 CTA + 席头再一颗同级「让它干活」双主按钮  
- 默认露出 Pack 文件名、席 bot 角标抢视线  
- 专家台按钮与主 CTA 同视觉权重  

### 刀 3 · 单一进度

| 钉 | 口径 |
|----|------|
| **一条推进链** | 推进 = 会话回合 /「让它干活·交卷」→ **`advanceSeatWork`** →（交卷步）本案 HITL → 人确认后主链前进 |
| **席内步骤 pill** | **只读**；不可点切步；不承担「点 pill = 推进」 |
| **去掉重复主链** | 勿同时上屏：可点阶段墙 + 可点席步骤 + 第二套「完成本步」主按钮 |

**保留（勿回退）**：

- 双文件正文随 `stepIndex` 真更新  
- 交卷 → 本案 HITL store；确认后 `stageId` / `doneSeatIds` 前进  
- Catalog / 专家台进本案 **同一 `projectId`**  
- `/agent` 开聊空态；7 席同构同一会话壳

## 4. 验收（规格）

- [ ] 案内视觉 **两栏**（案子+席 | 工作面）；群聊仅入口、无第三栏  
- [ ] 右栏会话为主；成果/过程为抽屉或次 tab  
- [ ] 默认无「席 bot」角标、无 `08_*.md` / disclosure_pack 抢主视线（详情可展）  
- [ ] 右上**唯一**主 CTA：待确认→去确认；否则让它干活/交卷  
- [ ] 专家台为次级  
- [ ] 席步骤 pill 只读；推进只走会话/`advanceSeatWork`；无重复可点主链  
- [ ] 不回退：开聊首页 · 席=bot · 双文件 · 交卷 HITL · Catalog 同 projectId · 7 席同构
