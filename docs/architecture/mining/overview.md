# 专利挖掘 · 概览

> **样机诚实**：发明点与评分为规则/种子，非真模型。  
> **波次**：W4。

## 1. 为何独立壳

- 路径是「交底 → 点子 → 评分 → 送下游」，与 workbench 办理 Flow、FTO 对比矩阵不同。  
- 默认 **`apps/mining:5184`**；备选挂 workbench 阶段模块（主计划允许），状态机不变。

## 2. 边界

| 邻居 | 关系 | 禁止 |
|------|------|------|
| **search** | 可选消费 Hit 作「已有公开」对照示意 | 重造检索引擎 |
| **inspire :5185** | 激发卡片可「送挖掘」（占位）；挖掘不负责漫游扩召 | 两壳揉成一个 |
| **fto** | 发明点可深链 FTO（占位） | 共享写模型 |
| **doc-harness / workbench** | 「送撰写/立项」= 事件 + 深链占位 | DomainCommand 建案 |
| **case-core** | **无**写路径 | 创建/改 PatentCase |
| **ai-data** | 无关 | 把交底当训练集发布 |

## 3. 核心对象（样机）

| 对象 | 含义 |
|------|------|
| `Disclosure` | 交底/技术点正文（可编辑） |
| `InventionCandidate` | 候选发明点：标题、要点、可选关联 Hit |
| `ScoreCard` | 维度分：新颖示意 / 价值 / 可写性 等假分 + 总分 |
| `HandoffIntent` | 送立项 / 送撰写 的占位意图（事件日志） |
