## 2. 各步要点

### ① 交底/技术点

- Textarea 或简易分节：背景 / 技术点 / 效果。  
- 「从种子加载」「清空」。  
- 可选：「关联 Search Hit」多选（种子 Hit；跨口说明同 FTO——以种子为准）。

### ② 候选发明点

- 「拆解生成」→ 短延迟 → 产出 ≥ 3 条 `InventionCandidate`（关键词/段落切分即可）。  
- 可手增/删/改标题与要点。  
- 空列表不能进入送出。

### ③ 评分

- 每条候选：滑条或星级 → 汇总排序。  
- 「按总分排序」。  
- 维度名诚实标「示意」。

### ④ 送立项 / 撰写

- 多选候选 → 「送立项」/「送撰写」。  
- 结果：事件日志 + toast；深链占位（workbench / doc-harness URL）。  
- **禁用**文案「已创建案件」。
