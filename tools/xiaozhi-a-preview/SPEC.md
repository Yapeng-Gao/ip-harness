# Spec：小知 A · 3D 形象优化路径

> **状态**：可评 · 未开工外包  
> **范围**：仅 3D 形象与接入门槛；**不改** `apps/agent` 产品原型，直至 GLB 验收通过  
> **真源造型**：外包设定板 A（3.5 头身半写实职业风）· 附件「小知 · 3D 数字人形象设定需求文档（外包版 v1）」  
> **本地示意**：本目录 `index.html`（程序化几何 · **仅色板/动作示意，不作形象评审**）  
> **产品现状**：大厅前台仍为小林 SVG / 既有原型；与小知 3D 解耦

---

## 0. 一句话

**程序化半身已证明「色板可对、气质不够」；优化路径 = 停抠几何 → 按 A 板外包 GLB → 独立预览验收 → 通过后再挂产品。**

---

## 1. 现状评估（钉死）

| 项 | 结论 |
|---|---|
| 当前 `index.html` 几何人 | 球+胶囊玩具感；发/西装/丝巾读不出设定；**不可作形象决策依据** |
| 再调 Three.js 几何 | 边际收益极低，到不了半写实职业风 |
| 色板 | 可用：肤 `#F3D4C0` · 发 `#5B3A2E` · 西装 `#C9CDD3` · 衬衫 `#F5F6F8` · 品牌点缀 `#3B6FE0`（占位） |
| 与产品 | **禁止**为「优化形象」改大厅 / `ExpertAvatar` / `LiveBust3D` |

### 1.1 明确不做（优化黑名单）

- 继续打磨程序化球体刘海 / 贴片丝巾冒充写实  
- 在 `apps/agent` 挂粗糙 3D 作前台主形象  
- 本期开发方向 C（7.5 头高写实）；C 仅对照评估，见 §6  
- 舞蹈、卖萌、夸张表演、耳麦回潮（A 板无耳麦）

---

## 2. 目标形象（优化终点 = A 正式设定）

| 维度 | 规格 |
|---|---|
| 定位 | 全系统拟人度上限；唯一 3D 数字人；亲和 × 专业 × 可靠 |
| 气质参照 | 大厂前台 / 航司地服；禁低幼玩具、网红脸、过度性感 |
| 比例 | 3.5 头身；肩宽 ≈ 2 头；腰线在 2 头处 |
| 眼 | 大眼、双眼皮、睫毛清晰；黑瞳高光偏上 |
| 发 | 深栗色低马尾 `#5B3A2E`；齐刘海侧分；无碎发 |
| 服 | 浅灰西装 `#C9CDD3` + 白衬衫 `#F5F6F8` + **左领品牌丝巾** + **胸前工牌**「小知 · 数字前台」 |
| 肤 | `#F3D4C0`；PBR + 轻度 SSS |
| 品牌色 | **只**用于丝巾 / 挂绳 / 工牌点缀（主体黑白灰） |

## 3. 优化分期（怎么做）

### 阶段 0 · 冻结示意（已完成）

| 项 | 规格 |
|---|---|
| 产物 | `tools/xiaozhi-a-preview/` 独立页 |
| 用途 | 色板核对、presence 意图演示 |
| 标签 | UI 明示「仅色板/动作示意 · 不作形象评审」 |
| 产品 | 零挂载 |

### 阶段 1 · 外包下单（主优化）

按外包版 v1 直接报价下单（本仓库附件 / 设定板截图一并交付）。

| 项 | 规格 |
|---|---|
| 技术 | `< 8 万` 三角面；glTF/GLB；PBR 全套；标准人形骨骼；口型通道预留 |
| LOD | 另交 ≤ 1.5 万面降级 |
| 表情 | blendshape **6** 基：微笑待机 / 专注倾听 / 引导手势 / 点头确认 / 认真道歉 / 担忧询问 |
| 动作 | **4**：待机呼吸 / 引导手势 / 欠身 / 递物 |
| 节奏 | 响应感 0.3–0.6s（产品侧控制；模型不「秒切」一切） |
| 语音 | 默认可静音；口型通道留给后置 TTS |
| 周期 | 三视图确认后约 3–4 周（商务以合同为准） |
| 改稿 | 建模 ≥ 2 轮；表情 ≥ 1 轮 |

**交付物（验收清单）**

1. 三视图（正/侧/背，服装发型标注）  
2. T-pose 源文件（Blender 或 Maya）+ GLB  
3. 6 表情演示视频（每表情约 3s）  
4. 贴图规范与源文件  
5. 4 动作演示视频  
6. LOD 降级 GLB  

### 阶段 2 · 独立预览验收（仍不进产品）

| 项 | 规格 |
|---|---|
| 落点 | 本目录替换/旁挂真 GLB 查看器（可新建 `viewer-glb.html`，**勿**改 agent） |
| 验收环境 | 中端机 Chrome / Safari ≥ 30fps |
| 验收人 | 产品 + 设计对照设定板与 §4 |
| 通过标准 | 见 §4；未通过不进入阶段 3 |

### 阶段 3 · 产品接入（闸：阶段 2 通过）

| 项 | 规格 |
|---|---|
| 触发 | 书面确认「形象可上大厅」 |
| 建议挂载 | `apps/agent` 前台 `live3d` ← 验收通过的 GLB；大厅可从 SVG 切真 3D |
| 降级 | 弱机 / WebGL 失败 → SVG 或静帧工牌像 |
| 人设文案 | 若上线小知：名片「小知 · 数字前台」；与现行「小林」切换需单独产品决策（本 spec 不擅自改原型） |

---

## 4. 验收标准（形象 + 工程）

### 4.1 形象

| # | 标准 |
|---|---|
| V-1 | 正面/侧面一眼可读「职业前台」，无玩具球头感 |
| V-2 | 发丝/刘海/低马尾轮廓清晰，无碎发堆砌 |
| V-3 | 西装领型可读；丝巾在左领；工牌字样「小知 · 数字前台」 |
| V-4 | 主体黑白灰，品牌色仅点缀 |
| V-5 | 表情 5（道歉）无委屈/卖萌倾向；表情 6 无可怜相 |
| V-6 | 动作克制；无舞蹈卖萌 |

### 4.2 工程

| # | 标准 |
|---|---|
| E-1 | 主模型 `< 8 万` 三角；LOD ≤ 1.5 万 |
| E-2 | 无穿模、无破面；任意轨道旋转可读 |
| E-3 | 中端设备浏览器 ≥ 30fps（半身构图） |
| E-4 | 6 blendshape 可独立触发且可混合 |
| E-5 | 源文件 + 授权链完整（买方独占使用） |
