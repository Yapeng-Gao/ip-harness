# 小知 A · 3D 形象优化方案

> **决策用** · 细节验收见 [SPEC.md](./SPEC.md) · 造型真源见外包设定板 / 外包版 v1  
> **原则**：不改 `apps/agent` 原型，直至形象验收通过  

---

## 1. 问题

当前独立页程序化半身：色板大致对，**气质不对**（玩具球头、贴片配饰、无西装/发丝可读性）。  
继续用 Three.js 几何「打磨」到不了设定板半写实职业风，且会浪费排期。

---

## 2. 方案对比（已改裁）

| 方案 | 做法 | 状态 |
|---|---|---|
| **自研程序化 v2（当前）** | 本目录升级造型 + **色板定稿**（`COLORS.md`，品牌 `#2F5FE0`） | **进行中** · 不改 agent |
| 外包 GLB | 半写实职业风终局 | **本期不做**（产品要求自研） |
| 方向 C 高写实 | 恐怖谷风险 | **否决** |

> 自研上限仍低于外包设定板；目标是「半身可读职业前台 + 色板/动作可评」，不是毛孔级。

---

## 3. 推荐方案怎么走

```
冻结程序化示意（已有 index.html）
        ↓
钉品牌色 → 打包 BRIEF（SPEC + 设定板 + 外包版 v1）询价
        ↓
三视图确认 → 建模 / 贴图 / 表情 / 动作
        ↓
GLB 进本目录独立 viewer 验收（SPEC §4）
        ↓
【闸】通过 → 再开「产品接入」任务（改 agent；大厅可降级 SVG）
```

### 3.1 外包要什么（摘要）

- 造型：3.5 头身 · 灰西装白衬衫 · 左领品牌丝巾 · 工牌「小知 · 数字前台」  
- 技术：GLB · &lt;8 万三角 · PBR+轻 SSS · LOD≤1.5 万  
- 表情 6：待机微笑 / 倾听 / 引导 / 点头 / 道歉（禁委屈卖萌）/ 担忧（禁可怜相）  
- 动作 4：呼吸 / 引导 / 欠身 / 递物  
- 交付：三视图 + 源文件 + GLB + 表情/动作演示视频 + 贴图规范  

### 3.2 验收闸（不过不进产品）

- 一眼职业前台，无玩具感  
- 丝巾/工牌/发/西装可读；品牌色只点缀  
- 中端机浏览器半身 ≥30fps  
- 6 表情 + 4 动作达标  

### 3.3 产品接入（验收后另开任务）

- 大厅：`live3d` ← 验收 GLB；失败/弱机 → 现有 SVG  
- 人设名「小知」vs 现行「小林」：**单独产品决策**，本方案不擅自改原型
